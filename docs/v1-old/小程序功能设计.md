## 2. 登录认证

**适用**：家长端和教师端小程序

### 2.1 设计方案：微信静默登录

核心原则：用户只在首次点击一次「手机号授权」按钮，后续打开小程序完全无感。

### 2.2 首次登录流程

```
用户打开小程序
  │
  ├─1─ wx.login()                      静默，无弹窗，获取 code
  │
  ├─2─ 显示「微信手机号一键登录」按钮      用户点一次授权
  │     button open-type="getPhoneNumber"
  │
  ├─3─ 拿到 code + 加密手机号
  │     POST /api/v1/auth/wechat-bind
  │     → 后端解密手机号 → 按 mobile 匹配 sys_user
  │       → 匹配成功：绑定 wx_openid → 签发 JWT → 登录成功
  │       → 匹配失败：返回「未关联账户，请联系机构」
  │
  └─4─ 存 token → 进入小程序首页
```

### 2.3 静默登录流程（第二次及以后）

```
用户打开小程序
  │
  ├─1─ wx.login()                      静默，获取 code
  │
  ├─2─ POST /api/v1/auth/wechat-login
  │     → 后端 code 换 openid → 查 sys_user.wx_openid
  │       → 找到：签发新 JWT → 登录成功
  │       → 未找到：回退到首次登录流程（显示授权按钮）
  │
  └─3─ 用户完全无感，直接进入首页
```

### 2.4 Token 刷新

- accessToken 2 小时过期，refreshToken 7 天
- 小程序每次启动时检查 token 有效性
- 过期 → 自动调 `POST /api/v1/auth/refresh` → 无感续期
- refreshToken 也过期 → 重新走静默登录

### 2.5 小程序页面状态

**登录中**（静默登录执行中）：
- 全屏 loading："正在登录…" + 品牌 logo
- 最长等待 5 秒，超时显示错误页 +「重试」按钮

**首次使用**（未绑定 openid）：
- 显示品牌页
- 「微信手机号一键登录」按钮（`open-type="getPhoneNumber"`）
- 下方小字："登录即表示同意《用户协议》"

**登录失败**（手机号未关联）：
- 空状态插图："未找到您的账户信息"
- 提示文字："请联系机构将您的手机号录入系统"
- 「联系机构」按钮（拨打机构电话）

### 2.6 新增 API

| 接口 | 入参 | 返回 | 说明 |
|------|------|------|------|
| `POST /api/v1/auth/wechat-login` | `{ code }` wx.login 返回 | `{ accessToken, refreshToken, userInfo }` 或 401 | code → openid → 查 wx_openid → 签发 JWT |
| `POST /api/v1/auth/wechat-bind` | `{ code, encryptedPhone, iv }` getPhoneNumber 返回 | `{ accessToken, refreshToken, userInfo }` 或 401 | 解密手机号 → 匹配 mobile → 绑定 openid → 签发 JWT |

### 2.7 数据变更

- `sys_user` 表新增 `wx_openid` 字段（VARCHAR 64，唯一索引，可空）
- 家长角色用户：`password` 字段存随机值（不使用），`username` 默认取手机号

### 2.8 家长账号自动注册

**触发时机**：PC 端录入学生信息，填写家长手机号

**后端逻辑**：
1. 按手机号查 `sys_user WHERE mobile = ?`
2. 不存在 → 自动插入：`username=手机号, password=随机UUID(不使用), role=家长, status=正常`
3. 存在 → 跳过
4. 关联学生档案 ↔ 家长 user_id

**结果**：家长首次打开小程序 → 授权手机号 → wx_openid 绑定到已有的 sys_user → 直接看到关联的孩子信息

### 2.9 后端依赖

- 微信 `jscode2session` API：`GET https://api.weixin.qq.com/sns/jscode2session?appid=APPID&secret=SECRET&js_code=CODE&grant_type=authorization_code`
- 微信手机号解密：AES-128-CBC，使用 session_key 解密 `getPhoneNumber` 返回的 encryptedData
- `wechat.app-id` 和 `wechat.app-secret` 写在 `application.yml`

## 4. 家长端页面设计

### 4.1 课程 Tab（✅ 已确认）

**定位**：面向潜在家长的课程橱窗，纯展示，无报名入口。

#### 课程列表页（主页面）

- 顶部：科目筛选标签（全部 / 语文 / 数学 / 英语 ...）
- 课程卡片列表，每张卡片展示：
  - 课程名称 + 类型标签（班课 / 一对一 / 小班）
  - 适用年级
  - 上课时间简述（如"每周六 14:00-16:00"）
  - 费用（如"¥200/课时"）
- 点击卡片进入详情页

#### 课程详情页

- 课程头图
- 课程名称 + 科目 + 类型
- 课程介绍（富文本）
- 上课安排：时间 + 地点/教室
- 授课教师简介
- 费用说明
- 底部无按钮（纯展示）

### 4.2 动态 Tab（✅ 已确认）

**定位**：以时间线展示所有孩子的动态，手风琴式展开/折叠。

**规则**：
- 多孩子混合展示，每条标注所属孩子
- 按时间倒序排列
- 默认折叠，显示预览摘要；点击展开完整内容

#### 签到通知卡片

- 预览："[孩子名] 已于 15:02 到校"
- 展开：签到时间、课程名称、考勤状态

#### 课堂评价卡片

- 预览："[孩子名] 今日课堂表现 ⭐⭐⭐⭐" + 评语前 30 字
- 展开：完整评语 + 各维度星级详情

#### 成绩更新卡片

- 预览："[孩子名] 数学月考：92 分"
- 展开：成绩趋势折线图 + 历史成绩列表

#### 作业通知卡片

- 预览："[孩子名] 语文作业：" + 内容前 30 字
- 展开：完整作业描述 + 附件图片

### 4.3 我的 Tab（✅ 已确认）

**定位**：家长个人中心。管理绑定手机号、查看孩子档案、报班/请假记录、系统通知、通知偏好设置。

**孩子关联机制**：通过手机号关联。家长在小程序绑定手机号 → 系统匹配后台学生档案中关联的家长手机号 → 自动展示对应孩子。无需手动添加或扫码。

#### 4.3.2 个人头部

| 元素 | 说明 |
|------|------|
| 头像 | 微信头像（`wx.getUserProfile` 获取） |
| 昵称 | 微信昵称 |
| 绑定手机号 | 脱敏显示，如 `138****5678`；未绑定时显示「绑定手机号」引导按钮 |

**手机号绑定流程**：
- 点击手机号区域 → 调起微信手机号快速验证组件（`button open-type="getPhoneNumber"`）
- 获取加密手机号 → 后端解密 → 写入家长档案 → 同时触发孩子匹配
- 绑定后该入口变为仅查看（脱敏展示），长按或点击可解绑/换绑

**换绑处理**：
- 换绑手机号后，重新执行孩子匹配
- 旧手机号关联的孩子自动解除

#### 4.3.3 我的孩子

**卡片内容**（每个孩子一张）：

| 字段 | 说明 |
|------|------|
| 姓名 | 学生姓名 |
| 年级 | 当前年级（如「三年级」） |
| 在读班级数 | 如「2 个班」 |
| 剩余课时汇总 | 所有在读班级剩余课时之和，如「剩余 18 课时」 |

**交互**：
- 横向滑动浏览多个孩子
- 点击卡片 → 进入「孩子详情页」（见 4.3.6）
- 只有一个孩子时卡片居中展示，无需滑动
- 无孩子时展示空状态：「暂无关联孩子，请联系机构绑定」，下方提供机构电话快捷拨打

**手机号匹配孩子的规则**：
- 家长绑定手机号后，系统搜索所有学生档案中家长手机号匹配的记录
- 一个手机号可能关联多个学生（如二胎家庭）
- 一个学生可能关联多位家长（如父母双方），每位家长登录后都能看到该孩子
- 匹配不到孩子时，展示空状态引导联系机构

#### 4.3.4 功能菜单

##### 报班记录

- **位置**：点击「报班记录」→ 进入报班记录页
- **内容**：按孩子分组，手风琴展开/折叠
- **每条记录展示**：
  - 课程名称 + 班级名称
  - 报班时间
  - 总课时 / 剩余课时
  - 有效期（起止日期）
  - 状态：在读 / 已结课
- **默认展开第一个孩子，其余折叠**

##### 请假记录

- **位置**：点击「请假记录」→ 进入请假列表页
- **列表**：按时间倒序，展示所有孩子的请假申请
- **每条展示**：
  - 孩子姓名（多孩家庭需要标注）
  - 请假日期
  - 请假类型（事假/病假）
  - 状态：待确认 / 已通过 / 已驳回
- **发起请假**：底部悬浮按钮「+ 请假申请」或列表页右上角入口，进入请假申请页
  - 选择孩子（多孩时）
  - 选择日期
  - 选择类型（事假/病假/其他）
  - 填写原因（文本框）
  - 提交 → 通知对应教师确认
- **已驳回的请假**：展示驳回原因

##### 系统通知

- **定位**：与动态 Tab 明确分工
  - **动态 Tab**：以孩子为维度的内容流（签到通知、课堂评价、成绩更新、作业通知），每条标注所属孩子，手风琴展开
  - **系统通知**：以事件为维度的推送汇总，纯列表，不区分孩子，用于回溯查看
- **列表**：按时间倒序，所有类型混合展示
- **每条展示**：
  - 通知类型图标（签到/评价/成绩/作业/请假结果）
  - 标题（如「张三 到校签到」「李四 课堂评价已更新」）
  - 时间
  - 已读/未读状态
- **点击**：跳转到对应的动态详情或审批结果
- **无需分类筛选**：MVP 阶段混合列表即可，后续可加类型筛选

##### 联系机构

- **点击直接拨打**机构电话（`makePhoneCall`）
- 号码从系统配置中读取（M0 系统配置中维护）
- 不跳转子页面，点击即弹拨打确认

#### 4.3.5 设置

##### 通知设置

从功能菜单中的「通知设置」或主页底部「设置」区域进入。

| 通知类型 | 默认 | 说明 |
|---------|:--:|------|
| 签到通知 | 开 | 孩子到校/迟到/缺勤时推送 |
| 课堂评价通知 | 开 | 教师发布课堂评价后推送 |
| 作业通知 | 开 | 教师布置作业后推送 |
| 成绩通知 | 开 | 新成绩录入后推送 |
| 请假审批结果 | 开 | 请假通过/驳回后推送 |

- 所有开关默认开启
- 关闭后不影响数据产生，仅停止该类型的微信订阅消息推送
- 开关状态保存在后端，跨设备同步

##### 关于平台

- 平台名称
- 版本号
- 机构名称（从系统配置读取）

##### 退出登录

- 点击后弹窗确认
- 确认后清除本地 token → 回到登录页
- 同时清除微信订阅消息授权状态（下次登录需重新授权）

## 5. 教师端页面设计

### 5.1 课表 Tab（✅ 已确认）

**定位**：周视图日历，查看自己的排课安排。

#### 主页面

- 顶部周选择器：← 上一周 | 日期范围 | 下一周 →，今天一键回到本周
- 星期横轴（一～日）
- 每天列出当天的课时卡片：
  - 时间段（14:00-16:00）
  - 课程名称 + 班级名
  - 教室位置
  - 学生人数
- 无课日显示"今日无课"

#### 交互

- 点击课时卡片 → 进入该节课详情（学生名单 + 课程信息）
- 已过日期卡片置灰只读，今天和未来可操作
- 左右滑动切换周

### 5.2 签到 Tab（✅ 已确认）

**定位**：选择当日课程，批量勾选到校学生。无地理位置限制。

#### 步骤 1：课程选择

- 显示教师当天所有排课列表
- 每项：时间段 + 课程名 + 班级名 + 应到人数
- 已签到的课标注"已签到"
- 点击进入签到页

#### 步骤 2：批量签到

- 顶部：课程信息 + 应到/已签人数
- 学生列表：全选 + 逐个勾选，默认全部"到校"
- 未到校学生手动取消勾选（迟到/缺勤）
- 底部「确认签到」按钮
- 签到成功后触发微信订阅消息推送家长

### 5.3 教学 Tab（✅ 已确认）

**结构**：顶部子导航切换「评价」和「作业」两个模块。

#### 评价

**定位**：教师课后对课堂和学生个人进行评价，支持暂存草稿。

**步骤 1：选择课程**
- 近期已上课的排课列表（按日期倒序）
- 每项：日期 + 时间段 + 课程名 + 班级名
- 状态标注：已评 / 待评 / 草稿
- 点击进入评价页

**步骤 2：课堂评价填写**
- 课堂总结：整体评论文本框（教学内容、课堂氛围等）
- 学生个人评价列表：
  - 星级评分（1-5 星，点击打星）
  - 文字评语（文本框，可跳过）
- 支持暂存草稿，后续继续编辑再提交

#### 作业

**定位**：教师课后布置作业，支持文字 + 图片 + 文件附件。

**作业列表**
- 已布置的作业按日期倒序
- 每项：日期 + 课程名 + 班级名 + 内容摘要
- 点击展开查看详情

**布置作业页**
- 选择关联课程/班级
- 文字描述（文本框）
- 上传图片（相册/拍照）
- 上传文件（PDF/Word 等）
- 底部「发布」按钮

**入口**：作业列表底部悬浮按钮「+ 布置作业」

### 5.4 我的 Tab（✅ 已确认）

- 个人信息：头像 + 姓名 + 手机号 + 所授科目
- 设置：消息通知开关、关于平台、退出登录

## 6. 校长/主管端页面设计

### 6.1 工作台 Tab（✅ 已确认）

#### 今日概览

### 6.2 消息 Tab（✅ 已确认）

**定位**：审批操作 + 知会消息。

#### 待审批
