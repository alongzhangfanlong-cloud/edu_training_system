# M1 课程管理

> **模块定位**：基础资源层（P0），课程体系 + 教室资源的数据底座，为班级管理、排课管理提供核心引用数据。
> **后端模块**：`edu-module-course`，同时支撑前端「课程管理」和「教室管理」两个独立菜单。
> **菜单位置**：左侧「基础管理」目录下，与教师管理、班级管理、教学管理、课件资料库同级。
> **访问角色**：校长、运营主管。

### 2.2 科目标签栏

#### 2.2.1 布局与行为

科目标签栏位于课程列表页顶部，用于快速按科目筛选课程，同时提供轻量级的科目管理入口。

| 元素 | 说明 |
|------|------|
| [全部] | 默认选中，显示所有课程。始终第一位，不可删除/移动 |
| 科目标签 | 按 `sort_order` 升序排列，每个标签显示科目名称 |
| 停用标签 | 停用科目显示灰色文字 + 小字"已停用"，排在启用标签之后 |
| [管理] | 齿轮图标 + 文字，点击弹出科目管理弹窗（§2.3） |

**交互规则：**
- 点击某科目标签 → 标签高亮（主题色）→ 筛选该科目下的课程 → 列表刷新
- 点击[全部] → 清除科目筛选 → 列表刷新
- 选中标签后切换页面前记录选中状态，从其他页面返回仍保持
- 科目标签栏数据由 `GET /api/v1/course/subject/list` 驱动，页面加载时获取

#### 2.2.2 科目标签无数据时

科目标签区仅显示 `[全部]`，其余标签区域为空。不影响课程管理正常使用。

#### 2.3.3 表格列定义

| 列 | 宽度 | 对齐 | 说明 |
|------|:--:|:--:|------|
| 序号 | 60px | 中 | 自动编号 |
| 科目名称 | — | 左 | 停用科目名称后附灰色"(已停用)" |
| 排序 | 80px | 中 | 可编辑数字，失焦自动保存（调用排序更新接口） |
| 状态 | 80px | 中 | ●绿色圆点「启用」/ ○灰色圆点「停用」 |
| 操作 | 200px | 中 | 按钮组（见下方） |

#### 2.3.4 操作列按钮

| 按钮 | 行为 |
|------|------|
| 编辑 | 科目名称变为可编辑输入框 + 确认/取消按钮（行内编辑，见 §2.3.5） |
| 停用/启用 | 切换状态，二次确认 |
| 删除 | 二次确认 → 调用 API。如科目被课程引用 → 后端返回错误 → toast "该科目下已有课程，不可删除，仅可停用" |

#### 2.3.5 行内编辑

点击「编辑」→ 该行科目名称变为输入框，操作列变为 [确认] [取消]：

- 确认 → 前端校验（名称非空、1-10 字符）→ `PUT /api/v1/course/subject/{id}` → 成功 → 刷新列表
- 取消 → 恢复原值
- 编辑中点击「删除」/「停用」→ 先自动取消编辑再执行操作

#### 2.3.6 新增科目

点击列表上方「+ 新增科目」→ 在表格顶部插入一行可编辑行：

| 列 | 内容 |
|------|------|
| 序号 | "--"（新增中） |
| 科目名称 | 输入框，焦点自动聚焦 |
| 排序 | 自动填充 `max(sort_order) + 1`，可修改 |
| 状态 | 默认「启用」标签，不可修改 |
| 操作 | [确认] [取消] |

- 确认 → 前端校验（名称 1-10 字符）→ `POST /api/v1/course/subject` → 成功 → 刷新列表
- 取消 → 移除新增行
- 同时只能有一行处于新增状态

#### 2.3.7 排序调整

排序列数字可直接点击编辑（双击或单击聚焦），修改后失焦自动调用 `PUT /api/v1/course/subject/sort`（批量入参 `[{id, sortOrder}]`），成功 → 刷新列表。

#### 2.3.8 二次确认文案

| 操作 | 弹窗文案 |
|------|------|
| 停用科目 | "确认将科目「{名称}」的状态改为**停用**？停用后该科目仍可被已有课程引用，但新增课程时不可选择。" |
| 启用科目 | "确认将科目「{名称}」的状态改为**启用**？" |
| 删除科目 | "确认删除科目「{名称}」？如该科目已被课程引用，将无法删除。" |

#### 2.3.9 状态处理

| 状态 | 表现 |
|------|------|
| 加载中 | 弹窗内表格骨架屏（5 行灰色条块） |
| 加载失败 | "科目数据加载失败"+「重试」按钮 |
| 新增/编辑提交中 | 确认按钮 loading |
| 新增/编辑提交失败 | 保留编辑行 + 错误提示 |
| 科目列表为空 | "暂无科目，点击上方按钮新增" |

### 2.7 新增/编辑课程弹窗

#### 2.7.1 触发

- 新增：工具栏「+ 新增课程」
- 编辑：操作列「编辑」

#### 2.7.2 弹窗规格

- 宽度：600px
- 标题：「新增课程」或「编辑课程」

#### 2.7.3 表单字段

| 字段 | 类型 | 必填 | 新增时 | 编辑时 | 校验规则 |
|------|------|:--:|:--:|:--:|------|
| 课程名称 | 文本 | ✅ | 显示 | 显示 | 1-30 字符，失焦异步校验同科目下名称唯一性 |
| 课程编号 | 文本 | ✅ | 显示 | 显示 | 1-20 字符，字母数字连字符。失焦异步校验全局唯一性 |
| 所属科目 | 下拉单选 | ✅ | 显示 | 显示 | 从启用科目列表中选择。编辑时可回填已停用科目（显示为"XXX(已停用)"） |
| 课程类型 | 下拉单选 | ✅ | 显示 | 显示 | 班课 / 一对一 / 小班(2-6人) |
| 单价 | 数字输入 | ✅ | 显示 | 显示 | ≥ 0，最多两位小数，单位"元" |
| 适用年级 | 下拉单选 | ❌ | 显示 | 显示 | 学前 / 一年级 / 二年级 / ... / 高三 / 不限 |
| 状态 | 单选组 | ✅ | 显示 | 显示 | 上架 / 下架（编辑已有课程且被班级引用时，不可设为下架，需走操作列单独下架） |

#### 2.7.4 唯一性校验

| 字段 | 校验时机 | 说明 | 类型 |
|------|------|------|:--:|
| 课程编号 | 失焦 | 全局唯一，重复则红色提示"该编号已被使用" | 硬阻断 |
| 课程名称 | 失焦 | 同科目下名称唯一（编辑时排除自身），重复则红色提示"该科目下已有同名课程" | 硬阻断 |

校验中 → 输入框右侧 loading 图标
校验通过 → 绿色勾
校验失败 → 红色叉 + 错误提示

#### 2.7.5 科目下拉选项
调用 `GET /api/v1/course/subject/list`，过滤 status=启用 的科目。编辑场景下，如果当前课程原科目已被停用，下拉列表中额外追加该项并标注"(已停用)"。

#### 2.7.6 交互

| 操作 | 行为 |
|------|------|
| 打开（新增） | 空表单，状态默认"上架" |
| 打开（编辑） | 调用 `GET /api/v1/course/{id}` → 填充表单 |
| 确认 | 前端校验 → 提交 API → 成功 → toast + 关闭弹窗 + 刷新列表 |
| 取消 | 有修改 → 确认"放弃修改？"；无修改 → 直接关闭 |

#### 2.7.7 状态处理

| 状态 | 表现 |
|------|------|
| 加载中（编辑） | 弹窗内骨架屏（5 行灰色条块） |
| 加载失败（编辑） | "加载课程信息失败"+「重试」 |
| 提交中 | 确认按钮 loading，"保存中…" |
| 提交失败 | 保留弹窗 + 错误提示 |
| 唯一性校验中 | 输入框 loading 图标 |

### 2.8 课程删除与下架

| 场景 | 按钮状态 | 行为 |
|------|------|------|
| 课程未被班级引用 | 「删除」可用 | 二次确认 → `DELETE /api/v1/course/{id}` → 成功 → 刷新列表 |
| 课程已被班级引用 | 「删除」隐藏 | 仅展示「下架」按钮 |
| 课程已下架（未被引用） | 「删除」恢复可用 | 上架后也可删除 |

### 2.9 分页器

| 元素 | 说明 |
|------|------|
| 页码 | 标准页码按钮，当前页高亮 |
| 每页条数 | 下拉选择：10 / 20 / 50 / 100，默认 20 |
| 总条数 | "共 {total} 条" |
| 跳转 | 「前往」输入框 + 确认 |

- 新增：工具栏「+ 新增教室」
- 编辑：操作列「编辑」

#### 3.5.2 弹窗规格

- 宽度：560px
- 标题：「新增教室」或「编辑教室」

#### 3.5.3 表单字段

| 字段 | 类型 | 必填 | 新增时 | 编辑时 | 校验规则 |
|------|------|:--:|:--:|:--:|------|
| 教室名称 | 文本 | ✅ | 显示 | 显示 | 1-30 字符，失焦异步校验名称唯一性 |
| 容纳人数 | 数字输入 | ✅ | 显示 | 显示 | 正整数 1-999 |

|------|------|------|:--:|

- 显示预设标签池（灰底标签），点击选中变为主色标签

## 5. 业务规则

### 5.1 科目引用保护

```
edu_subject ──1对多── edu_course
```

| 规则 | 说明 |
|------|------|
| 停用 | 科目可随时停用。停用后：①科目标签栏中标签灰显+后置；②新增/编辑课程时科目下拉不再显示该科目；③已有课程不受影响 |
| 删除前置检查 | 删除前检查 `edu_course` 表中 `subject_id` 引用。如有引用 → 禁止删除，返回错误"该科目下已有{N}门课程，不可删除，仅可停用" |
| 无引用 | 科目未被任何课程引用 → 允许删除 |

### 5.2 课程引用保护

```
edu_course ──1对多── edu_class
```

| 规则 | 说明 |
|------|------|
| 下架 | 课程可随时下架。下架后：①课程列表行变灰；②新增班级时课程下拉不再显示该课程；③已有班级不受影响 |
| 删除前置检查 | 删除前检查 `edu_class` 表中 `course_id` 引用。如有引用 → 禁止删除，返回错误"该课程已被{N}个班级引用，不可删除，仅可下架" |
| 无引用 | 课程未被任何班级引用 → 允许删除 |
| 已下架+无引用 | 允许删除 |

### 5.3 教室引用保护

```
edu_classroom ──1对多── edu_schedule（排课记录）
```

| 规则 | 说明 |
|------|------|
| 停用 | 教室可随时停用。停用后：①教室列表行变灰；②新增/编辑排课时教室下拉不再显示该教室；③已有排课不受影响 |
| 删除前置检查 | 删除前检查排课表中 `classroom_id` 引用。如有引用 → 禁止删除，返回错误"该教室已被{N}条排课记录引用，不可删除，仅可停用" |
| 无引用 | 教室未被任何排课引用 → 允许删除 |
| 已停用+无引用 | 允许删除 |

### 5.4 引用保护前端联动

| 对象 | 被引用时 |
|------|------|
| 科目 | 操作列「删除」按钮隐藏，仅显示「编辑」「停用/启用」 |
| 课程 | 操作列「删除」按钮隐藏，仅显示「编辑」「上架/下架」 |
| 教室 | 操作列「删除」按钮隐藏，仅显示「编辑」「启用/停用」 |

> 前端通过列表接口返回的 `referenced` 字段（boolean）控制按钮显隐，避免额外请求。

## 8. 异常边界

### 8.1 重复名称/编号

| 场景 | 触发时机 | 前端行为 | 后端行为 |
|------|------|------|------|
| 科目名称重复 | 新增/编辑科目提交 | — | 返回 400 "科目名称已存在" |
| 课程编号重复 | 新增/编辑课程提交 | 失焦时异步校验，重复则红色提示"该编号已被使用"，阻止提交 | 返回 400 "课程编号已存在" |
| 同科目下课程名称重复 | 新增/编辑课程提交 | 失焦时异步校验，重复则红色提示"该科目下已有同名课程"，阻止提交 | 返回 400 "该科目下课程名称已存在" |
| 教室名称重复 | 新增/编辑教室提交 | 失焦时异步校验，重复则红色提示"该教室名称已存在"，阻止提交 | 返回 400 "教室名称已存在" |

### 8.2 引用删除拦截

| 场景 | 前端行为 | 后端返回 |
|------|------|------|
| 删除被引用的科目 | 「删除」按钮已隐藏（列表接口返回 referenced 判断） | 若绕过前端直接调接口 → 返回 400 "该科目下已有{N}门课程，不可删除，仅可停用" |
| 删除被引用的课程 | 「删除」按钮已隐藏 | 若绕过 → 返回 400 "该课程已被{N}个班级引用，不可删除，仅可下架" |
| 删除被引用的教室 | 「删除」按钮已隐藏 | 若绕过 → 返回 400 "该教室已被{N}条排课记录引用，不可删除，仅可停用" |

### 8.3 权限不足

| 场景 | 前端行为 | 后端行为 |
|------|------|------|
| 无 `course:list` 权限 | 菜单不展示「课程管理」入口 | `@PreAuthorize` 拦截 → 返回 403 |
| 无 `classroom:list` 权限 | 菜单不展示「教室管理」入口 | `@PreAuthorize` 拦截 → 返回 403 |
| 无新增/编辑/删除权限 | 工具栏按钮、操作列按钮不渲染（`v-if` 权限码控制） | `@PreAuthorize` 拦截 → 返回 403 |

### 8.4 并发冲突

| 场景 | 表现 |
|------|------|
| 编辑的科目/课程/教室已被他人删除 | 提交后后端返回 404 → toast "该数据已被删除，请刷新列表" → 关闭弹窗 → 刷新列表 |
| 编辑的科目/课程/教室已被他人修改 | 当前版本不做乐观锁。打开编辑弹窗时获取的数据与最新数据可能不一致，以最后提交者为准 |

### 8.5 其他边界

| 场景 | 行为 |
|------|------|
| 课程单价输入负数 | 前端 `min=0` 阻止；后端校验返回 400 |
| 教室容纳人数为 0 或负数 | 前端 `min=1` 阻止；后端校验返回 400 |
| 设施标签超过 10 个 | 前端输入框 disabled + 提示；后端校验返回 400 |
| 科目标签栏无科目时点[管理] | 正常打开弹窗，表格显示空状态 |
