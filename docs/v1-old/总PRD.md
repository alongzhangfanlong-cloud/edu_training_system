> **版本**：v2.0  
> **状态**：草稿  
> **更新日期**：2026-07-13  

---

## 1. 项目背景

### 1.1 问题陈述

传统教育机构在日常运营中面临以下痛点：

- **信息碎片化**：课程安排、学生档案、收费记录散落在 Excel / 微信聊天 / 纸质文件中，查询与追溯困难
- **家校沟通滞后**：家长无法及时了解孩子到校情况、课堂表现和学习进度，机构与家长之间缺乏透明的信息通道
- **教师协作低效**：排课调整、代课协调、成绩录入依赖口头或微信沟通，容易出错和遗漏
- **经营决策缺乏数据支撑**：校长无法快速掌握报名趋势、课时消耗、教师课酬等关键经营指标

### 1.2 产品愿景

为中小型教育机构提供一套**轻量、实用、易上手**的管理工具，覆盖教务管理、家校互通、经营分析三大核心场景，帮助机构从"靠人记"升级为"系统管"。

### 1.3 项目边界

| 在范围内 | 不在范围内（本期不做） |
|----------|------------------------|
| PC 后台管理系统 | 在线支付（线下收费后录入系统） |
| 微信小程序（教师端 + 家长端） | 多校区/连锁机构管理 |
| 教务管理 + 家校互通 + 经营看板 | 对外营销获客（SEO、广告投放等） |
| | 在线直播/网课 |

## 2. 用户画像

### 2.1 角色定义

| 角色 | 使用端 | 核心诉求 |
|------|--------|---------|
| **校长** | PC | 掌握经营全貌：报名趋势、课时消耗、教师产出，做决策有数据依据 |
| **运营主管** | PC | 高效处理日常教务：排课、调课、收费录入、学生档案管理 |
| **教师** | PC + 小程序 | PC 用于备课、录成绩、管理作业；小程序用于签到、查看课表、收到通知 |
| **学生家长** | 小程序 | 实时了解孩子在机构的一切：到校安全、课堂表现、成绩变化、作业通知 |

### 2.2 核心用户旅程

```
家长视角（小程序）：
  收到课程提醒 → 送孩子到校 → 收到签到通知 ✓
  → 看到课堂评价 + 评语 → 查看成绩趋势 → 辅导作业

教师视角（PC + 小程序）：
  打开课表 → 到校签到（小程序） → 课后评语打分（PC/小程序）
  → 布置作业 → 录入成绩 → 上传课件

校长/主管视角（PC）：
  看工作台（今日概览+本周课表） → 处理待办（请假审批/调课）
  → 招生报名录入 → 查看本月课时消耗统计
```

## 3. 功能模块清单

### 3.1 模块分层架构

```
┌──────────────────────────────────────────────────┐
│  第四层：数据与工具                                 │
│  M10 工作台（P0）  │  M11 课件资料库（P2 可选）      │
├──────────────────────────────────────────────────┤
│  第三层：教学互动（P1）                             │
│  M9 教学管理（课堂评价 + 成绩管理 + 作业管理）        │
├──────────────────────────────────────────────────┤
│  第二层：核心教务（P0）                             │
│  M4 班级管理  │  M5 排课管理  │  M6 报名管理          │
│  M7 收银管理  │  M8 考勤管理                        │
├──────────────────────────────────────────────────┤
│  第一层：基础资源（P0）                             │
│  M1 课程管理  │  M2 教师管理  │  M3 学员管理          │
├──────────────────────────────────────────────────┤
│  第〇层：系统底座（P0）                             │
│  M0 系统管理                                      │
└──────────────────────────────────────────────────┘
```

### 3.2 模块总览

| 编号 | 模块 | 优先级 | 简述 |
|------|------|:--:|------|
| M0 | 系统管理 | P0 | 用户、角色、权限、菜单、系统配置、登录认证 |
| M1 | 课程管理 | P0 | 科目体系（内嵌管理）、课程信息（类型/定价），教室独立为平级菜单 |
| M2 | 教师管理 | P0 | 教师档案、可授科目、资质信息 |
| M3 | 学员管理 | P0 | 学生档案、家长信息、报班记录、课时明细 |
| M4 | 班级管理 | P0 | 班级创建（关联课程+教师+教室）、学员管理、上课规则 |
| M5 | 排课管理 | P0 | 单次排课、批量排课、冲突检测、课表视图 |
| M6 | 报名管理 | P0 | 报名信息录入、关联学生/课程/经手人，与 M7 前端合并为「招生管理」 |
| M7 | 收银管理 | P0 | 收费记录、退费处理、赠送课时、收据凭证、财务对账，与 M6 前端合并为「招生管理」 |
| M8 | 考勤管理 | P0 | 签到打卡 + 请假管理（学生/教师请假、代课/调课） |
| M9 | 教学管理 | P1 | 课堂评价 + 成绩管理 + 作业管理，教师课后一站式操作 |
| M10 | 工作台 | P0 | 今日课表、本周概览、本月课时消耗统计、待办提醒 |
| M11 | 课件资料库 | P2 | 课件上传、分类浏览、共享范围、下载 |

**优先级定义：**
- **P0**：MVP 必须，没有它系统不成立
- **P1**：MVP 应包含，家校互通的核心价值
- **P2**：MVP 之后的首批迭代

### 3.3 模块详细说明

#### M0 · 系统管理

| 子功能 | 说明 |
|------|------|
| 用户管理 | 系统用户的增删改查、状态启用/禁用 |
| 角色管理 | 校长 / 运营主管 / 教师 / 家长，各角色权限配置 |
| 权限管理 | 菜单权限 + 按钮权限 + 接口权限 |
| 菜单管理 | 后台左侧菜单树，角色关联后动态展示 |
| 系统配置 | 全局参数（如签到距离限制、请假免费课时额度等） |
| 登录认证 | 账号密码登录 + JWT 令牌 + 登出令牌失效 |

#### M1 · 课程管理

课程管理聚焦课程信息维护，科目作为课程的分类标签在课程列表页顶部以标签栏形式内嵌管理（点击「管理科目」弹出轻量弹窗操作），不设独立子页面。教室管理独立为平级菜单。

| 子功能 | 说明 |
|------|------|
| 课程 CRUD | 课程名称、编号、所属科目、课程类型（班课/一对一/小班）、单价、适用年级、状态（上架/下架） |
| 科目标签栏 | 课程列表页顶部展示科目标签（全部/语文/数学/…），点击筛选；「管理科目」按钮弹出弹窗，支持新增/编辑/删除/排序 |
| 引用保护 | 科目被课程引用后不可删除仅可停用；课程被班级引用后不可删除仅可下架 |

#### M2 · 教师管理

| 子功能 | 说明 |
|------|------|
| 教师档案 | 姓名、手机号、入职日期、状态 |
| 可授科目 | 一个教师可关联多个科目 |
| 教师资质 | 教师资格证、学历、教龄等附加信息 |
| 当前班级 | 展示教师当前在教的班级列表 |
| 教师列表 | 按科目/状态筛选，分页查询 |

#### M3 · 学员管理

学员管理聚焦学生档案维护，课时明细作为每个学员的操作入口（列表行内「课时记录」按钮），不设独立子页面。

| 子功能 | 说明 |
|------|------|
| 学生档案 | 姓名、性别、年级、学校、手机号、标签 |
| 家长信息 | 一个学生可关联多个家长（姓名、关系、手机号、微信 OpenID） |
| 报班记录 | 学生报了什么班、总课时、剩余课时、有效期 |
| 学生状态 | 在读 / 停课 / 结课 / 流失，支持流转 |
| 课时记录 | 每行操作列「课时记录」按钮，弹出抽屉展示该学员的课时变动流水（报名获得 / 上课消耗 / 请假返还 / 补课消耗 / 退费扣回 / 赠送获得） |

#### M4 · 班级管理

| 子功能 | 说明 |
|------|------|
| 班级创建 | 关联课程 + 教师 + 教室，设定最大人数 |
| 学员管理 | 班级内学生列表，支持批量添加/移除 |
| 当前人数 | 实时显示已报人数/最大人数，超员预警 |
| 上课规则 | 每周几上课、几点到几点、每节课时长 |

#### M5 · 排课管理

| 子功能 | 说明 |
|------|------|
| 单次排课 | 指定班级在某天某时段上课 |
| 批量排课 | 按班级的上课规则，一次性生成多周的排课计划 |
| 冲突检测 | 同教师同时段 + 同教室同时段冲突检查 |
| 排课状态 | 正常 / 已取消 / 已调课 / 补课 / 停课 |
| 课表视图 | 按周/月查看课表，支持按教师/教室/班级筛选 |

#### M6 · 报名管理

> 与 M7 收银管理在前端合并展示为「招生管理」菜单。后端独立模块，聚焦报名录入这一业务动作。

| 子功能 | 说明 |
|------|------|
| 报名录入 | 选择学生 + 课程/班级 + 收费金额 + 经手人，完成报名登记 |
| 报名列表 | 按时间/学生/课程筛选，分页查询 |
| 关联收银 | 报名记录自动生成待收费条目，流转至 M7 收银管理 |

#### M7 · 收银管理

> 与 M6 报名管理在前端合并展示为「招生管理」菜单。聚焦资金流：收费确认、退费、赠课时、财务对账。

| 子功能 | 说明 |
|------|------|
| 收费记录 | 确认收费（报名费 / 课时费 / 教材费 / 其他费用） |
| 支付方式 | 现金 / 微信 / 支付宝 / 银行转账（人工选择，非在线支付） |
| 退费处理 | 退费申请 → 审批 → 金额计算 → 课时扣回 → 退款记录 |
| 赠送课时 | 运营促销赠课，记录赠送原因 + 课时数 + 审批 |
| 收据凭证 | 生成简单收费凭证，可打印或截图 |
| 课时入账 | 收费确认后自动为学生增加对应课时 |
| 财务对账 | 按时间/费用类型汇总收入，支持按经手人对账 |
| 收费查询 | 按时间/学生/费用类型筛选，统计收入汇总 |

#### M8 · 考勤管理

**签到子功能：**

| 子功能 | 说明 |
|------|------|
| 班级签到 | 教师选择排课记录，批量勾选到校学生 |
| 签到状态 | 正常到校 / 迟到 / 缺勤 |
| 签到时间 | 记录签到精确时间 |
| 通知推送 | 签到后微信小程序订阅消息通知家长 |
| 签到查询 | 按学生/班级/日期范围查询签到记录 |

**请假子功能：**

| 子功能 | 说明 |
|------|------|
| 学生请假 | 家长(小程序)发起 → 教师确认；教师也可代申请 |
| 教师请假 | 教师发起 → 管理员审批 |
| 请假类型 | 事假 / 病假 / 其他 |
| 冲突处理 | 教师请假审批通过后，系统列出该时段所有排课冲突 |
| 代课处理 | 为冲突排课指派代课教师，通知代课教师+受影响家长 |
| 调课处理 | 将冲突排课改到新时间，通知家长 |
| 停课处理 | 取消当次课标记「待补课」 |
| 课时返还 | 学生请假根据规则返还/不返还课时 |

#### M9 · 教学管理

> 整合课堂评价、成绩管理、作业管理，教师课后一站式操作。PC 端按子模块独立页面，小程序端教师"教学 Tab"下切换。

**课堂评价：**

| 子功能 | 说明 |
|------|------|
| 课堂总结 | 教师对整节课的总体评价（教学内容、课堂氛围） |
| 学生评价 | 对每个学生个人表现打分（1-5星）+ 文字评语 |
| 教师端录入 | PC 或小程序端课后填写 |
| 家长端查看 | 小程序查看自己孩子的评价和评语 |
| 评价历史 | 按时间线查看历史评价记录 |

**成绩管理：**

| 子功能 | 说明 |
|------|------|
| 成绩录入 | 教师按科目录入成绩（考试类型 + 分数 + 满分 + 日期） |
| 批量录入 | 一个班级一次考试批量录入所有学生成绩 |
| 考试类型 | 月考 / 期中 / 期末 / 随堂测验 / 自定义 |
| 成绩趋势 | 家长端：自己孩子的趋势折线图 + 班级平均分对比线 |
| 教师端视图 | 全班成绩表、分数分布、平均分、排名 |

**作业管理：**

| 子功能 | 说明 |
|------|------|
| 布置作业 | 教师课后布置，文字描述 + 上传图片/文档 |
| 作业关联 | 关联排课记录或班级 |
| 教师端管理 | 查看历史布置的作业列表 |
| 家长端查看 | 小程序查看孩子当次作业内容 |

#### M10 · 工作台

> 运营主管和校长登录后的默认首页，提供每日运营概览和关键指标。P0 优先交付。

| 子功能 | 说明 |
|------|------|
| 今日课表 | 当天所有课程安排（时间段 + 课程 + 班级 + 教师 + 教室） |
| 本周概览 | 本周每日上课班级数、到校学生数、请假数 |
| 课时统计 | 本月课时消耗总计、按科目/班级分布 |
| 待办提醒 | 待审批请假、待处理退费、排课冲突预警 |
| 快捷入口 | 报名录入、排课操作、请假审批等常用功能入口 |

#### M11 · 课件资料库

| 子功能 | 说明 |
|------|------|
| 课件上传 | 教师/主管上传课件文件（文档、图片、PPT） |
| 分类管理 | 按科目 / 年级 / 类型分类浏览 |
| 共享范围 | 公开（全体教师可见）/ 私有 |
| 下载 | 教师可下载课件资源 |

**依赖说明：**
- **M0（系统管理）** 是所有业务模块的前置依赖，必须最先开发
- **M1+M2+M3** 是第一层基础资源，M4~M9 均依赖它们
- **M1（课程管理）** 聚焦课程信息+科目分类，是 M4（班级）和 M5（排课）的核心依赖；教室管理独立为平级菜单，后端共用 `edu-module-course`
- **M4（班级）** 依赖 M1+M2，M5（排课）依赖 M4+M1
- **M6+M7（招生管理）** 前端合并展示；M6 报名关联 M3+M1 产生待收费记录，M7 消费报名记录完成收费+退费+赠课时，关联 M3 学员课时
- **M8（考勤）** 依赖 M4+M5+M3，签到和请假共享出勤数据
- **M9（教学管理）** 依赖 M3+M5+M8，三个子模块共用排课和班级上下文
- **M10（工作台）** 依赖 M5+M8+M7 的实时数据
- **M11（课件库）** 相对独立，仅引用 M1 的科目分类

## 4. 运营主管视角菜单结构

PC 管理端左侧菜单按使用频率分层：高频操作独立顶层直达，低频设置收进「基础管理」目录。

```
├── 📊 工作台                    ← 登录后默认首页
├── 📅 排课管理                  ← 高频：每天看课表、调课
├── 👦 学员管理                  ← 高频：随时查学员，行内操作含「课时记录」
├── 💰 招生管理                  ← 高频(招生季)：报名+收费+退费一条龙
│   ├── 报名录入
│   ├── 收费管理
│   ├── 退费处理
│   ├── 赠送课时
│   └── 财务对账
├── 📋 考勤管理                  ← 高频：每天签到、请假处理
├── 📦 基础管理  ← 目录(可折叠)   ← 低频：设置后很少变动
│   ├── 课程管理                  ← 科目内嵌弹窗 + 教室Tab切换
```

## 6. 关键业务规则

### 6.1 报名 → 收费 → 课时入账流程

```
运营主管录入报名（M6） → 选择学生 + 课程/班级 + 金额 + 经手人
  → 生成报名记录 + 待收费条目
  → 收银管理（M7）确认收费 → 选择支付方式
  → 自动为该学生增加对应课时（课时入账）
  → 可生成收据凭证
```

### 6.2 收费模式

- 所有收费为**线下完成**后录入系统，系统不接入支付通道
- 收费记录关联学生和课程，记录支付方式（现金/微信/支付宝/银行转账）
- 支持报名费、课时费、教材费等费用类型
- 收费确认后自动为学生增加对应课时（课时入账）

### 6.3 退费与赠送课时

**退费流程：**
- 运营主管发起退费申请 → 校长审批（金额超限时）
- 审批通过后：计算退款金额 → 扣回对应课时 → 生成退款记录
- 退费记录关联原收费记录，保证财务可追溯

**赠送课时：**
- 运营主管操作 → 选择学生 + 赠送课时数 + 赠送原因（促销/补偿/其他）
- 经手人记录，纳入课时变动明细
- 赠送课时与购买课时在明细中区分标注

### 6.4 请假与代课

- **学生请假**：家长(小程序)发起 → 教师确认 → 系统标记 + 通知双方
- **教师请假**：教师发起 → 管理员审批 → 系统列出冲突排课 → 逐节处理（代课/调课/停课）
- 代课：指派其他教师，通知代课教师 + 受影响家长
- 调课：选定新时间，通知家长
- 停课：标记「待补课」，后续单独安排

### 6.5 签到通知链路

```
教师到校给班级学生签到 → 系统记录签到时间 
  → 微信小程序订阅消息推送家长："您的孩子 xxx 已于 15:02 到校"
```

### 6.6 成绩隐私

- 家长端只可查看自己孩子的成绩和个人趋势曲线
- 可展示「班级平均分」作为对比参考线，不暴露其他学生姓名和具体分数

### 9.1 与旧项目的关系

本项目参考了 `edu_training_system` Demo 项目（Spring Boot 3 + Vue 3，31 张表，90 个 API），两者的主要差异：

| 维度 | 旧项目 | 新项目 |
|------|--------|--------|
| 模块数 | 10 个业务模块 | 11 个模块（含 M0 底座），按运营主管视角重构 |
| 系统底座 | 隐含在 auth 模块中 | M0 独立，用户-角色-权限-菜单完整 |
| 课程域 | 一个模块包含课程+教师+教室+班级 | M1课程(科目+课程+教室) + M2教师 + M4班级 |
| 收银域 | 收费记录+课时入账 | 拆为 M6报名管理 + M7收银管理(含退费+赠课时+对账) |
| 教学域 | 考勤+评价各自独立 | M8考勤 + M9教学管理(评价+成绩+作业合并) |
| 工作台 | 数据报表 P2 | M10工作台提升至P0，运营主管日常入口 |
| 校区 | campus_id 贯穿所有表 | 全部去掉 |
| 在线支付 | 有 stub | 全部去掉 |
| 安全 | JWT Filter，未集成 Spring Security | 标准 SecurityFilterChain + @PreAuthorize |
| 模块通信 | 跨模块直接调 Mapper | 通过 Service 接口通信 |
