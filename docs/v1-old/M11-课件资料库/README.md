# M11 课件资料库

> **模块定位**：数据与工具层（P2），MVP 后首批迭代。为教师和运营主管提供课件上传、分类浏览、共享管理的统一资源库。
> **优先级**：P2，MVP 之后的首批迭代
> **路由**：`/resource/library`
> **后端模块**：`edu-module-resource`
> **菜单位置**：左侧菜单「基础管理」目录 > 课件资料库

---

## 1. 模块概述

### 1.1 解决的问题

- 教师课件分散存储在个人电脑/微信聊天记录中，查找费时、版本混乱
- 优秀课件无法在教师之间共享复用，教学资源利用率低
- 缺乏统一的分类体系，课件随科目/年级/类型堆积杂乱
- 运营主管无法统筹管理全机构的教学资源

### 1.2 核心能力

```
教师/主管上传课件
    → 按科目 > 年级 > 类型三级分类归档
    → 设置共享范围（公开/私有）
    → 其他教师浏览、搜索、下载公开课件
    → 运营主管全量管理（含私有课件）
```

### 1.3 用户角色与权限

| 角色 | 上传课件 | 查看公开课件 | 查看私有课件 | 下载公开课件 | 下载私有课件 | 管理所有课件 |
|------|:--:|:--:|:--:|:--:|:--:|:--:|
| 校长 | 不可上传 | 可查看 | 可查看 | 可下载 | 可下载 | 不可上传不可删除 |
| 运营主管 | 可上传 | 可查看 | 可查看 | 可下载 | 可下载 | 可删除任意课件 |
| 教师 | 可上传 | 可查看 | 仅自己的 | 可下载 | 仅自己的 | 仅自己的 |
| 家长 | - | - | - | - | - | - |

### 3.2 左侧分类树

#### 3.2.1 树结构

三级分类体系，数据来源于科目管理（M1 课程管理中的科目体系）+ 系统预设的课件类型：

```
全部课件（根节点，默认选中）
├── 语文
│   ├── 一年级
│   │   ├── 课件文档
│   │   ├── 教学PPT
│   │   └── 练习资料
│   ├── 二年级
│   │   └── ...
│   └── ...
├── 数学
│   └── ...
└── 英语
    └── ...
```

#### 3.2.2 树节点定义

| 层级 | 数据来源 | 说明 |
|:--:|------|------|
| 第1级·科目 | `edu-module-course` 的科目表 | 所有启用状态的科目，无课件的科目也显示但灰色 |
| 第2级·年级 | 系统预设枚举 | 一年级~高三，仅显示该科目下有课件的年级 |
| 第3级·类型 | 系统预设枚举 | 课件文档 / 教学PPT / 练习资料 / 其他 |

#### 3.2.3 交互行为

| 操作 | 行为 |
|------|------|
| 点击根节点「全部课件」 | 清除分类筛选，加载全部课件 |
| 点击科目节点 | 筛选该科目下所有课件（不限年级和类型），右侧列表刷新 |
| 点击年级节点 | 筛选该科目+该年级的课件，右侧列表刷新 |
| 点击类型节点 | 筛选该科目+该年级+该类型的课件，右侧列表刷新 |
| 节点前图标 | 有子节点显示文件夹图标，无子节点显示文件图标 |
| 空科目 | 该科目下无任何课件时节点显示为灰色，可点击但右侧列表为空 |
| 加载状态 | 树首次加载时显示骨架屏（4条灰色横条），加载失败显示重试 |

#### 3.2.4 树节点数量展示

每个节点右侧显示该分类下的课件数量（如 `语文 (15)`），数量为 0 时不显示数字。

### 3.3 搜索与筛选

#### 3.3.1 搜索栏

| 字段 | 类型 | 默认值 | 说明 |
|------|------|------|------|
| 课件名称 | 文本输入 | 空 | 模糊匹配课件名称关键词，支持按 Enter 触发搜索 |

#### 3.3.2 筛选条件

| 字段 | 类型 | 默认值 | 选项来源 | 说明 |
|------|------|------|------|------|
| 科目 | 下拉单选 | 全部 | `GET /api/v1/course/subject/all`（仅启用状态） | 与分类树科目联动 |
| 年级 | 下拉单选 | 全部 | 系统预设：全部/一年级~高三 | 与分类树年级联动 |
| 类型 | 下拉单选 | 全部 | 系统预设：全部/课件文档/教学PPT/练习资料/其他 | 与分类树类型联动 |
| 上传人 | 下拉单选 | 全部 | `GET /api/v1/system/user/teachers` | 仅包含教师+运营主管 |
| 共享范围 | 下拉单选 | 全部 | 全部/公开/私有 | 教师仅能看到公开+自己的私有 |

#### 3.3.3 联动规则

- 分类树点击 → 自动同步更新筛选栏的科目/年级/类型下拉值
- 筛选栏下拉变更 → 自动同步高亮分类树对应节点
- 切换筛选条件时，列表回到第 1 页

#### 3.3.4 按钮

| 按钮 | 行为 |
|------|------|
| 搜索 | 重置到第 1 页 → 调用列表 API |
| 重置 | 清空搜索 + 重置筛选条件为"全部" + 取消分类树选中 → 重新加载 |

### 4.2 表单字段

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|------|------|:--:|------|------|
| 课件名称 | 文本输入 | ✅ | 1-50 字符，不含特殊字符 `<>"/\|?*` | |

| 年级 | 下拉单选 | ✅ | 一年级~高三 | |
| 类型 | 下拉单选 | ✅ | 课件文档 / 教学PPT / 练习资料 / 其他 | |
| 上传文件 | 文件上传 | ✅ | 见 §4.3 | 每次仅支持上传 1 个文件 |
| 共享范围 | 单选组 | ✅ | 公开 / 私有 | 默认选中「公开」 |

### 4.3 文件上传规则

#### 4.3.1 支持的文件格式

| 类别 | 扩展名 | MIME 类型 |
|------|------|------|
| PDF | `.pdf` | `application/pdf` |
| Word | `.doc`, `.docx` | `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| PPT | `.ppt`, `.pptx` | `application/vnd.ms-powerpoint`, `application/vnd.openxmlformats-officedocument.presentationml.presentation` |
| 图片 | `.jpg`, `.jpeg`, `.png` | `image/jpeg`, `image/png` |
| 压缩包 | `.zip`, `.rar` | `application/zip`, `application/x-rar-compressed` |

#### 4.3.2 大小限制

| 规则 | 数值 |
|------|:--:|
| 单个文件最大 | 50MB（后端同步校验） |
| 超出限制提示 | "文件大小不能超过 50MB，当前文件大小 {实际大小}"，红色 toast |

#### 4.3.3 交互行为

| 操作 | 行为 |
|------|------|
| 点击上传区域 | 打开系统文件选择器，仅显示支持的文件类型 |
| 拖拽文件 | 拖拽至区域时高亮边框，释放后自动填入 |
| 选择文件后 | 显示文件名 + 大小 + 格式图标 + 删除按钮（✕） |
| 重新选择 | 点击删除按钮移除当前文件，重新选择（覆盖旧文件，非追加） |
| 前端校验 | 选择文件后立即校验格式和大小，不通过则 toast 提示 + 不填入 |

### 4.4 上传流程

```
点击「确认上传」
  → 前端校验（名称、分类、文件、共享范围）
  → 校验通过 → 确认按钮 loading "上传中…"
  → 先上传文件：POST /api/v1/files/upload（multipart/form-data）
    → 获取文件URL
  → 再创建课件记录：POST /api/v1/resource/library（JSON body 含 fileUrl）
  → 成功 → toast "课件上传成功"
          → 关闭弹窗
          → 刷新列表
  → 失败 → 保留弹窗 + 错误提示
```

#### 4.4.1 上传进度

上传过程中显示进度条：

| 状态 | 表现 |
|------|------|
| 上传中 | 确认按钮 loading，按钮文字变为「上传中…」，禁用取消按钮 |
| 进度展示 | 弹窗底部显示进度条 + 百分比（基于文件实际上传进度） |
| 上传失败 | 进度条变红，显示"上传失败：{错误信息}"，「重试」按钮替代确认按钮 |
| 上传成功 | 进度条变绿 100% → 短暂显示"上传成功" → 关闭弹窗 |

### 4.5 上传状态处理

| 状态 | 表现 |
|------|------|
| 文件格式不支持 | 选择文件后立即 toast "不支持的文件格式，支持：PDF/Word/PPT/JPG/PNG/ZIP/RAR" |
| 文件过大 | 选择文件后立即 toast "文件大小不能超过 50MB，当前文件 {N}MB" |
| 文件未选择 | 点击确认时校验提示 "请选择上传文件" |
| 上传中网络中断 | 进度条停止 → toast "网络异常，上传中断，请重试" → 恢复确认按钮 |
| 上传中关闭弹窗 | 弹窗关闭按钮 disabled，不可关闭 |
| 并发上传 | 一次只能上传一个课件（一个文件），不支持批量上传 |
| 同名文件覆盖 | 系统端存储使用 UUID 重命名，不会覆盖 |

### 4.6 上传人记录

- 后端从 JWT token 中获取当前用户 ID，自动记录为上传人
- 上传人字段在前端表单中不展示、不可选

## 6. 共享范围规则

### 6.1 规则定义

| 共享范围 | 可见范围 | 可下载范围 |
|------|------|------|
| **公开** | 全体教师 + 运营主管 + 校长 | 全体教师 + 运营主管 + 校长 |
| **私有** | 仅上传者本人 + 运营主管 + 校长 | 仅上传者本人 + 运营主管 + 校长 |

### 6.2 规则详解

#### 6.2.1 教师视角

- 浏览列表时：看到所有「公开」课件 + 自己上传的「私有」课件
- 其他教师上传的「私有」课件不出现在列表中
- 搜索和筛选仅在有权查看的课件范围内执行
- 下载「公开」课件 → 下载次数 +1
- 下载自己的「私有」课件 → 下载次数 +1
- 编辑/删除：仅限自己上传的课件

#### 6.2.2 运营主管视角

- 浏览列表时：看到**所有**课件（含公开和私有）
- 共享范围筛选：包含「私有」选项，可专门筛选私有课件
- 可下载任意课件
- 可编辑任意课件的名称、分类、共享范围（不可修改文件本身）
- 可删除任意课件

#### 6.2.3 校长视角

- 浏览列表时：看到**所有**课件（含公开和私有）
- 可下载任意课件
- **不可上传**课件
- **不可编辑/删除**课件

#### 6.2.4 列表筛选中的共享范围选项

| 当前用户角色 | 共享范围下拉选项 |
|------|------|
| 教师 | 全部 / 公开 / 私有 |
| 运营主管/校长 | 全部 / 公开 / 私有 |

> 教师选择「私有」时，仅显示自己上传的私有课件。

### 6.3 共享范围变更

| 操作 | 行为 |
|------|------|
| 公开 → 私有 | 课件将对其他教师不可见；已记录的下载次数不清零 |
| 私有 → 公开 | 课件将对全体教师可见 |
| 变更人 | 仅上传者本人和运营主管可修改共享范围 |

## 7. 下载

### 7.1 下载流程

```
点击「下载」按钮
  → 权限校验（前端按钮级别 + 后端接口级别）
  → 记录下载日志（用户 + 课件 + 时间）
  → 下载次数 +1（异步更新，非强一致）
  → 浏览器触发文件下载（Content-Disposition: attachment）
```

### 7.2 下载规则

| 规则 | 说明 |
|------|------|
| 下载计数 | 每次下载请求（无论成功与否，后端接收到请求即计数） |
| 重复下载 | 不限制同一用户重复下载，每次均计次 |
| 并发下载 | 不限制 |
| 私有课件 | 仅上传者本人 + 运营主管可下载 |
| 下载记录 | 记录到下载日志表（用户ID + 课件ID + 下载时间 + IP） |

### 7.3 下载状态

| 状态 | 表现 |
|------|------|
| 下载触发 | 按钮 loading + 文字变为「下载中…」 |
| 下载成功 | 浏览器开始下载 → 按钮恢复 → 下载次数 +1 |
| 下载失败 | toast "下载失败，请重试" |
| 无权限下载 | toast "您没有权限下载此课件" |
| 文件不存在 | toast "课件文件不存在或已被删除" |

### 11.5 权限判断逻辑（后端伪代码）

```
// 查看权限
canView(resource, currentUser):
    if resource.isPublic → return true
    if currentUser.isAdmin() or currentUser.isSupervisor() → return true
    if resource.uploaderId == currentUser.id → return true
    return false

// 下载权限
canDownload(resource, currentUser):
    return canView(resource, currentUser)

// 编辑权限
canEdit(resource, currentUser):
    if resource.uploaderId == currentUser.id → return true
    if currentUser.isSupervisor() → return true
    return false

// 删除权限
canDelete(resource, currentUser):
    return canEdit(resource, currentUser)

// 上传权限
canUpload(currentUser):
    return currentUser.isTeacher() or currentUser.isSupervisor()
```

### 11.6 列表查询权限过滤（后端 SQL 层面）

```sql
-- 教师视角（isTeacher）
WHERE is_deleted = 0
  AND (is_public = 1 OR uploader_id = #{currentUserId})

-- 运营主管/校长视角（isSupervisor / isAdmin）
WHERE is_deleted = 0
```

## 12. 异常边界

### 12.1 前端异常

| 场景 | 处理 |
|------|------|
| 文件超过 50MB | 前端选择文件时立即校验拦截，toast 提示 |
| 不支持的格式 | 前端校验拦截，toast 提示 |
| 上传中关闭弹窗 | 上传过程中弹窗不可关闭（关闭按钮 + 取消按钮 + 遮罩层点击均 disabled） |
| 上传中断 | 进度条停止 → toast 提示 → 允许重试 |
| 表单未填完提交 | 字段标红 + 错误提示 |
| 名称包含非法字符 | 实时校验，输入时过滤或失焦时提示 |
| 搜索关键词过长 | 限制 50 字符 |
| 图片预览加载失败 | 显示裂图占位 + "图片加载失败，请下载后查看" |
| XSS 防护 | 课件名称等文本字段前端 `v-text` 渲染，不做 HTML 解析 |

### 12.2 后端异常

| 场景 | 处理 |
|------|------|
| 文件大小为 0 | 返回 400 "文件不能为空" |
| 文件超过 50MB | Spring multipart 配置 `max-file-size: 50MB`，超出返回 413 |
| 文件类型伪造（扩展名与 MIME 不匹配） | 后端校验 MIME 类型白名单 |
| 课件不存在 | 返回 404 "课件不存在" |
| 课件已删除 | 返回 404 "课件不存在或已被删除" |
| 无权限下载 | 返回 403 "您没有权限下载此课件" |
| 无权限编辑/删除 | 返回 403 "您没有权限执行此操作" |
| 科目不存在 | 创建/编辑时校验 `subjectId` 是否有效，无效则返回 400 |
| 文件上传失败 | 返回 500 "文件上传失败，请重试" |
| 并发下载计数 | 使用乐观锁或异步更新，避免计数竞争 |
| 文件存储服务不可用 | 返回 500 "文件服务暂不可用，请稍后重试" |
| 请求参数非法 | Spring Validation 统一校验，返回 400 + 具体字段错误信息 |

### 12.3 边界条件

| 边界 | 处理 |
|------|------|
| 课件名称为空字符串 | 前后端均校验必填 |
| 课件名称全是空格 | 前后端均 trim 后校验非空 |
| 科目被停用/删除 | 已有课件保留原科目名称（冗余存储），分类树中不展示已停用科目，但筛选下拉保留已停用科目选项（灰色标记"已停用"） |
| 用户被删除 | 已有课件的上传人显示为"已离职用户"或用户名（冗余存储） |
| 同一文件重复上传 | 允许，每次上传生成独立的课件记录（文件存储使用 UUID 重命名） |
| 下载计数溢出 | 使用 INT 类型（最大约 21 亿），常规场景不会溢出 |

## 13. 业务规则

### 13.1 通用规则

| 编号 | 规则 |
|:--:|------|
| R1 | 每次上传只能上传 1 个文件，不支持批量上传 |
| R2 | 课件上传后原始文件名保留，存储文件名使用 UUID 避免冲突 |
| R3 | 编辑课件不可更换文件，需更换时删除后重新上传 |
| R4 | 课件删除为逻辑删除，文件物理保留（便于误删恢复） |
| R5 | 下载计数异步更新，允许短时间内的微小偏差 |
| R6 | 教师的共享范围筛选「私有」仅返回自己上传的私有课件 |
| R7 | 运营主管可查看、下载、编辑、删除所有课件 |
| R8 | 校长可查看、下载所有课件，不可上传/编辑/删除 |

### 13.2 文件管理规则

| 编号 | 规则 |
|:--:|------|
| F1 | 文件存储路径：`resources/{yyyy-MM}/{uuid}.{ext}` |
| F2 | 文件上传使用统一的文件服务接口 `POST /api/v1/files/upload` |
| F3 | 不支持的文件类型在前后端双重校验拦截 |
| F4 | 上传失败时课件记录不回滚创建（先传文件再建记录的两步模式天然保证） |
