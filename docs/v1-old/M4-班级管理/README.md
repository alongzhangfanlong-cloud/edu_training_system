# M4 班级管理

> **模块定位**：核心教务层（P0），班级是整个教务体系的中枢枢纽，上承课程/教师/教室等基础资源，下接排课/报名/考勤/教学等业务流程。
> **后端模块**：`edu-module-class`
> **左侧菜单**：`基础管理 > 班级管理`
> **权限码前缀**：`class:`

---

## 1. 模块概述

### 1.1 模块价值

班级是教育机构日常运营的核心组织单元。本模块提供班级的创建、配置、学员管理和状态流转能力，作为排课、考勤、教学等下游模块的数据基础。

### 1.2 核心能力

- 创建班级并关联课程、教师、教室，设定最大人数和上课规则
- 管理班级内学员（添加/移除），实时追踪已报人数
- 人数达到上限自动锁定，超员行高亮预警
- 上课规则作为 M5 批量排课的默认参数，减少重复配置

| 关联模块 | 关系 | 说明 |
|----------|------|------|
| M1 课程管理 | 班级关联课程 | 选择课程后自动带出所属科目、课程类型（班课/一对一/小班）；教室下拉显示容量 |
| M2 教师管理 | 班级关联教师 | 教师下拉按课程所属科目过滤，仅显示可授该科目的教师 |
| M3 学员管理 | 班级包含学员 | 班级详情内嵌学员列表；学员通过班级维度进行管理 |
| M5 排课管理 | 上课规则作为排课默认参数 | 班级的「每周几 + 时间段 + 每节课时长」作为批量排课的默认值，减少手动填写 |
| M6 报名管理 | 报名时选择班级 | 报名录入时选择目标班级，报名成功后学员自动加入班级学员列表 |
| M8 考勤管理 | 按班级签到 | 教师对班级进行签到，签到名单来自班级学员列表 |
| M9 教学管理 | 按班级进行评价/成绩/作业 | 课堂评价、成绩录入、作业布置均以班级为操作单元 |

#### 3.4.3 超员预警

当 `currentCount > maxCount` 时，整行添加红色背景高亮（`#fef0f0` 或 Element Plus `--el-color-danger-light-9`），并在"已报/最大人数"列显示红色加粗的 `22/20 ⚠超员`。

超员行在表格置顶（排在正常行前面），并在表格上方显示黄色警告条："检测到 {N} 个班级人数超员，请及时处理。"

#### 3.4.4 二次确认文案

| 操作 | 弹窗文案 |

| 结课 | "确认将班级「{班级名称}」标记为**结课**？结课后该班级将不再参与排课，学员剩余课时不受影响。" |

## 4. 新增/编辑班级弹窗

### 4.1 触发

- 新增：列表页工具栏「+ 新增班级」
- 编辑：操作列「编辑」

### 4.2 弹窗规格

- 宽度：680px
- 标题：「新增班级」或「编辑班级」
- 高度：内容超出时内部滚动

### 4.3 表单字段

#### 4.3.1 基本信息

| 字段 | 类型 | 必填 | 新增时 | 编辑时 | 校验规则 |
|------|------|:--:|:--:|:--:|------|
| 班级名称 | 文本 | ✅ | 显示 | 显示 | 1-50 字符 |
| 班级编号 | 文本 | ❌ | 显示 | 显示 | 不填则自动生成（规则：`CLS` + 年月日 + 4位序号，如 `CLS202607130001`） |
| 关联课程 | 下拉单选 | ✅ | 显示 | 显示 | 调用 `GET /api/v1/course/all?status=UP` 加载已上架课程。选中后自动显示该课程所属科目和课程类型 |
| 课程科目 | 只读文本 | - | 自动显示 | 自动显示 | 选课后面课程名旁自动展示，灰色只读 |
| 课程类型 | 只读标签 | - | 自动显示 | 自动显示 | 选课后自动展示 `el-tag`：班课 / 一对一 / 小班 |
| 关联教师 | 下拉单选 | ✅ | 显示 | 显示 | 选课后按课程科目过滤可授该科目的在职教师；选课前显示全部在职教师并置灰提示 |
| 关联教室 | 下拉单选 | ❌ | 显示 | 显示 | 调用 `GET /api/v1/classroom/all` 加载可用教室，选项格式："教室名（容量：N人）" |
| 最大人数 | 数字输入 | ✅ | 显示 | 显示 | 正整数，1-999。课程类型为「一对一」时自动设为 1 且不可更改 |

#### 4.3.2 上课规则

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 每周上课日 | 多选按钮组 | ✅ | 周一 ~ 周日，多选，至少选一天 |
| 上课开始时间 | 时间选择器 | ✅ | HH:mm 格式，如 14:00 |
| 上课结束时间 | 时间选择器 | ✅ | HH:mm 格式，如 15:30，必须晚于开始时间 |
| 每节课时长 | 数字输入 | ✅ | 单位：分钟，正整数，常用值 30/45/60/90 以快捷按钮展示，也支持手动输入 |

```

│  上课规则                                                │
│                                                         │
│  每周上课日                                              │
│  [周一] [周二] [周三] [周四] [周五] [周六] [周日]          │
│   ■     ■     未选   未选   未选   未选   未选            │  ← 选中高亮
│                                                         │
│  上课时间段                                              │
│  [14:00]  ~  [15:30]                                    │
│                                                         │
│  每节课时长                                              │

- 每周上课日：使用 `el-checkbox-button` 或 `el-button` 分组，选中态主色填充
- 时间选择器：`el-time-select` 或 `el-time-picker`（仅时间，不含日期），步长 5 分钟
- 时长快捷按钮：点击自动填入对应值；自定义输入框默认值 45

### 4.4 联动逻辑

```
用户选择课程
  │
  ├── 1. 自动显示课程所属科目（只读文本）
  ├── 2. 自动显示课程类型标签（班课/一对一/小班）
  ├── 3. 课程类型=一对一 → 最大人数自动设为 1 + 禁用编辑
  ├── 4. 课程类型≠一对一 → 最大人数保持用户输入值（默认 20）
  └── 5. 教师下拉重新加载 → 过滤仅显示可授该科目的在职教师
       ├── 过滤后有结果 → 正常选择
       ├── 过滤后无结果 → 下拉显示空状态"暂无可授该科目的教师"+ 提示"请先在教师管理中为教师配置可授科目"
       └── 未选课程时 → 下拉显示全部教师，placeholder 提示"请先选择课程"
```

| 联动项 | 触发条件 | 行为 |
|--------|----------|------|
| 科目自动带出 | 选择课程 | 课程名后显示所属科目，灰色只读 |
| 课程类型标签 | 选择课程 | 显示班课/一对一/小班标签 |
| 最大人数锁定 | 课程类型=一对一 | 自动设为 1，输入框 disabled + 灰色底 |
| 教师过滤 | 选择课程 | 教师下拉仅显示可授该科目的在职教师 |
| 教师选项空 | 选择课程后无可授教师 | 显示空状态提示，引导去 M2 配置 |
| 教师重置 | 更换课程 | 清空已选教师，重新加载筛选后的教师列表 |
| 教室容量提示 | 始终 | 每个选项显示教室名称+容量，如"301 教室（容量：30人）" |

### 4.5 编辑时的特殊处理

| 场景 | 行为 |
|------|------|
| 班级已满（或超员） | 编辑时允许调大最大人数（≥ 当前已报人数），不允许调至小于当前已报人数 |
| 已结课的班级 | 编辑按钮仍然可用，但仅允许修改基本信息（名称、编号），课程/教师/教室/人数/上课规则不可修改（灰色只读 + 提示"已结课班级仅可修改基本信息"） |
| 更换课程 | 清空已选教师；已报人数 >0 时，弹窗确认"更换课程将清空已选教师，是否继续？" |
| 更换教师 | 直接更换，无额外限制 |

### 4.6 交互

| 操作 | 行为 |
|------|------|
| 打开（新增） | 空表单，默认最大人数 20，默认时长 45 分钟，无默认上课日 |
| 打开（编辑） | 调用 `GET /api/v1/class/{id}` → 填充表单（含上课规则回填） |
| 确认 | 前端校验 → 提交 API → 成功 → toast + 关闭弹窗 + 刷新列表 |
| 取消 | 有修改 → 确认"放弃修改？"；无修改 → 直接关闭 |
| 教师下拉焦点 | 如已选课程且无匹配教师，下拉展开时显示空状态提示 |

### 4.7 状态

| 状态 | 表现 |
|------|------|
| 加载中（编辑） | 弹窗内骨架屏（表单区域灰色条块） |
| 加载失败（编辑） | "加载班级信息失败"+「重试」按钮 |
| 课程列表加载中 | 课程下拉 loading |
| 教师列表加载中 | 教师下拉 loading（选课后触发） |
| 教室列表加载中 | 教室下拉 loading |
| 教师过滤后为空 | 下拉显示空状态插图 + 引导文案 |
| 提交中 | 确认按钮 loading，"保存中…" |
| 提交失败 | 保留弹窗 + 错误提示 |

### 4.8 对应 API

| 操作 | API |
|------|------|

## 6. 状态体系

### 6.1 班级状态

| 状态 | 英文 | 说明 | 触发条件 |
|------|------|------|----------|
| 招生中 | `ENROLLING` | 正常招生，可添加学员 | 新建班级默认状态 |
| 已满 | `FULL` | 人数已达上限，禁止添加学员 | 已报人数 ≥ 最大人数时自动变更 |
| 停招 | `SUSPENDED` | 暂停招生，不允许添加学员 | 手动操作（如寒暑假停班） |
| 结课 | `FINISHED` | 课程结束，班级归档 | 手动操作；有在讀学员时允许结课 |

### 6.2 状态流转

```
                    ┌──────────┐
         手动操作    │  招生中   │  人数达到上限（自动）
    ┌──────────────►│ ENROLLING ├──────────────────────┐
    │               └─────┬────┘                      │
    │                     │                           │
    │       手动操作       │  手动操作                  │
    │                     │                           ▼
    │               ┌─────▼────┐                ┌──────────┐
    │               │  停招    │                │   已满    │
    │               │SUSPENDED │                │   FULL   │
    │               └─────┬────┘                └────┬─────┘
    │                     │                         │
    │       手动操作       │    手动操作               │ 手动操作
    │                     │                         │
    │                     ▼                         ▼
    │               ┌──────────────────────────────────┐
    │               │            结课                   │
    └───────────────│          FINISHED                │
      手动操作       └──────────────────────────────────┘
```

规则：
- "招生中" ↔ "停招"：可双向手动切换
- "招生中" → "已满"：系统自动（添加学员后 `currentCount ≥ maxCount`）
- "已满" → "招生中"：系统自动（移除学员后 `currentCount < maxCount`），或手动调大最大人数后触发
- 所有状态 → "结课"：手动操作，终态，不可逆
- "结课"状态不可再变更到其他状态
- 超员（`currentCount > maxCount`）不是独立状态，而是异常标记；状态仍为"招生中"或"已满"

### 6.3 学员在班状态

学员在班级中的状态独立于学员全局状态（在讀/停课/结课/流失），此处沿用学员全局状态：

| 状态 | 说明 |
|------|------|
| 在讀 | 正常在班上课 |
| 停课 | 暂时停课（如请假休学），保留班级关联 |
| 结课 | 课程修完，留作历史记录 |

## 7. 业务规则

### 7.1 班级创建规则

| 编号 | 规则 | 说明 |
|:--:|------|------|
| R1 | 课程:班级 = 1:N | 一个课程下可创建多个班级（如书法1班、书法2班），班级名称在同一课程下建议不重复（软提示，不强制阻止） |
| R2 | 教师科目匹配 | 班级关联的教师必须可授该课程所属科目；选课时自动过滤教师下拉 |
| R3 | 教师唯一性 | 一个班级只能关联一位教师 |
| R4 | 一对一锁定 | 课程类型为"一对一"时，最大人数自动锁定为 1，不可修改 |
| R5 | 上课日必选 | 至少选择一个上课日（周一~周日），否则不可提交 |
| R6 | 时间合法性 | 上课结束时间必须晚于开始时间 |

### 7.2 学员管理规则

| 编号 | 规则 | 说明 |
|:--:|------|------|
| R7 | 人数上限 | 班级已报人数达到最大人数后，自动变为「已满」状态，禁止再添加学员 |
| R8 | 不重复添加 | 同一学员不可重复添加到同一班级（后端唯一约束 + 前端列表已过滤） |
| R9 | 移除不删档 | 移除学员仅解除关联，不删除学员档案，不自动退费/退课时 |
| R10 | 剩余课时警告 | 移除仍有剩余课时的学员时，必须弹窗警告确认 |
| R11 | 超员告警 | 如因数据迁移/手动调整等导致已报 > 最大，行高亮红色预警，但不影响正常业务操作 |

### 7.3 删除与结课规则

| 编号 | 规则 | 说明 |
|:--:|------|------|
| R12 | 有学员不可删除 | 班级下有在讀或停课状态的学员时，不可删除班级，仅可结课 |
| R13 | 无学员可删除 | 班级下学员列表为空，或全部学员已结课/已移除时，允许删除 |
| R14 | 结课不可逆 | 结课是终态，结课后不可重新激活 |
| R15 | 结课后限制 | 结课班级不可再添加学员、参与排课；编辑仅允许修改基本信息（名称、编号） |

### 7.4 与排课管理（M5）的协作规则

| 编号 | 规则 | 说明 |
|:--:|------|------|
| R16 | 上课规则作为默认值 | 批量排课时，班级的上课规则自动填充到排课表单（上课日、时间段、时长），用户可在此基础上调整 |
| R17 | 停招/结课班级不参与排课 | 停招和结课班级在排课下拉选项中过滤或置灰标注 |
| R18 | 班级变更不影响已有排课 | 修改班级的上课规则、教师、教室等，不影响已生成的排课记录；仅对未来新排课生效 |

## 8. 数据模型要点

### 8.1 核心表：`class_info`（班级信息表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `name` | VARCHAR(50) | 班级名称 |
| `code` | VARCHAR(32) | 班级编号，自动生成规则 `CLS` + yyyyMMdd + 4位序号，唯一索引 |
| `course_id` | BIGINT FK | 关联课程 ID → `course_info.id` |
| `teacher_id` | BIGINT FK | 关联教师 ID → `teacher_info.id` |
| `classroom_id` | BIGINT FK | 关联教室 ID → `classroom.id`（可为空） |
| `max_count` | INT | 最大人数，默认 20 |
| `current_count` | INT | 当前已报人数（冗余字段，添加/移除学员时同步更新） |
| `status` | VARCHAR(20) | 状态：ENROLLING / FULL / SUSPENDED / FINISHED |
| `create_time` | DATETIME | 创建时间 |
| `update_time` | DATETIME | 更新时间 |
| `create_by` | VARCHAR(64) | 创建人 |
| `update_by` | VARCHAR(64) | 更新人 |
| `is_deleted` | TINYINT | 逻辑删除（0-未删除，1-已删除） |

### 8.2 核心表：`class_schedule_rule`（班级上课规则表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `class_id` | BIGINT FK | 关联班级 ID → `class_info.id` |
| `week_days` | VARCHAR(20) | 上课日，逗号分隔：`1,3,5` 表示周一、周三、周五（1=周一，7=周日） |
| `start_time` | TIME | 上课开始时间，如 `14:00` |
| `end_time` | TIME | 上课结束时间，如 `15:30` |
| `duration` | INT | 每节课时长（分钟），如 45 |

> **关系**：`class_info` : `class_schedule_rule` = 1 : 1（一个班级仅一套上课规则）

### 8.3 核心表：`class_student`（班级学员关联表）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `class_id` | BIGINT FK | 关联班级 ID |
| `student_id` | BIGINT FK | 关联学员 ID → `student_info.id` |
| `enroll_time` | DATETIME | 报班时间 |
| `status` | VARCHAR(20) | 学员在班状态：STUDYING / PAUSED / FINISHED |
| `create_time` | DATETIME | 创建时间 |

> **唯一约束**：`UNIQUE (class_id, student_id)` 防止重复添加
> **索引**：`INDEX idx_class_id (class_id)`, `INDEX idx_student_id (student_id)`

### 8.4 ER 关系

```

## 10. 异常边界

### 10.1 前端异常处理

| 场景 | 表现 |
|------|------|
| 网络超时/断网 | 统一 toast "网络异常，请检查网络后重试"，保留当前页面状态 |
| 接口 401（未登录） | 全局拦截 → 跳转 `/login` |
| 接口 403（无权限） | toast "您没有权限执行此操作"，不关闭弹窗 |
| 接口 404（资源不存在） | 班级详情页显示 404 提示；弹窗内 toast 错误信息 |
| 接口 409（冲突） | toast "添加失败：该学员已在班级中" 或 "学员已存在" |
| 接口 422（业务规则冲突） | toast 后端返回的具体错误信息，如"班级已满，无法添加学员" |
| 接口 500（服务器错误） | toast "服务器异常，请稍后重试" |

### 10.2 后端异常处理

| 场景 | HTTP 状态码 | 说明 |
|------|:--:|------|
| 班级不存在 | 404 | `DELETE/PUT/GET` 操作的目标资源不存在 |
| 删除有学员的班级 | 422 | 返回 `"班级下有 {N} 名在讀学员，不可删除"` |
| 添加学员时班级已满 | 422 | 返回 `"班级已满（{maxCount}人），无法添加学员"` |
| 重复添加学员 | 409 | 返回 `"学员 {姓名} 已在该班级中"` |
| 教师不匹配 | 422 | 返回 `"教师 {姓名} 不可授该课程所属科目 {科目名}"` |
| 最大人数小于当前人数 | 422 | 编辑时，返回 `"最大人数不可小于当前已报人数 {N}"` |
| 一对一人数修改 | 422 | 返回 `"一对一课程最大人数固定为 1，不可修改"` |
| 同时编辑冲突 | 409 | 使用乐观锁（`update_time` 版本号），返回"数据已被他人修改，请刷新后重试" |

### 10.3 并发场景

| 场景 | 处理策略 |
|------|----------|
| 多人同时添加学员到同一班级 | 后端使用数据库行锁（`SELECT ... FOR UPDATE`）扣减容量，先到先得；后到达的请求若班级已满则返回 422 |
| 多人同时移除学员 | 允许并发，后操作的请求若学员已被移除则返回 404 |
| 多人同时编辑班级 | 乐观锁（`update_time` 版本比较），冲突时提示用户刷新 |
| 添加学员与编辑最大人数同时发生 | 数据库约束保证一致性，最大人数修改与学员添加互斥 |

### 10.4 边界值

| 字段 | 最小值 | 最大值 | 说明 |
|------|:--:|:--:|------|
| 班级名称 | 1 字符 | 50 字符 | |
| 班级编号 | - | 32 字符 | 自动生成格式 `CLS` + yyyyMMdd + 4位序号 |
| 最大人数 | 1 | 999 | 一对一课程固定为 1 |
| 已报人数 | 0 | 无上限（允许超员） | 达到上限后禁止再添加 |
| 上课日 | 至少 1 天 | 最多 7 天 | 周一~周日 |
| 上课开始时间 | 00:00 | 23:55 | 步长 5 分钟 |
| 上课结束时间 | 00:05 | 23:59 | 必须晚于开始时间 |
| 每节课时长 | 1 分钟 | 480 分钟（8小时） | 常用值 30/45/60/90 |

### 10.5 数据一致性保障

| 保障项 | 机制 |
|------|------|
| `current_count` 与实际学员数一致 | 添加/移除学员时在事务内更新 `current_count`；定期任务校验不一致数据并告警 |
| 状态与人数一致 | 添加学员后 `currentCount ≥ maxCount` 自动触发 `status = FULL`；移除学员后 `currentCount < maxCount` 自动触发 `status = ENROLLING`（非手动停招/结课时） |
| 唯一约束 | `class_student` 表 `(class_id, student_id)` 联合唯一索引 |
| 教师-科目匹配 | 添加/编辑班级时后端校验 `teacher.subjectIds` 包含 `course.subjectId` |
