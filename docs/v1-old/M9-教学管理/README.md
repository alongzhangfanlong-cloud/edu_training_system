# M9 教学管理

> **模块定位**：教学互动层（P1），整合课堂评价、成绩管理、作业管理三个子模块，为教师提供课后一站式操作入口。
> **优先级**：P1（MVP 应包含，家校互通的核心价值）
> **后端包**：`edu-module-teaching`
> **PC 端路由**：`/teaching`

---

## 1. 模块概述

### 1.1 三个子模块的整体定位

| 子模块 | 定位 | 核心用户 | 核心价值 |
|--------|------|---------|---------|
| **课堂评价** | 每节课后教师对课堂整体和学生个人的表现评价 | 教师录入，家长查看 | 家长了解孩子课堂表现，建立教学透明度 |
| **成绩管理** | 考试成绩的录入、管理与分析 | 教师录入，家长查看 | 家长跟踪孩子学业进步，教师掌握班级整体情况 |
| **作业管理** | 课后作业的布置与查看 | 教师布置，家长查看 | 家长明确作业内容，降低沟通成本 |

三个子模块在 PC 端通过 **Tab 切换**（评价 / 成绩 / 作业）整合为「教学管理」一个菜单页面，小程序教师端在「教学 Tab」下通过子导航切换。

### 1.2 业务闭环

```
教师上课 → 课后评价（课堂总结 + 学生打分） → 布置作业 → 下次考试录入成绩
  │               │                              │
  │               ▼                              ▼
  │         家长查看评价            家长查看作业 + 成绩趋势
  └──────────────── 形成教学反馈闭环 ────────────────┘
```

### 1.3 与其他模块的关联

| 关联模块 | 关联方式 | 说明 |
|---------|---------|------|
| **M5 排课管理** | 评价/作业关联排课记录 | 评价基于上课记录，作业可关联排课或班级 |
| **M4 班级管理** | 成绩/作业关联班级 | 成绩按班级录入，作业可布置到班级 |
| **M3 学员管理** | 评价/成绩关联学生 | 评价是对班级内每个学生的，成绩是每个学生的 |

#### 3.1.2 列表字段

| 字段 | 说明 | 宽度 |
|------|------|------|
| 上课日期 | 关联排课记录的日期，格式 yyyy-MM-dd | 120px |
| 上课时间 | 排课时段，如"14:00-16:00" | 120px |
| 课程名称 | 关联课程名称 | 150px |
| 班级名称 | 关联班级名称 | 150px |

| 最后更新时间 | yyyy-MM-dd HH:mm | 160px |
| 操作 | 见下方"操作按钮" | 160px |

#### 3.1.3 操作按钮

| 状态 | 主按钮 | 说明 |
|------|--------|------|
| 待评 | 「评价」 | 进入评价表单页（新建） |
| 草稿 | 「继续编辑」 | 进入评价表单页（加载已有草稿） |
| 已评 | 「查看」 | 进入评价详情页（只读） |

辅助操作（所有记录）：删除按钮（仅教师本人且评价为草稿/待评时可删，已评不可删）。

#### 3.1.4 排序规则

- 按上课日期倒序排列（最近的排课在最上面）
- 同一天的多条排课按时间早晚排序

#### 3.1.5 数据来源

评价记录不预先创建。列表数据来源为**该教师关联的已上课的排课记录**（即 M5 排课管理中的记录），仅展示已完成上课的排课。系统按排课记录查询是否有对应的评价记录，有则展示评价状态，无则展示「待评」。

即：是否生成列表行的判断依据是排课记录（该教师已上课的），而非评价表。

#### 3.2.2 排课信息区域

只读信息卡，从排课记录自动带入：

| 字段 | 来源 |
|------|------|
| 上课日期 | M5 排课记录 `schedule_date` |
| 课程名称 | M1 课程 `name` |
| 班级名称 | M4 班级 `name` |
| 上课时段 | 开始时间 + 结束时间 |
| 教师名称 | 排课记录的教师（当前登录教师） |

#### 3.2.3 课堂总结

| 属性 | 说明 |
|------|------|
| 字段类型 | Textarea（多行文本），最小 30 字，最大 2000 字 |
| 是否必填 | 是（提交时校验，草稿可不填） |
| 提示文案 | "请总结本次课堂的教学内容完成情况、学生整体表现、课堂氛围等" |
| 字数统计 | 右下角实时显示当前字数 / 2000 |

#### 3.2.4 学生个人评价列表

每条学生评价行包含：

| 字段 | 说明 |
|------|------|
| 学生姓名 | 从班级学员列表获取，只读 |
| 星级评分 | 1-5 星，点击打星组件，必填 |
| 文字评语 | Textarea，最长 500 字，选填（可跳过） |
| 头像 | 学生头像（如有），32×32 圆形 |

交互规则：

- 学生列表按姓名拼音排序
- 每个学生独立评分，互不影响
- 星级评分使用 Element Plus 的 `el-rate` 组件，允许半星（0.5 步进）
- 未打星的学生提交时高亮提示，阻止提交
- 文字评语为选填，不填不阻塞提交
- 页面较长时（超过 10 个学生）出现"回顶部"悬浮按钮

### 3.3 暂存草稿

| 属性 | 说明 |
|------|------|
| 触发 | 评价表单页点击「暂存草稿」按钮 |
| 行为 | 保存当前填写内容，不校验必填字段 |
| 状态 | 该排课记录评价状态变为「草稿」 |
| 后续 | 列表页该记录显示「继续编辑」按钮，点击重新进入表单页加载已有内容 |
| 草稿有效期 | 无限制，永久保留直到提交或删除 |
| 草稿覆盖 | 同一排课记录只能有一份草稿，再次暂存覆盖之前草稿 |
| 排课已取消 | 关联排课被取消后，草稿自动标记为无效（不可继续编辑，仅可查看历史内容） |

### 3.4 评价详情页（查看已评）

- 与表单页布局相同，所有字段为**只读**
- 顶部标注评价时间（首次提交时间）
- 不可编辑，不可删除（已评状态）
- 页面底部展示"返回列表"按钮

### 3.5 评价历史

教师可通过列表页的筛选条件查看自己过去的评价记录。评价历史没有独立的"时间线"页面，**统一在评价列表中通过筛选条件（日期范围）实现**。

具体表现：
- 评价列表本身就按日期倒序排列
- 通过日期范围选择器筛选历史月份/学期的评价
- 已评记录可点击「查看」回顾详情

校长和运营主管：具有查看所有教师评价记录的权限（不限于自己授课），用于教学质量监控。在列表页数据范围不同（教师只看到自己的，校长/主管看到所有）。

### 4.2 成绩录入页

#### 4.2.1 录入流程

步骤：**选择考试信息 → 批量填写分数 → 提交**

不设"单个录入"模式，统一使用批量表格形式。

#### 4.2.2 考试信息区域

```
┌─────────────────────────────────────────────────────────┐
│  考试信息                                                │
│  ┌──────────┬──────────┬──────────┬──────────┐         │
│  │ 班级*     │ 科目*     │ 考试类型*  │ 考试日期* │         │
│  │ [下拉选择]│ [下拉选择]│ [下拉选择]│ [日期选择]│         │
│  ├──────────┴──────────┴──────────┴──────────┤         │
│  │ 满分*      │ 考试名称(自定义时)              │         │
│  │ [输入框]   │ [输入框，仅自定义类型时显示]      │         │
│  └──────────────────────────────────────────┘         │
└─────────────────────────────────────────────────────────┘
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 班级 | 下拉（远程搜索） | ✅ | 选择班级后自动加载该班级学生名单 |
| 科目 | 下拉 | ✅ | 选择考试科目 |
| 考试类型 | 下拉 | ✅ | 月考 / 期中 / 期末 / 随堂测验 / 自定义 |
| 考试日期 | 日期选择器 | ✅ | 默认为当天，不能选择未来日期 |
| 满分 | 数字输入 | ✅ | 1-999，默认 100 |
| 自定义考试名称 | 输入框 | 条件必填 | 仅考试类型选择「自定义」时显示和必填，最长 50 字 |

约束：

- **同一班级 + 同一科目 + 同一考试类型 + 同一日期** 不能重复录入（唯一约束）
- 选择班级后，科目下拉选项自动限定为该班级关联的课程科目
- 如果班级没有学生，提示"该班级尚无学生，请先在班级管理中添加学生"并阻止进入下一步

#### 4.2.3 成绩表格

```
┌─────────────────────────────────────────────────────────┐
│  成绩录入                                                │
│  ┌──────┬──────┬──────────────┬──────┐                 │

│  │  3   │ 王五  │ [  缺考 ]     │ [   ]│                 │
│  │  4   │ 赵六  │ [  78  ]     │ [   ]│                 │
│  └──────┴──────┴──────────────┴──────┘                 │

│  已填 3 / 共 4 人                           [提交成绩]    │

```

| 字段 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 学生姓名 | 从班级学员列表传入，只读 |
| 分数 | 数字输入框，范围 0 - 满分，支持一位小数 |
| 缺考标记 | 复选框，勾选后分数输入框置灰不可填写，分数记为 null |
| 备注 | 选填，最长 100 字 |

交互规则：

- 学生按姓名拼音排序
- 学生名单从选择班级后自动加载，如果有变动提示刷新
- 已填人数实时计算（勾选缺考也计入已填）
- 分数输入框校验：数字、0-满分范围、最高 1 位小数
- 提交按钮：所有学生均需填写分数或勾选缺考后才可提交；有未填写的学生 → 红色提示"X 名学生尚未填写分数"，提交按钮置灰
- 提交成功后返回成绩列表页并刷新

#### 4.2.4 编辑成绩

- 从列表页「编辑」进入，加载已有成绩数据
- 考试信息（班级、科目、考试类型、日期、满分）不可修改
- 仅可修改各学生的分数、缺考标记、备注
- 编辑后保存 → 覆盖原有成绩数据

#### 7.2.3 成绩隐私保护规则（核心规则）

这是本模块最重要的业务规则之一，必须严格执行：

| 规则 | 说明 |
|------|------|
| **个人成绩可见** | 家长可以查看自己孩子的所有成绩 |
| **自身排名可见** | 家长可以看到自己孩子的排名（第 X 名） |
| **班级平均分可见** | 家长可以看到班级平均分作为对比参考线 |
| **班级最高/最低分不可见** | 不暴露班级最佳和最差分数 |
| **其他学生姓名不可见** | 不暴露任何其他学生的姓名或身份 |
| **其他学生分数不可见** | 不暴露任何其他学生的具体分数 |
| **他人排名不可见** | 家长不知道其他学生的排名位置 |
| **成绩趋势图仅含均值对比** | 折线图只能展示「个人成绩」+「班级平均分」两条线 |

**后端实现要求**：
- 成绩趋势 API 返回个人成绩列表 + 每次考试对应的班级平均分
- 排名字段仅在查询自己孩子时返回
- 禁止通过修改参数越权查看其他学生的成绩
- 接口层面需要通过家长用户 ID 关联学生 ID，而不是通过前端传入学生 ID

## 8. 状态处理

### 8.1 评价状态

| 状态 | 含义 | 列表标识 | 教师操作 | 家长端 |
|------|------|---------|---------|--------|
| 待评 | 已上课但教师尚未填写评价 | 灰色"待评" | 点击「评价」进入表单 | 不可见 |
| 草稿 | 教师已开始填写但未提交 | 橙色"草稿" | 点击「继续编辑」 | 不可见 |
| 已评 | 教师已完成并提交评价 | 绿色"已评" | 点击「查看」（只读） | 可见 |

### 8.2 成绩状态

| 场景 | 处理 |
|------|------|
| 学生缺考 | 勾选「缺考」标记，分数记为 null，统计时排除 |
| 班级无学生 | 录入页显示提示"该班级尚无学生"，阻止进入录入 |
| 成绩被删除 | 该次考试的所有学生分数归档，逻辑删除后不可见 |

## 9. 业务规则汇总

### 9.1 课堂评价规则

| 编号 | 规则 |
|:--:|------|
| E01 | 评价基于已完成上课的排课记录，由系统根据排课日期自动判断是否"已上课"（排课日期 ≤ 当天） |
| E02 | 每个排课记录只能有一份评价（同一排课记录不可重复评价） |
| E03 | 评价只能由该排课记录的授课教师填写（通过排课记录的教师 ID 校验） |
| E04 | 提交评价时所有学生的星级评分为必填，文字评语选填 |
| E05 | 草稿不校验必填字段，可随时保存 |
| E06 | 已提交的评价不可编辑、不可删除 |
| E07 | 家长只能看到自己孩子的个人评价，看不到课堂总结和其他学生的评价 |
| E08 | 校长/运营主管可查看所有教师的评价记录（用于教学质量监督） |

### 9.2 成绩管理规则

| 编号 | 规则 |
|:--:|------|
| G01 | 同一班级+科目+考试类型+日期 四字段组合唯一 |
| G02 | 考试日期不能为未来日期 |
| G03 | 分数范围 0 - 满分（含边界），支持一位小数 |
| G04 | 缺考学生分数为 null，不纳入平均分/排名/分布统计 |
| G05 | 及格线 = 满分 × 60%（向下取整） |
| G06 | 排名按分数降序，同分同名次（如 2 人并列第 2，则下一名为第 4） |
| G07 | 家长只能查看自己孩子的成绩、排名和班级平均分，不可见其他学生的任何信息 |
| G08 | 成绩被删除后，家长端不可见，历史趋势图相应数据点移除 |
| G09 | 只有授课教师可以录入和编辑成绩 |

### 9.3 作业管理规则

| 编号 | 规则 |
|:--:|------|
| H01 | 作业可以关联排课记录（表示某次课的作业）或直接关联班级（表示班级日常作业） |
| H02 | 关联排课记录时，可选排课自动限定为该班级+该课程下的已完成排课 |
| H03 | 作业由教师发布后家长端可见 |
| H04 | 教师可编辑已发布作业，编辑后家长端显示"已更新"标识 |
| H05 | 教师可删除自己发布的作业（逻辑删除） |
| H06 | 图片附件：jpg/png/gif/webp，单张 ≤ 10MB，单次最多 9 张 |
| H07 | 文件附件：pdf/doc/docx/xls/xlsx/ppt/pptx，单个 ≤ 20MB，单次最多 5 个 |
| H08 | 关联的排课被取消后，作业保留，关联字段置 null |
| H09 | 作业发布时，系统向关联班级所有学生家长推送订阅消息（已订阅"作业通知"的） |

## 12. 异常边界

### 12.1 数据异常

| 异常场景 | 处理策略 |
|---------|---------|
| 排课被删除 | 关联评价不可编辑，仅可查看历史内容；关联作业保留但 schedule_id 置 null，标注"关联排课已取消" |
| 班级被删除 | 关联成绩/作业/评价保留，但 class_id 关联的数据在筛选时显示"已删除"标识 |
| 学生从班级移除 | 历史评价和成绩记录保留，但该学生的新排课记录中不再出现在评价名单中 |
| 学生被删除 | 历史评价/成绩记录保留，姓名字段展示"已删除学生"，成绩不参与统计 |
| 教师被删除/离职 | 历史评价/成绩/作业记录保留，教师姓名展示为"已离职教师" |
| 课程被删除 | 关联数据保留，课程名称展示为"已删除课程" |

### 12.2 并发异常

| 异常场景 | 处理策略 |
|---------|---------|
| 同一排课被多次提交评价 | 数据库唯一约束 + 接口乐观锁（版本号或 update_time 比较） |
| 同一考试被重复录入 | 数据库唯一约束 + 前端禁用重复提交按钮 |
| 多个教师同时编辑同一作业 | 接口乐观锁，后者提交时提示"数据已被修改，请刷新后重试" |
| 家长同时查看导致查看次数溢出 | `view_count` 使用 `update edu_parent_view_log set view_count = view_count + 1` 原子更新 |

### 12.3 边界条件

| 边界条件 | 处理策略 |
|---------|---------|
| 班级无学生时录入成绩 | 前端提示"该班级尚无学生"，阻止进入录入页 |
| 满分设为 0 | 前端校验，满分必须 ≥ 1 |
| 分数超过满分 | 前端校验阻止，后端二次校验返回错误 |
| 所有学生缺考 | 允许提交，平均分/排名/分布显示"无有效数据" |
| 学生评语超过字数限制 | 前端实时计数 + 阻止输入；后端截断（安全措施） |
| 批量上传超过限制数量 | 前端阻止选择，后端校验返回错误"附件数量超限" |
| 文件大小超过限制 | 前端上传前检查，后端 MultipartFile 校验 |
| 同一家长多个孩子 | 动态时间线混合展示，每条标注所属孩子 |
| 家长未绑定手机号 | 无法关联学生 → 动态 Tab 显示空状态"暂无数据" |

### 12.4 推送异常

| 异常场景 | 处理策略 |
|---------|---------|
| 微信订阅消息推送失败 | 不影响评价/作业/成绩的提交成功，静默忽略推送失败 |
| 家长关闭订阅通知 | 数据正常产生，仅不推送；家长可在小程序动态 Tab 手动查看 |
| 微信接口限流 | 加入消息队列缓冲（P1 迭代），MVP 阶段失败降级（仅记录日志） |
