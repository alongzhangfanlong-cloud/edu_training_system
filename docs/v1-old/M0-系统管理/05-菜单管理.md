# 05 · 菜单管理

> 路由：`/system/menu`
> 权限码：`system:menu:list`
> 对应 API 模块：menu

---

## 1. 页面结构

菜单是树形结构，不使用分页表格。使用 `el-table` 的 `row-key` + `tree-props` 实现树形展开。

│  面包屑：系统管理 > 菜单管理                            │
├──────────────────────────────────────────────────────┤
│  工具栏：                                              │
│  [+ 新增] [展开全部] [折叠全部]                         │
├──────────────────────────────────────────────────────┤
│  树形表格                                              │
│  ┌────────┬──┬──┬────────┬──────┬──┬──┬────┐        │
│  │菜单名称│图│排│权限标识│组件路│状│类│操作│          │
│  │        │标│序│        │  径  │态│型│    │          │

## 2. 工具栏

| 按钮 | 权限码 | 说明 |
|------|--------|------|
| + 新增 | `system:menu:add` | 打开新增弹窗（默认上级菜单为"主目录"） |
| 展开全部 | — | 展开所有树节点 |
| 折叠全部 | — | 折叠所有树节点，仅显示根级 |

---

## 3. 树形表格

### 3.1 列定义

| 列 | 说明 |
|------|------|
| 菜单名称 | 树形展示，缩进层级。类型图标：📁 目录 / 📄 菜单 / ● 按钮 |
| 图标 | 预览 Element Plus 图标（如 `HomeFilled`），30×30 居中 |
| 排序 | 中心对齐，数字 |
| 权限标识 | `system:user:list` 等，按钮类型显示，其他为空；`<code>` 样式 |
| 组件路径 | 菜单类型显示，如 `system/user/index`；目录和按钮为空 |
| 状态 | 绿色「显示」/ 灰色「隐藏」 |
| 类型 | 标签：目录(蓝) / 菜单(绿) / 按钮(灰) |
| 操作 | 按钮组（见 3.2） |

### 3.2 操作列按钮

| 按钮 | 权限码 | 显示条件 |
|------|--------|------|
| 编辑 | `system:menu:edit` | 所有行 |
| 新增子级 | `system:menu:add` | 目录和菜单行（按钮行不显示——按钮不能有子级） |
| 删除 | `system:menu:delete` | 所有行 |

### 3.3 保护规则

| 规则 | 说明 |
|------|------|
| 删除级联 | 删除父节点 → 二次确认："将同时删除其下所有子菜单（共 {N} 个），确认？" → 后端级联删除 + 清除 role-menu 关联 |
| 按钮不能有子级 | 「新增子级」按钮在 type=F 的行上隐藏 |
| 目录不能添加按钮子级 | 前端不限制（后端可拒绝） |

## 4. 新增/编辑弹窗

### 4.1 弹窗规格

- 宽度：600px
- 标题：「新增菜单」或「编辑菜单」

### 4.2 动态表单（根据菜单类型切换）

新增时可切换类型，编辑时类型锁定（创建时即固定）。

| 字段 | 目录(M) | 菜单(C) | 按钮(F) | 说明 |
|------|:--:|:--:|:--:|------|
| 上级菜单 | ✅ | ✅ | ✅ | `el-tree-select`，根节点为「主目录」（id=0） |
| 菜单类型 | ✅ | ✅ | ✅ | 三个 radio 按钮：目录 / 菜单 / 按钮。编辑时禁用 |
| 菜单名称 | ✅ | ✅ | ✅ | 显示在菜单和管理页上的文字 |
| 图标 | ✅ | ❌ | ❌ | 图标选择器，弹出 \src\assets\svgfont\icons.js中 图标面板，可搜索 |
| 路由地址 | ✅ | ✅ | ❌ | 目录：如 `system`；菜单：如 `user` |
| 组件路径 | ❌ | ✅ | ❌ | 如 `system/user/index` |
| 权限标识 | ❌ | ❌ | ✅ | 如 `system:user:list` |
| 显示状态 | ✅ | ✅ | ❌ | 开关，默认开启。关闭 = 菜单不显示但权限仍生效 |
| 是否缓存 | ❌ | ✅ | ❌ | 开关，`keep-alive` |
| 是否外链 | ❌ | ✅ | ❌ | 开关 |
| 排序 | ✅ | ✅ | ✅ | 数字输入，默认 0，同层兄弟间排序 |

### 4.3 图标选择器

- 弹出面板，展示 弹出 \src\assets\svgfont\icons.js中 全部图标
- 顶部搜索框：输入关键字过滤图标
- 当前选中图标蓝色高亮
- 点击图标 → 选中 + 关闭面板 → 回填图标名称到表单

### 4.4 状态

| 状态 | 表现 |
|------|------|
| 打开（新增） | 空表单，默认类型=菜单，默认上级=主目录 |
| 打开（编辑） | 调用 `GET /api/v1/system/menu/{id}` → 填充表单，类型锁定 |
| 类型切换 | 动态显示/隐藏对应字段，已填内容不清除 |
| 提交中 | 确认按钮 loading |
| 提交失败 | 保留弹窗 + 错误提示 |

### 4.5 对应 API

| 操作 | API |
|------|------|
| 新增 | `POST /api/v1/system/menu` |
| 编辑 | `PUT /api/v1/system/menu/{id}` |
| 详情 | `GET /api/v1/system/menu/{id}` |
| 菜单树 | `GET /api/v1/system/menu/tree` |
| 删除 | `DELETE /api/v1/system/menu/{id}` |

---

## 5. 空状态与异常

| 状态 | 表现 |
|------|------|
| 菜单树为空 | 表格显示空状态："暂无菜单数据，点击「新增」创建根级菜单" |
| 加载中 | 树形表格骨架屏（每行灰条 + 折叠箭头占位） |
| 加载失败 | "菜单数据加载失败"+「重试」 |
