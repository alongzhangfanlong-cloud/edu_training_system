# 01 · 登录认证

> 覆盖 PC 端账号密码登录。小程序端微信静默登录见 `docs/prd/小程序功能设计.md` §2
> 权限码：无（公共接口）

---

## 1. PC 端登录页

**路由**：`/login`

### 1.1 页面布局

居中卡片式。左侧机构 Logo + 名称，右侧登录表单。

```
┌─────────────────────────────────────────┐
│                                         │
│   ┌───────────────────────────────┐     │
│   │  Logo                        │     │
│   │  新艺智源管理平台              │     │
│   │                              │     │
│   │  * 账号    [______________]  │     │
│   │  * 密码    [______________]  │     │
│   │  验证码    [____] [图片]      │     │
│   │  [ ] 记住我                   │     │
│   │  [      登 录      ]          │     │
│   └───────────────────────────────┘     │
└─────────────────────────────────────────┘
```

### 1.2 元素规格

| 元素 | 类型 | 说明 |
|------|------|------|
| 账号 | 文本输入 | placeholder:"请输入手机号/姓名/用户名"，支持手机号、姓名、用户名任一方式登录 |
| 密码 | 密码输入 | placeholder:"请输入密码"，支持 Enter 提交 |
| 验证码 | 文本 + 图片 | 4位图片验证码，点击图片刷新；**MVP 阶段后端未实现，前端预留位置隐藏即可** |
| 记住我 | checkbox | 勾选 → token 存 localStorage；不勾选 → sessionStorage |
| 登录按钮 | 按钮 | 宽度与输入框一致，loading 态显示"登录中…" |

### 1.3 交互

**提交流程**：
1. 前端校验：账号非空 + 密码非空
2. 调用 `POST /api/v1/auth/login`，传 `{ account, password }`，后端按手机号 → 姓名 → 用户名优先级匹配
3. 成功 → 存 token → 跳转 `/dashboard`（或跳回 `redirect` 参数目标页）
4. 失败 → 密码框清空 + 验证码刷新 + 显示错误信息

**错误信息映射**：

| 后端返回 | 前端提示 |
|------|------|
| 401 账号或密码错误 | "账号或密码错误" |
| 401 账号已停用 | "账号已被停用，请联系管理员" |
| 其他 | "登录失败，请重试" |

### 1.4 状态处理

| 状态 | 表现 |
|------|------|
| 正常 | 显示登录表单 |
| 提交中 | 按钮 loading，"登录中…"，输入框禁用 |
| 失败 | 密码清空，红色错误提示在密码框下方 |
| 未登录访问 | 路由守卫 → 自动跳转 `/login`，登录后到首页 |
| Token 过期 | 接口返回 401 → 清除 token → 跳转 `/login` + 提示"登录已过期，请重新登录" |
| 已登录访问 | 路由守卫 → 直接跳转 `/dashboard` |

### 1.5 对应 API

| 接口 | 说明 |
|------|------|
| `POST /api/v1/auth/login` | 登录，入参 `{ account, password }`（account 支持手机号/姓名/用户名），返回 `{ accessToken, refreshToken, userId, username, realName, avatar, permissions, roles }` |
