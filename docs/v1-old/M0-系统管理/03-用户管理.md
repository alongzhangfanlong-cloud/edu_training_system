## 2. 搜索栏

### 2.1 字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|------|------|
| 关键词 | 文本输入 | 空 | 模糊匹配用户名 / 姓名 / 手机号 |
| 角色 | 下拉单选 | 全部 | 调用 `GET /api/v1/system/role/all` 加载选项，全部 / 各角色名 |
| 状态 | 下拉单选 | 全部 | 全部 / 正常(`0`) / 停用(`1`) |

### 2.2 按钮

| 按钮 | 行为 |
|------|------|
| 搜索 | 重置到第 1 页 → 调用 `GET /api/v1/system/user/list` |
| 重置 | 清空搜索条件 → 重新加载 |

### 2.3 竞态保护

搜索按钮触发，使用竞态序号模式（不防抖，但丢弃过期响应）。

## 4. 数据表格

### 4.1 列定义

| 列 | 宽度 | 对齐 | 说明 |
|------|:--:|:--:|------|
| 多选 | 40px | 中 | checkbox，全选仅选中当前页 |
| 序号 | 60px | 中 | 自动编号（分页连续） |
| 姓名 | 100px | 左 | `realName`，空则显示"--" |
| 手机号 | 130px | 左 | 脱敏：`138****5678` |
| 性别 | 60px | 中 | 男 / 女 / 未知 |
| 状态 | 80px | 中 | ● 绿色圆点「正常」/ ● 红色圆点「停用」 |
| 角色 | 150px | 左 | `el-tag` 标签，多个换行显示 |
| 创建时间 | 160px | 左 | `YYYY-MM-DD HH:mm` |
| 操作 | 180px | 中 | 按钮组（见 4.2） |

### 4.2 操作列按钮

| 按钮 | 权限码 | 行为 |
|------|--------|------|
| 编辑 | `system:user:edit` | 打开编辑弹窗（数据预填） |
| 停用/启用 | `system:user:edit` | 切换状态，二次确认 |
| 修改密码 | `system:user:resetPwd` | 打开修改密码弹窗（§8） |
| 删除 | `system:user:delete` | 二次确认 → 调用 API |

**保护规则**：
- 当前登录用户自己的行：删除 + 停用按钮隐藏
- userId=1（超级管理员）的行：删除 + 停用按钮隐藏，角色列锁定标签「超级管理员」
- "停用"按钮文案在正常状态时显示"停用"，停用状态时显示"启用"

### 4.3 二次确认文案

| 操作 | 弹窗文案 |
|------|------|
| 停用 | "确认将用户「{姓名}」的状态改为**停用**？停用后该用户将无法登录系统。" |
| 启用 | "确认将用户「{姓名}」的状态改为**启用**？" |
| 删除 | "确认删除用户「{姓名}」？删除后不可恢复。" |
| 批量删除 | "确认删除选中的 {N} 个用户？删除后不可恢复。" |

## 6. 新增/编辑弹窗

### 6.1 触发

- 新增：工具栏「+ 新增」
- 编辑：操作列「编辑」

### 6.2 弹窗规格

- 宽度：560px
- 标题：「新增用户」或「编辑用户」

### 6.3 表单字段

| 字段 | 类型 | 必填 | 新增时 | 编辑时 | 校验规则 |
|------|------|:--:|:--:|:--:|------|
| 用户名 | 文本 | ✅ | 显示 | 只读 | 2-20 字符，字母数字下划线，失焦异步校验唯一性 |
| 密码 | 密码 | ✅(新增) | 显示 | **不显示** | 新增必填 6-20 字符；编辑时无此字段（另行重置） |
| 姓名 | 文本 | ✅ | 显示 | 显示 | 1-20 字符。失焦时检测重名：如已有同名用户，下方显示蓝色提示"已有同名用户，建议在姓名后加数字区分，如「{姓名}01」"，不阻止提交 |
| 手机号 | 文本 | ✅ | 显示 | 显示 | 11 位数字格式。失焦异步校验唯一性（编辑时排除自身），如已存在 → 红色提示"该手机号已被使用" + 不可提交 |
| 性别 | 单选组 | ❌ | 显示 | 显示 | 男 / 女 / 未知 |
| 角色 | 多选下拉 | ❌ | 显示 | 显示 | 调用 `GET /api/v1/system/role/all` 加载选项，支持多选+搜索 |
| 备注 | 文本域 | ❌ | 显示 | 显示 | 最多 500 字符，右下角计数器 |

### 6.4 唯一性校验

| 字段 | 校验时机 | 校验方式 | 类型 |
|------|------|------|:--:|
| 用户名 | 失焦 | 调后端查询是否已存在（编辑时排除自身） | 硬阻断 |
| 手机号 | 失焦 | 调后端查询是否已存在（编辑时排除自身），重复则提示"该手机号已被使用" | 硬阻断 |
| 姓名 | 失焦 | 调后端查询是否已存在同名用户 | 软提示 |

**硬阻断**：校验失败 → 红色错误提示，不可提交
**软提示**：校验到重名 → 蓝色信息提示"已有同名用户，建议在姓名后加数字区分，如「{姓名}01」"，不阻止提交

校验中 → 输入框右侧 loading 图标
校验通过（无重名/无冲突）→ 绿色勾
校验失败（唯一性冲突）→ 红色叉 + "用户名已存在"等提示

### 6.5 交互

| 操作 | 行为 |
|------|------|
| 打开（新增） | 空表单，默认性别"未知" |
| 打开（编辑） | 调用 `GET /api/v1/system/user/{id}` → 填充表单（密码不显示，角色回填） |
| 确认 | 前端校验 → 提交 API → 成功 → toast + 关闭弹窗 + 刷新列表 |
| 取消 | 有修改 → 确认"放弃修改？"；无修改 → 直接关闭 |

### 6.6 状态

| 状态 | 表现 |
|------|------|
| 加载中（编辑） | 弹窗内骨架屏 |
| 加载失败（编辑） | "加载用户信息失败"+「重试」 |
| 提交中 | 确认按钮 loading，"保存中…" |
| 提交失败 | 保留弹窗 + 错误提示 |
| 唯一性校验中 | 输入框 loading 图标 |

### 6.7 对应 API

| 操作 | API |
|------|------|
| 新增 | `POST /api/v1/system/user` |
| 编辑 | `PUT /api/v1/system/user/{id}` |
| 详情 | `GET /api/v1/system/user/{id}` |
| 角色选项 | `GET /api/v1/system/role/all` |

## 7. 用户状态切换

### 7.1 流程

操作列点击「停用」/「启用」→ 二次确认 → 调用 `PUT /api/v1/system/user/{id}/status` → 刷新列表

### 7.2 删除

操作列点击「删除」→ 二次确认 → 调用 `DELETE /api/v1/system/user/{ids}` → 刷新列表
批量删除：工具栏「批量删除」→ 取选中行 ID → 同上

## 8. 修改密码弹窗

### 8.1 触发

操作列「修改密码」→ 打开 Dialog（宽度 420px）

### 8.2 弹窗布局

```
┌─────────────────────────────────────┐
│  修改密码 — 用户：张三             [✕] │
├─────────────────────────────────────┤
│                                     │
│  新密码      [______________]       │
│  确认密码    [______________]       │
│                                     │
│  [ 生成随机密码并复制 ]              │
│                                     │
├─────────────────────────────────────┤
│              [ 取消 ]  [ 确定 ]      │
└─────────────────────────────────────┘
```

### 8.3 字段

| 字段 | 类型 | 校验 |
|------|------|------|
| 新密码 | 密码输入 | 6-20 字符，非空 |
| 确认密码 | 密码输入 | 必须与新密码一致 |

### 8.4 交互

| 操作 | 行为 |
|------|------|
| 打开 | 空表单，标题显示目标用户姓名 |
| 输入密码 | 手动输入新密码 |
| 生成随机密码 | 前端生成 8 位随机密码（大小写字母+数字）→ 自动填入新密码和确认密码 → 复制到剪贴板 → toast"密码已复制" |
| 确定 | 前端校验 → `PUT /api/v1/system/user/{id}/password`，入参 `{ newPassword }` → 成功 → toast"密码已修改" + 关闭弹窗 |
| 取消 | 关闭弹窗，清空表单 |

### 8.5 状态

| 状态 | 表现 |
|------|------|
| 提交中 | 确定按钮 loading |
| 提交失败 | 保留弹窗 + 错误提示 |
| 生成密码 | 密码框瞬间填入，无 loading |

### 8.6 对应 API

| 接口 | 说明 |
|------|------|
| `PUT /api/v1/system/user/{id}/password` | 修改用户密码，入参 `{ newPassword }` |

## 9. 导入

### 9.1 密码策略

导入模板**不含密码列**。导入时系统为每个用户自动生成 8 位随机密码（大小写字母+数字）。

### 9.2 流程

1. 点击「下载模板」→ `GET /api/v1/system/user/template` → 浏览器下载 Excel
2. 点击「导入」→ 打开导入弹窗
3. 上传文件 → 文件格式校验（仅允许 `.xlsx` `.xls`，最大 10MB）→ 调 `POST /api/v1/system/user/import`
4. 返回结果 → 弹窗展示导入结果（§9.4）→ 关闭弹窗 → 刷新列表

### 9.3 导入弹窗

- 上传区域：拖拽或点击上传
- 下载模板链接
- 上传中：进度条

### 9.4 导入结果弹窗

上传完成后不自动关闭，展示结果：

```
┌─────────────────────────────────────────────┐
│  导入结果                               [✕]  │
├─────────────────────────────────────────────┤
│  成功 12 条，失败 2 条                        │
├─────────────────────────────────────────────┤
│  成功列表：                                   │
│  ┌────┬──────┬────────────┐                 │
│  │姓名│用户名│ 随机密码    │                 │
│  ├────┼──────┼────────────┤                 │
│  │张三│zhang │ aB3xK9mQ   │                 │
│  │李四│lisi  │ pQ7wR2tY   │                 │
│  │ ...                                      │
│  └────┴──────┴────────────┘                 │
│                                             │
│  [ 复制全部（姓名+密码）]                      │
│                                             │
│  失败列表（可折叠）：                          │
│    · 第 3 行：手机号格式错误                   │
│    · 第 8 行：用户名已存在                     │
├─────────────────────────────────────────────┤
│                        [ 关闭（已复制）]       │
└─────────────────────────────────────────────┘
```

- 「复制全部」：复制为文本 `张三 / zhang / aB3xK9mQ\n李四 / lisi / pQ7wR2tY\n...`
- 复制后按钮变为"已复制"（绿色勾）
- 关闭弹窗后密码不再展示，管理员需自行分发

## 10. 导出

点击「导出」→ 将当前搜索条件（不分页，不传 page/size）调 `GET /api/v1/system/user/export` → 浏览器下载 Excel

## 11. 空状态与异常

| 状态 | 表现 |
|------|------|
| 列表为空（无数据） | 表格显示空状态插图："暂无用户数据" |
| 搜索无结果 | "未找到匹配的用户"+「清空筛选」按钮 |
| 列表加载中 | 表格骨架屏（灰色条块） |
| 列表加载失败 | "数据加载失败"+「重试」按钮 |
| 网络错误 | 统一 toast "网络异常，请重试" |
