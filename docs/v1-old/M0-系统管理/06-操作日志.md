# 06 · 操作日志

> 路由：`/system/log/operlog`
> 权限码：`system:log:list`
> 对应 API 模块：log/operlog

## 3. 搜索栏

| 字段 | 类型 | 说明 |
|------|------|------|
| 操作人 | 文本输入 | 模糊匹配 |
| 模块标题 | 文本输入 | 模糊匹配，如"用户管理" |
| 业务类型 | 多选下拉 | 登录 / 新增 / 修改 / 删除 / 授权 / 导出 / 导入 / 清空 / 其他；可多选 |
| 状态 | 下拉单选 | 全部 / 成功 / 失败 |
| 操作时间 | 日期范围选择器 | `el-date-picker` type `daterange`，快捷选项：今天 / 最近7天 / 最近30天 |
| 搜索 | 按钮 | 重置到第1页，触发查询 |
| 重置 | 按钮 | 清空全部条件 + 重新加载 |

---

## 4. 工具栏

| 按钮 | 权限码 | 行为 |
|------|--------|------|
| 批量删除 | `system:log:delete` | 取选中行 ID → 二次确认 → 调用 API → 刷新 |
| 清空全部 | `system:log:delete` | 二次确认弹窗，红色警告"此操作将清空所有操作日志，不可恢复！" + 输入确认文字 |

### 4.1 清空确认流程

1. 点击「清空全部」
2. 弹窗：
   - 红色警告图标 + "清空所有操作日志"
   - 警告文字："此操作将删除全部操作日志记录，不可恢复！"
   - 输入框：请手动输入"确认清空"以继续
   - 「取消」按钮 + 「确认清空」按钮（红色，disabled 直到输入正确文字）
3. 输入"确认清空" → 确认按钮可用 → 点击 → 调用 `DELETE /api/v1/system/log/operlog/clean`

### 5.2 登录事件展示

当业务类型=「登录」时：
- 模块标题显示"登录认证"
- 请求方式显示"POST"
- 请求参数列可能包含密码字段 → 详情弹窗中做脱敏处理（密码字段替换为 `****`）

| 操作 | API |
|------|------|

## 7. 空状态与异常

| 状态 | 表现 |
|------|------|

- 操作日志的业务类型枚举新增 `LOGIN`（值为"登录"）
