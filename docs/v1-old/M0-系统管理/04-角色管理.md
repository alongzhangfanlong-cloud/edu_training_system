> 权限码：`system:role:list`

## 2. 搜索栏

| 字段 | 类型 | 说明 |
|------|------|------|
| 角色名称 | 文本输入 | 模糊匹配 |
| 状态 | 下拉单选 | 全部 / 正常 / 停用 |

## 3. 工具栏

| 按钮 | 权限码 | 说明 |
|------|--------|------|
| + 新增 | `system:role:add` | 打开新增弹窗 |
| 批量删除 | `system:role:delete` | 有选中项可用 |

---

## 4. 数据表格

### 4.1 列定义

| 列 | 说明 |
|------|------|
| 多选 | checkbox |
| 序号 | 自动编号 |
| 角色名称 | — |
| 角色编码 | 如 `admin`、`teacher`、`parent`，`<code>` 样式 |
| 排序 | 中心对齐，数字 |
| 状态 | ● 绿色「正常」/ ● 红色「停用」 |
| 创建时间 | `YYYY-MM-DD HH:mm` |
| 操作 | 按钮组（见 4.2） |

### 4.2 操作列按钮

| 按钮 | 权限码 | 行为 |
|------|--------|------|
| 编辑 | `system:role:edit` | 打开编辑弹窗 |
| 分配菜单 | `system:role:edit` | 打开分配菜单抽屉（§5） |
| 分配用户 | `system:role:edit` | 打开分配用户弹窗（§6） |
| 停用/启用 | `system:role:edit` | 二次确认后切换状态 |
| 删除 | `system:role:delete` | 二次确认后删除 |

### 4.3 保护规则

| 规则 | 说明 |
|------|------|
| code=`admin` 的角色 | 「删除」按钮隐藏 |
| 角色下有用户时删除 | 弹窗提示"角色「{name}」下已有 {N} 个用户，确认删除？" |
| 当前用户所属角色 | 不影响操作，但删除后该角色下的用户权限立即失效 |

### 4.4 二次确认文案

| 操作 | 弹窗文案 |
|------|------|
| 停用 | "确认将角色「{name}」的状态改为**停用**？该角色下的用户将失去对应权限。" |
| 启用 | "确认将角色「{name}」的状态改为**启用**？" |
| 删除 | "确认删除角色「{name}」？删除后不可恢复，角色下的用户将失去对应权限。" |
| 批量删除 | "确认删除选中的 {N} 个角色？删除后不可恢复。" |

---

## 5. 新增/编辑弹窗

### 5.1 弹窗规格

- 宽度：520px
- 标题：「新增角色」或「编辑角色」

### 5.2 表单字段

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|:--:|------|
| 角色名称 | 文本 | ✅ | 1-30 字符 |
| 角色编码 | 文本 | ✅ | 1-20 字符，字母开头，仅字母数字下划线，失焦异步校验唯一性 |
| 排序 | 数字输入 | ✅ | 0-999，默认 0 |
| 菜单展开方式 | 开关 | ❌ | 默认关闭（父子联动）；开启 = 父子不联动（`menuCheckStrictly`） |
| 状态 | 开关 | ❌ | 默认开启 |
| 备注 | 文本域 | ❌ | 500 字符 |

### 5.3 对应 API

| 操作 | API |
|------|------|
| 新增 | `POST /api/v1/system/role` |
| 编辑 | `PUT /api/v1/system/role/{id}` |
| 详情 | `GET /api/v1/system/role/{id}` |

```
┌────────────────────────────────────────┐
│  分配菜单权限 — 角色：教师           [✕] │
├────────────────────────────────────────┤
│                                        │
│  展开/折叠全部                           │
│                                        │
│  ☑ 系统管理                             │
│    ☑ 用户管理                           │
│      ☑ 用户列表                         │
│      ☐ 用户新增                         │
│      ☑ 用户编辑                         │
│      ☐ 用户删除                         │
│    ☑ 角色管理                           │
│      ☐ 角色列表                         │
│    ...                                  │
│  ☑ 课程管理                             │
│    ☑ 课程列表                           │
│    ☐ 课程新增                           │
│                                        │
├────────────────────────────────────────┤
│  提示：勾选父节点自动选中所有子节点。       │
│  取消勾选父节点自动取消所有子节点。         │
├────────────────────────────────────────┤
│              [ 取消 ]  [ 保存 ]          │
└────────────────────────────────────────┘
```

### 6.2 交互

| 行为 | 说明 |
|------|------|
| 打开 | 调用 `GET /api/v1/system/role/{id}` 获取已有 `menuIds` + 调用 `GET /api/v1/system/menu/tree` 获取全部菜单树 → 勾选已有权限 |
| 勾选/取消 | 父子联动：勾父 → 全选子；取父 → 全取子 |
| 半选态 | 部分子节点选中时，父节点显示半选横线 |
| 保存 | 收集全部 `checked` 的菜单 ID → `PUT /api/v1/system/role/{id}` 提交 `menuIds` |
| 取消 | 关闭抽屉，不保存 |

### 6.3 状态

| 状态 | 表现 |
|------|------|
| 加载中 | 菜单树骨架屏 |
| 保存中 | 「保存」按钮 loading |
| 保存失败 | toast 错误提示，抽屉不关闭 |

### 6.4 对应 API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/system/role/{id}` | 获取角色详情（含 `menuIds`） |
| `GET /api/v1/system/menu/tree` | 获取全部菜单树 |
| `PUT /api/v1/system/role/{id}` | 保存（传入 `menuIds` 全量替换） |

## 7. 分配用户

### 7.1 触发与布局

操作列 →「分配用户」→ 打开 Dialog（宽度 700px）

```
┌─────────────────────────────────────────────┐
│  分配用户 — 角色：教师                     [✕] │
├──────────────────┬──────────────────────────┤
│  未分配用户       │  已分配用户（共 {N} 人）  │
│  [搜索____]      │                          │
│  ┌────────────┐  │  ┌──────────────────────┐│
│  │ ☐ 张三     │  │  │ 李四          [移除] ││
│  │ ☐ 王五     │  │  │ 赵六          [移除] ││
│  │ ☐ 陈七     │  │  │ 孙八          [移除] ││
│  │ ...        │  │  │                      ││
│  │            │  │  │                      ││
│  │ 共 M 人    │  │  │                      ││
│  └────────────┘  │  └──────────────────────┘│
│                  │                          │
├──────────────────┴──────────────────────────┤
│              [ 取消 ]  [ 保存 ]              │
└─────────────────────────────────────────────┘
```

### 7.2 交互

| 行为 | 说明 |
|------|------|
| 打开 | 调用 `GET /api/v1/system/role/{id}/auth-user` → 填充右侧已分配用户列表 |
| 左侧搜索 | 远程搜索，显示未分配该角色的用户 |
| 分配 | 左侧勾选用户 → 点击某按钮移入右侧（或直接双击用户行） |
| 移除 | 右侧用户行 → 点击「移除」→ 回到左侧 |
| 保存 | 收集右侧全部用户 ID → `PUT /api/v1/system/role/{id}/auth-user` 提交全量 userId 列表 |

### 7.3 对应 API

| 接口 | 说明 |
|------|------|
| `GET /api/v1/system/role/{id}/auth-user` | 获取该角色已分配的用户列表 |
| `GET /api/v1/system/user/list` | 获取未分配用户列表（搜索用） |
| `PUT /api/v1/system/role/{id}/auth-user` | 保存（传入完整 userId 列表，全量替换） |

### 7.4 状态

| 状态 | 表现 |
|------|------|
| 加载中 | 左右两侧骨架屏 |
| 保存中 | 「保存」按钮 loading |
| 左侧搜索中 | 搜索输入框 loading 图标 + 列表骨架屏 |
