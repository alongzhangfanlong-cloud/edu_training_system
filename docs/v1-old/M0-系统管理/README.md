## 3. 权限模型

```
sys_user ──多对多── sys_role ──多对多── sys_menu
                                              │
                                    type: M(目录) / C(菜单) / F(按钮)
```

- 前端：菜单树控制路由访问，按钮权限码 `v-if` 控制操作显隐
- 后端：`@PreAuthorize("@ss.hasPermi('system:user:list')")` 方法级鉴权
- 超级管理员（userId=1）绕过所有权限检查

## 6. 全局约定

### 6.1 页面通用布局

```
┌────────────────────────────────────────────┐
│  面包屑导航（自动生成）                       │
├────────────────────────────────────────────┤
│  搜索栏（关键词 + 状态筛选 + 搜索/重置按钮）    │
├────────────────────────────────────────────┤
│  工具栏（新增 / 批量删除 / 导入 / 导出 等）     │
├────────────────────────────────────────────┤
│  数据表格（分页 + 多选 + 排序）               │
├────────────────────────────────────────────┤
│  分页器（页码 + 每页条数 + 总条数）           │
└────────────────────────────────────────────┘
```

### 6.2 表单通用规则

| 规则 | 说明 |
|------|------|
| 必填标记 | 必填字段 label 前红色 `*` |
| 校验时机 | 失焦校验 + 提交前全量校验 |
| 唯一性校验 | 用户名、编码等字段失焦时异步校验，重复则提示已存在 |
| 提交反馈 | 成功 → 关闭弹窗 + 刷新列表 + 成功提示；失败 → 保留弹窗 + 错误提示 |
| 重复提交 | 提交按钮点击后 loading，禁止重复点击 |
| 取消确认 | 表单有修改时点取消 → 弹窗确认"是否放弃修改？" |

### 6.3 操作日志自动记录

以下操作 AOP 自动记录，前端无需处理：
- 新增 / 修改 / 删除
- 导入 / 导出
- 授权（分配角色/分配菜单）
- 密码重置
