## 5. edu_class（班级）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| name | VARCHAR(50) | — | 班级名称 |
| code | VARCHAR(32) | — | 自动生成 `CLS`+yyyyMMdd+4位序号 |
| course_id | BIGINT | — | → edu_course.id |
| teacher_id | BIGINT | — | → sys_user.id（主讲教师） |
| classroom_id | BIGINT | NULL | → edu_classroom.id |
| max_students | INT | 20 | 最大人数 |
| current_count | INT | 0 | 当前人数(冗余缓存) |
| status | VARCHAR(20) | 'RECRUITING' | RECRUITING/FULL/SUSPENDED/FINISHED/CANCELLED |
| start_date | DATE | NULL | 开课日期 |
| end_date | DATE | NULL | 结课日期 |
| description | VARCHAR(500) | NULL | 班级说明 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_code`, `idx_course_id`, `idx_teacher_id`, `idx_classroom_id`, `idx_status`, `idx_name`

**状态流转**：
```
RECRUITING ⇄ SUSPENDED（手动）
RECRUITING → FULL（自动，current_count >= max_students）
FULL → RECRUITING（自动，学员退出或扩容）
任意 → FINISHED（手动结课，不可逆）
任意 → CANCELLED（手动取消，无在读学员时）
```

**current_count 维护**：插入 edu_class_student 时 +1，删除/退出时 -1，事务保护。

## 6. edu_class_schedule_rule（班级排课规则）

> 与班级 1:1 关联，班级创建时同步创建。Batch 2 排课计划基于此规则生成课程表。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| class_id | BIGINT | — | → edu_class.id，UNIQUE |
| week_days | VARCHAR(20) | — | 每周上课日 `"1,3,5"`（1=周一） |
| start_time | TIME | — | 上课开始 |
| end_time | TIME | — | 上课结束 |
| duration | INT | 45 | 每节课时长(分钟) |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_class_id (class_id)`

## 7. edu_class_student（班级学员关联）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| class_id | BIGINT | — | → edu_class.id |
| student_id | BIGINT | — | → edu_student.id |
| join_time | DATETIME | NOW | 加入时间 |
| status | VARCHAR(20) | 'ENROLLED' | ENROLLED/SUSPENDED/EXITED |
| remark | VARCHAR(200) | NULL | 备注 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_class_student (class_id, student_id)` — 同一学员不能重复加入同一班级，`idx_student_id`

## 9. 模块内部依赖

```
edu_subject ──1:N──▶ edu_course ──1:N──▶ edu_class ──1:1──▶ edu_class_schedule_rule
                                                   ──1:N──▶ edu_class_student ◀── N02.edu_student

edu_classroom ───────────▶ edu_class (classroom_id, 可空)

edu_resource ── 独立模块，按 subject_id + grade + resource_type 分类
```
