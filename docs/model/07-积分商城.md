> **版本**：v1.0 | **日期**：2026-07-18 | **批次**：Batch 3a
>
> 本文档定义 N04 积分商城模块的完整数据模型，包括 ER 图、建表 SQL、索引设计和跨模块引用。

## 1. 模块概述

积分商城是贯穿教务闭环的激励子系统。学生通过教师课后发放和运维手动调整获取积分，使用积分兑换礼品。运营端负责礼品库管理与兑换核销。

### 1.1 核心业务规则

| 编号 | 规则 |
|:----:|------|
| R01 | 积分不可透支，兑换前检查余额 |
| R02 | 库存原子扣减，使用条件 UPDATE + 受影响行数判断 |
| R03 | 取消兑换退积分+库存，事务包裹三操作 |
| R04 | 积分日志只追加，不修改不删除 |
| R05 | 删除礼品前置校验存在 PENDING_CLAIM 兑换记录 |
| R06 | 禁用礼品不影响历史兑换记录 |

### 1.2 积分变动类型

| 类型码 | 含义 | amount 符号 |
|--------|------|:-----------:|
| EARN | 获取积分 | 正数 |
| REDEEM | 兑换消耗 | 负数 |
| ADJUST | 管理员调整 | 正或负 |
| EXPIRE | 积分过期 (v1预留) | 负数 |

## 3. 建表 SQL

```sql
-- ============================================
-- N04 积分商城 — 数据表定义 (Batch 3a)
-- 数据库：MySQL 8.0 + InnoDB
-- 字符集：utf8mb4
-- ============================================

-- 3.1 积分账户
CREATE TABLE edu_points_account (
    id              BIGINT          NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
    student_id      BIGINT          NOT NULL                 COMMENT '学生ID，关联 edu_student.id',
    total_earned    INT             NOT NULL DEFAULT 0       COMMENT '累计获取积分',
    total_spent     INT             NOT NULL DEFAULT 0       COMMENT '累计消费积分',
    balance         INT             NOT NULL DEFAULT 0       COMMENT '当前积分余额 (total_earned - total_spent)',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_student_id (student_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='积分账户';

-- 3.2 积分日志（只追加，不修改不删除）
CREATE TABLE edu_points_log (
    id              BIGINT          NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
    student_id      BIGINT          NOT NULL                 COMMENT '学生ID',
    change_type     VARCHAR(20)     NOT NULL                 COMMENT '变动类型: EARN/REDEEM/EXPIRE/ADJUST',
    amount          INT             NOT NULL                 COMMENT '变动积分数，正数=获取，负数=消耗',
    balance_after   INT             NOT NULL                 COMMENT '变动后账户余额',
    source_type     VARCHAR(50)     NOT NULL                 COMMENT '来源类型: TEACHER/ADMIN/REDEEM/CANCEL_REDEEM/ADJUST',
    source_id       BIGINT          NULL                     COMMENT '来源业务记录ID（评价ID/兑换ID等）',
    remark          VARCHAR(200)    NULL                     COMMENT '备注说明',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    KEY idx_student_id (student_id),
    KEY idx_create_time (create_time),
    KEY idx_source (source_type, source_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='积分日志（只追加）';

-- 3.3 积分礼品
CREATE TABLE edu_points_gift (
    id              BIGINT          NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
    name            VARCHAR(50)     NOT NULL                 COMMENT '礼品名称',
    image_url       VARCHAR(500)    NULL                     COMMENT '礼品图片URL',
    points_required INT             NOT NULL                 COMMENT '兑换所需积分',
    stock_total     INT             NOT NULL                 COMMENT '总库存数量',
    stock_remaining INT             NOT NULL                 COMMENT '剩余库存数量',
    status          TINYINT         NOT NULL DEFAULT 1       COMMENT '状态: 1=启用, 0=禁用',
    description     VARCHAR(500)    NULL DEFAULT ''          COMMENT '礼品描述',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted      TINYINT         NOT NULL DEFAULT 0       COMMENT '逻辑删除: 0=未删除, 1=已删除',
    PRIMARY KEY (id),
    UNIQUE KEY uk_name (name),
    KEY idx_status (status),
    KEY idx_is_deleted (is_deleted)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='积分礼品';

-- 3.4 积分兑换记录
CREATE TABLE edu_points_redemption (
    id              BIGINT          NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
    student_id      BIGINT          NOT NULL                 COMMENT '学生ID',
    gift_id         BIGINT          NOT NULL                 COMMENT '礼品ID',
    points_spent    INT             NOT NULL                 COMMENT '消耗积分',
    status          VARCHAR(20)     NOT NULL DEFAULT 'PENDING_CLAIM' COMMENT '状态: PENDING_CLAIM/CLAIMED/CANCELLED',
    redeem_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '兑换时间',
    claim_time      DATETIME        NULL                     COMMENT '领取时间',
    cancel_time     DATETIME        NULL                     COMMENT '取消时间',
    operator_id     BIGINT          NULL                     COMMENT '操作人ID（核销/取消时的操作人员，关联 sys_user）',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted      TINYINT         NOT NULL DEFAULT 0       COMMENT '逻辑删除: 0=未删除, 1=已删除',
    PRIMARY KEY (id),
    KEY idx_student_id (student_id),
    KEY idx_gift_id (gift_id),
    KEY idx_status (status),
    KEY idx_redeem_time (redeem_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='积分兑换记录';
```

## 4. 索引设计说明

| 表 | 索引 | 类型 | 覆盖查询场景 |
|----|------|:----:|-------------|
| `edu_points_account` | `uk_student_id` | UNIQUE | 按学生ID查余额（高频） |
| `edu_points_log` | `idx_student_id` | NORMAL | 按学生ID查积分日志（分页） |
| `edu_points_log` | `idx_create_time` | NORMAL | 按时间范围筛选 |
| `edu_points_log` | `idx_source` | NORMAL | 防重查询（source_type + source_id） |
| `edu_points_gift` | `uk_name` | UNIQUE | 礼品名称唯一约束 |
| `edu_points_gift` | `idx_status` | NORMAL | 按状态筛选（启用/禁用） |
| `edu_points_gift` | `idx_is_deleted` | NORMAL | 逻辑删除过滤 |
| `edu_points_redemption` | `idx_student_id` | NORMAL | 按学生查兑换记录 |
| `edu_points_redemption` | `idx_gift_id` | NORMAL | 按礼品查兑换记录（删除校验） |
| `edu_points_redemption` | `idx_status` | NORMAL | 按状态筛选 |
| `edu_points_redemption` | `idx_redeem_time` | NORMAL | 按时间范围筛选 + 排序 |

## 5. 关键设计决策

| 决策 | 说明 |
|------|------|
| `total_earned` / `total_spent` / `balance` 冗余存储 | 积分账户余额高频查询（兑换列表、余额展示），由 `edu_points_log` 写入时同步更新 |
| `points_log` 只追加不可变 | 银行流水模式，无 update_time/deleted，`idx_source` 索引支持防重查询 |
| `stock_remaining` 条件更新防超卖 | `UPDATE ... SET stock_remaining = stock_remaining - 1 WHERE id = ? AND stock_remaining > 0` |
| `redemption.status` 用 VARCHAR | 语义自解释 (PENDING_CLAIM / CLAIMED / CANCELLED)，不依赖魔术数字 |
| 兑换状态机 | PENDING_CLAIM → CLAIMED（核销）或 CANCELLED（取消），终态不可变 |
| 取消退积分 | 事务包裹：状态更新 + 退还积分到 account + 恢复库存 + 写入日志 |

## 7. 跨模块引用

| 引用方向 | 字段 | 说明 |
|----------|------|------|
| → N02 edu_student | `edu_points_account.student_id` | 积分账户关联学生 (1:1) |
| → N02 edu_student | `edu_points_log.student_id` | 积分日志关联学生 (N:1) |
| → N02 edu_student | `edu_points_redemption.student_id` | 兑换记录关联学生 (N:1) |
| → N08 sys_user | `edu_points_redemption.operator_id` | 兑换操作人关联用户 (N:1) |
| ← N05 edu_evaluation_student | `reward_points` 联动发放 | 教师评价时附带积分奖励 |

> **核心原则**：积分模块接收来自 N05（评价积分）的事件写入，本身不反向依赖业务模块。`edu_points_log.source_id` 为多态外键，通过 `source_type` 区分来源。

## 8. 约束与校验

| 约束 | 实现方式 |
|------|----------|
| 积分不可透支 | Service 层校验 + 数据库行锁 `SELECT ... FOR UPDATE` |
| 库存不可超卖 | 条件 UPDATE + 受影响行数判断 |
| 礼品名唯一 | 数据库 UNIQUE 索引 + Service 层前置校验 |
| 兑换状态流转 | Service 层状态机校验，拒绝非法转换 |
| 日志不可变 | Mapper 层只暴露 insert，不暴露 update/delete |
| 取消退积分事务 | `@Transactional` 包裹全部操作 |
