## 2. edu_enrollment（报名记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| student_id | BIGINT | — | → edu_student.id |
| course_id | BIGINT | — | → edu_course.id |
| class_id | BIGINT | NULL | → edu_class.id（可空） |
| amount | DECIMAL(10,2) | — | 应缴金额 |
| handler_id | BIGINT | — | → sys_user.id（经手人） |
| enrollment_date | DATE | — | 报名日期 |
| payment_status | VARCHAR(20) | 'PENDING' | DRAFT / PENDING / PARTIAL / PAID / REFUNDED / CANCELLED |
| remark | VARCHAR(200) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_student_id`, `idx_course_id`, `idx_payment_status`, `idx_enrollment_date`, `idx_handler_id`

**缴费状态流转**：
```
DRAFT ──提交──→ PENDING（待收费）
PENDING ──部分缴费──→ PARTIAL
PARTIAL ──缴清──→ PAID
PENDING/PARTIAL ──取消──→ CANCELLED（无缴费时）
PAID ──退费──→ REFUNDED
```

**业务规则**：
- 同一学生+同一课程+同一班级组合唯一（重复报名前端警告+后端拒绝）
- 选择课程后自动带出课程单价作为默认金额，可手动修改
- 报名日期不可选未来日期

## 3. edu_tuition_fee（收费记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| fee_no | VARCHAR(32) | — | 收费编号 `T`+yyyyMMdd+4位流水，UNIQUE |
| enrollment_id | BIGINT | NULL | → edu_enrollment.id |
| student_id | BIGINT | — | → edu_student.id |
| course_id | BIGINT | — | → edu_course.id |
| class_id | BIGINT | NULL | → edu_class.id |
| fee_type | VARCHAR(32) | — | REGISTRATION / TUITION / MATERIAL / OTHER |
| amount_receivable | DECIMAL(10,2) | — | 应缴金额 |
| amount_paid | DECIMAL(10,2) | — | 实缴金额 |
| payment_method | VARCHAR(32) | — | CASH / WECHAT / ALIPAY / BANK_TRANSFER |
| status | VARCHAR(32) | 'PAID' | PAID / REFUNDED / PARTIAL_REFUNDED |
| remark | VARCHAR(500) | NULL | 备注 |
| operator_id | BIGINT | — | → sys_user.id（经手人） |
| create_time | DATETIME | NOW | 收费时间 |
| update_by/update_time | — | — | 操作人/时间 |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_fee_no (UNIQUE)`, `idx_enrollment_id`, `idx_student_id`, `idx_create_time`

**课时入账规则**（仅 fee_type=TUITION 时触发）：
```
入账课时 = floor(amount_paid / edu_course.price)
→ 写入 edu_student_hours_log (change_type=ENROLL_GAIN, source_type=TUITION)
→ 更新 edu_student.remaining_hours += 入账课时
```

**部分收费**：同一报名记录可多次收费，每次独立计算课时入账，累计已缴=应缴时报名状态→PAID。

**删除保护**：已关联退费记录的收费不可删除（按钮隐藏）。

## 4. edu_tuition_refund（退费记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| refund_no | VARCHAR(32) | — | 退费编号 `R`+yyyyMMdd+4位流水，UNIQUE |
| fee_id | BIGINT | — | → edu_tuition_fee.id |
| student_id | BIGINT | — | → edu_student.id |
| course_id | BIGINT | — | → edu_course.id |
| amount | DECIMAL(10,2) | — | 退费金额 |
| reason | VARCHAR(32) | — | 退费原因编码 |
| reason_custom | VARCHAR(200) | NULL | 自定义原因 |
| refund_method | VARCHAR(32) | — | ORIGINAL / CASH / WECHAT / ALIPAY / BANK_TRANSFER |
| status | VARCHAR(32) | 'COMPLETED' | PENDING_APPROVAL / APPROVED / REJECTED / COMPLETED |
| hours_deducted | INT | 0 | 扣回课时数 |
| applicant_id | BIGINT | — | → sys_user.id（申请人） |
| approver_id | BIGINT | NULL | → sys_user.id（审批人） |
| approval_time | DATETIME | NULL | 审批时间 |
| reject_reason | VARCHAR(500) | NULL | 驳回原因 |
| remark | VARCHAR(500) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time | DATETIME | NOW | 申请时间 |
| update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_refund_no (UNIQUE)`, `idx_fee_id`, `idx_student_id`, `idx_status`, `idx_create_time`

**审批流程**：
```
退费金额 ≤ 审批阈值（默认500元）→ 直接 COMPLETED
退费金额 > 审批阈值 → PENDING_APPROVAL → 校长审批 → APPROVED/REJECTED
```

**课时扣回**：
```
扣回课时 = ceil(退费金额 / 课程单价)
→ 写入 edu_student_hours_log (change_type=REFUND_DEDUCT, source_type=REFUND)
→ 剩余课时 ≤ 0 → 学员自动标记"结业"
```

**可退上限**：退费金额 ≤ 实缴金额 - 累计已退费

## 5. edu_tuition_gift_hours（赠送课时）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| gift_no | VARCHAR(32) | — | 赠送编号 `G`+yyyyMMdd+4位流水，UNIQUE |
| student_id | BIGINT | — | → edu_student.id |
| course_id | BIGINT | — | → edu_course.id |
| hours | INT | — | 赠送课时数（1-200） |
| reason | VARCHAR(32) | — | PROMOTION / COMPENSATION / OTHER |
| reason_custom | VARCHAR(200) | NULL | 自定义原因 |
| remark | VARCHAR(500) | NULL | 备注 |
| operator_id | BIGINT | — | → sys_user.id（经手人） |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_gift_no (UNIQUE)`, `idx_student_id`, `idx_course_id`, `idx_create_time`

**入账规则**：
```

→ 更新 edu_student.remaining_hours += hours
```

**删除保护**：删除前校验剩余课时 ≥ 赠送课时数，不足时警告。

## 6. edu_teacher_pay_rate（教师课酬单价）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| teacher_id | BIGINT | — | → sys_user.id（教师） |
| course_id | BIGINT | — | → edu_course.id |
| pay_per_lesson | DECIMAL(10,2) | — | 单节课酬（元） |
| effective_from | DATE | — | 生效起始日期 |
| effective_to | DATE | NULL | 生效截止日期（NULL=长期有效） |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_teacher_course_period (teacher_id, course_id, effective_from) UNIQUE`, `idx_teacher_id`, `idx_course_id`

**约束**：同一教师+同一课程的有效期不允许重叠。

**课酬单价优先级**：
```
edu_class.pay_rate_override（班级级覆盖） > edu_teacher_pay_rate（教师课程级） > sys_user.default_pay_per_lesson（教师默认）
```

## 7. edu_teacher_payroll（教师课酬记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| teacher_id | BIGINT | — | → sys_user.id |
| month | VARCHAR(7) | — | 月份 YYYY-MM |
| course_id | BIGINT | — | → edu_course.id |
| lesson_count | INT | 0 | 消课数（到校+迟到人次，来源 N07） |
| pay_per_lesson | DECIMAL(10,2) | — | 计算时锁定的单节课酬 |
| total_pay | DECIMAL(10,2) | — | = lesson_count × pay_per_lesson |
| status | VARCHAR(20) | 'DRAFT' | DRAFT / CONFIRMED / PAID |
| confirmed_at | DATETIME | NULL | 确认时间 |
| confirmed_by | BIGINT | NULL | → sys_user.id（确认人） |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_teacher_month_course (teacher_id, month, course_id) UNIQUE`, `idx_month`, `idx_status`

**状态流转**：
```
DRAFT ──确认──→ CONFIRMED（锁定消课数和单价）
CONFIRMED ──取消确认──→ DRAFT
CONFIRMED ──发放──→ PAID（终态，不可逆）
```

**自动计算规则**：
- 每月1号凌晨自动计算上月课酬
- 消课数 = N07 签到记录中 status IN (到校,迟到) 的人次
- 代课教师的消课计入代课教师（非原排课教师）
- 无消课记录不生成课酬记录

## 8. 编号规则

| 前缀 | 格式 | 示例 | 说明 |
|------|------|------|------|
| T | T + yyyyMMdd + 4位流水 | T202607180001 | 收费编号 |
| R | R + yyyyMMdd + 4位流水 | R202607180001 | 退费编号 |
| G | G + yyyyMMdd + 4位流水 | G202607180001 | 赠送编号 |

流水号按业务类型独立编号，每日从 0001 开始。

## 9. 费用类型与课时关系

| 费用类型 | 编码 | 触发课时入账 |
|------|------|:--:|
| 报名费 | REGISTRATION | ❌ |
| 课时费 | TUITION | ✅ floor(实缴/单价) |
| 教材费 | MATERIAL | ❌ |
| 其他 | OTHER | ❌ |

---

## 10. 报名→收费→课时入账 完整链路

```
N06.1 报名 → edu_enrollment (status=PENDING)
       ↓
N06.1 收费 → edu_tuition_fee (fee_no=Txxx, status=PAID)
       ↓
       回写 edu_enrollment.payment_status (PARTIAL/PAID)
       ↓
       fee_type=TUITION: 写入 edu_student_hours_log (ENROLL_GAIN, TUITION)
       ↓
       更新 edu_student.total_hours / remaining_hours
```
