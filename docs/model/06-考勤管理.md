## 2. edu_attendance（签到记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| schedule_id | BIGINT | — | → edu_schedule.id（排课记录） |
| class_id | BIGINT | — | → edu_class.id |
| student_id | BIGINT | — | → edu_student.id |
| status | TINYINT | 0 | 0=到校, 1=迟到, 2=缺勤, 3=请假, 4=请假未审批 |
| signin_time | DATETIME | NULL | 签到操作时间 |
| operator_id | BIGINT | NULL | → sys_user.id（操作人） |
| operator_type | VARCHAR(20) | NULL | PC / MINI_PROGRAM |
| remark | VARCHAR(200) | NULL | 备注 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**唯一约束**：`uk_schedule_student (schedule_id, student_id)` — 同一排课同一学生只能有一条签到记录

**索引**：`idx_class_id`, `idx_student_id`

**签到状态值**：

| 值 | 含义 | 触发方式 |
|:--:|------|---------|
| 0 | 到校 | 教师默认勾选确认 |
| 1 | 迟到 | 教师取消勾选后选择"迟到" |
| 2 | 缺勤 | 教师取消勾选后选择"缺勤" |
| 3 | 请假 | 学生请假通过后自动写入 |
| 4 | 请假未审批 | 学生提交请假但教师未处理 |

**状态流转**：
```
未签到（默认）──教师签到──→ 到校/迟到/缺勤
                          │
请假通过 ──自动写入──→ 请假(3)
请假未审批 ──标记──→ 请假未审批(4)
                          │
PC端修改（需权限）←─────────┘（任一状态可互相切换，请假状态除外）
```

**消课规则**（签到即消课）：
```
签到完成
  ├── 到校/迟到 → 扣 1 课时 → 写 edu_student_hours_log(CONSUME, ATTENDANCE)
  ├── 缺勤/请假 → 不扣课时
  └── 试听课(schedule_type=TRIAL) → 不扣课时

→ 更新 edu_student.remaining_hours -= 1
→ 更新 edu_student.last_visit_time = now
```

**签到窗口**：上课开始前 30 分钟 ~ 开始后 2 小时

## 3. edu_leave_student（学生请假）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| student_id | BIGINT | — | → edu_student.id |
| leave_date | DATE | — | 请假日期 |
| leave_type | TINYINT | — | 0=事假, 1=病假, 2=其他 |
| reason | VARCHAR(500) | — | 请假原因 |
| status | TINYINT | 0 | 0=待确认, 1=已通过, 2=已驳回, 3=已撤销 |
| applicant_type | VARCHAR(20) | — | PARENT / TEACHER |
| applicant_id | BIGINT | — | → sys_user.id |
| confirm_teacher_id | BIGINT | NULL | → sys_user.id（确认教师） |
| confirm_time | DATETIME | NULL | 确认时间 |
| reject_reason | VARCHAR(200) | NULL | 驳回原因 |
| auto_approved | TINYINT | 0 | 0=普通, 1=上课时间到达自动通过 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_student_date (student_id, leave_date)`, `idx_status`, `idx_create_time`

**状态流转**：
```
待确认(0) ──教师确认──→ 已通过(1) → 写签到记录 status=3(请假)
待确认(0) ──教师驳回──→ 已驳回(2) → 通知家长（含驳回原因）
待确认(0) ──上课时间到,教师未处理──→ 自动通过(1)（auto_approved=1）
已通过/已驳回 ──撤销(P2)──→ 已撤销(3)
```

**核心规则**：学生请假与课时完全解耦。请假仅是考勤记录，不影响课时消耗。课时只由签到决定。

**教师代请假**：教师提交后状态直接=已通过，跳过确认流程。

## 4. edu_leave_teacher（教师请假）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| teacher_id | BIGINT | — | → sys_user.id（教师） |
| leave_start_date | DATE | — | 请假开始日期 |
| leave_end_date | DATE | — | 请假结束日期（单天时相同） |
| leave_type | TINYINT | — | 0=事假, 1=病假, 2=其他 |
| reason | VARCHAR(500) | — | 请假原因 |
| status | TINYINT | 0 | 0=待审批, 1=已通过, 2=已驳回, 3=已处理, 4=已撤销 |
| applicant_type | VARCHAR(20) | — | TEACHER / ADMIN |
| applicant_id | BIGINT | — | → sys_user.id |
| approver_id | BIGINT | NULL | → sys_user.id（审批人） |
| approve_time | DATETIME | NULL | 审批时间 |
| reject_reason | VARCHAR(200) | NULL | 驳回原因 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_teacher_date (teacher_id, leave_start_date)`, `idx_status`, `idx_create_time`

**状态流转**：
```
待审批(0) ──管理员通过──→ 已通过(1) → 自动冲突检测 → 生成 edu_leave_conflict
待审批(0) ──管理员驳回──→ 已驳回(2)
待审批(0) ──上课时间到,管理员未处理──→ 自动通过(1)
已通过(1) ──全部冲突处理完毕──→ 已处理(3)
```

## 5. edu_leave_conflict（教师请假冲突排课处理）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| leave_id | BIGINT | — | → edu_leave_teacher.id |
| schedule_id | BIGINT | — | → edu_schedule.id（冲突排课） |
| resolve_type | TINYINT | — | 0=代课, 1=调课, 2=停课 |
| substitute_teacher_id | BIGINT | NULL | → sys_user.id（代课教师，resolve_type=0 必填） |
| new_schedule_date | DATE | NULL | 调课后新日期（resolve_type=1 必填） |
| new_time_slot | VARCHAR(50) | NULL | 调课后新时段（resolve_type=1 必填） |
| new_classroom_id | BIGINT | NULL | 调课后新教室（resolve_type=1 可选） |
| status | TINYINT | 0 | 0=待处理, 1=已处理 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_leave_id`, `idx_schedule_id`

**三种处理方式**：

| 方式 | 值 | 行为 | 排课状态变更 | 课酬归属 |
|------|:--:|------|------|------|
| 代课 | 0 | 选择代课教师替换 | schedule.status→SUBSTITUTE, teacher_id→代课教师 | 代课教师 |
| 调课 | 1 | 更新排课日期/时间/教室 | schedule.status→RESCHEDULED, 新建NORMAL记录 | 原教师 |
| 停课 | 2 | 取消本次排课 | schedule.status→SUSPENDED, 标记待补课 | 无 |

**约束**：
- 代课教师必须是可授该科目+该时段空闲+非请假人
- 调课新日期不可在请假范围内
- 每节冲突课必须逐一处理，不可跳过

## 6. 考勤→消课→财务 数据流

```
N03 edu_schedule (排课) ──→ N07 edu_attendance (签到)
                                │
                    status=到校/迟到: 消课
                                │
                    ┌───────────┼───────────┐
                    ▼           ▼           ▼
          edu_student_hours_log    edu_teacher_payroll
          (N02 课时变动明细)        (N06 课酬计算)
                    │
                    ▼
          edu_student.remaining_hours
          (N02 学员剩余课时)
```
