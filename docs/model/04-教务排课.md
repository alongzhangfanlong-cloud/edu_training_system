## 2. edu_schedule_plan（排课计划）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| class_ids | VARCHAR(500) | — | 关联班级ID列表（JSON数组，如 `[1,2,3]`） |
| start_date | DATE | — | 排课起始日期 |
| end_date | DATE | — | 排课结束日期 |
| status | VARCHAR(20) | 'UNGENERATED' | UNGENERATED / GENERATED |
| conflict_detail | TEXT | NULL | 冲突详情 JSON |
| remark | VARCHAR(200) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_status`, `idx_create_time`

**状态流转**：
```
UNGENERATED → GENERATED（冲突检测通过 + 用户确认生成）

生成逻辑：
1. 根据 class_ids 查每个班级的 edu_class_schedule_rule
2. 在 start_date ~ end_date 范围内按 week_days 生成排课日期
3. 取 class_schedule_rule 的 start_time/end_time/duration
4. 执行三维冲突检测（教师-教室-班级）
5. 无冲突→status=GENERATED→写入 edu_schedule
6. 有冲突→用户选择：强制生成(force_flag=1) / 跳过冲突 / 取消
```

**约束**：起始日期不可晚于结束日期，最大跨度 180 天。已生成的计划不可删除（按钮隐藏）。

## 3. edu_schedule（排课记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| plan_id | BIGINT | NULL | → edu_schedule_plan.id（单次排课为空） |
| class_id | BIGINT | — | → edu_class.id |
| course_id | BIGINT | — | → edu_course.id（冗余，方便查询） |
| teacher_id | BIGINT | — | → sys_user.id（授课教师） |
| room_id | BIGINT | NULL | → edu_classroom.id |
| schedule_date | DATE | — | 上课日期 |
| start_time | TIME | — | 开始时间 |
| end_time | TIME | — | 结束时间 |
| schedule_type | VARCHAR(20) | 'NORMAL' | NORMAL=正常 / TRIAL=试听 / MAKEUP=补课 |
| status | VARCHAR(20) | 'NORMAL' | NORMAL / CANCELLED / RESCHEDULED / MAKEUP / SUSPENDED / SUBSTITUTE |
| force_flag | TINYINT | 0 | 0=正常, 1=强制排课（有冲突仍生成） |
| force_reason | VARCHAR(500) | NULL | 强制排课时冲突摘要 |
| cancel_reason | VARCHAR(200) | NULL | 取消原因 |
| cancel_time | DATETIME | NULL | 取消时间 |
| cancel_by | VARCHAR(64) | NULL | 取消人 |
| rescheduled_from_id | BIGINT | NULL | 调课来源排课 ID |
| rescheduled_to_id | BIGINT | NULL | 调课目标排课 ID |
| consumed | TINYINT | 0 | 0=未消课, 1=已消课（手动消课） |
| consume_time | DATETIME | NULL | 消课时间 |
| consume_by | VARCHAR(64) | NULL | 消课人 |
| remark | VARCHAR(200) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_class_date (class_id, schedule_date)`, `idx_teacher_date (teacher_id, schedule_date)`, `idx_room_date (room_id, schedule_date)`, `idx_date (schedule_date)`, `idx_status (status)`, `idx_plan_id (plan_id)`

**状态流转**：
```
NORMAL / MAKEUP ──取消──→ CANCELLED
NORMAL / MAKEUP ──调课──→ RESCHEDULED（原记录） + 新 NORMAL 记录
NORMAL / MAKEUP ──停课──→ SUSPENDED（教师请假冲突→停课）
NORMAL / MAKEUP ──代课──→ SUBSTITUTE（教师请假冲突→代课，teacher_id 更新为代课教师）
NORMAL ──手动消课──→ consumed=1
```

**消课规则**：
- 签到即消课（N07 考勤）：到校/迟到 → N02 学员课时 -1
- 手动消课（课程表操作）：补录无签到记录但实际已上课的场景
- 试听课（schedule_type=TRIAL）不触发消课

**排课冲突检测**（三维独立检测）：
- 教师冲突：同一教师，同一日期及时段（时间有交集），已有其他 NORMAL/MAKEUP 状态排课
- 教室冲突：同一教室，同一日期及时段
- 班级冲突：同一班级，同一日期及时段
- 时间交集公式：`start1 < end2 AND end1 > start2`
- 排除：CANCELLED / RESCHEDULED / SUSPENDED 状态不参与冲突检测
