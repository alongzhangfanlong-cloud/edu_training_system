## 2. edu_student（在学学员）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| name | VARCHAR(20) | — | 学员姓名 |
| gender | CHAR(1) | 'M' | M=男, F=女 |
| birth_date | DATE | NULL | 出生日期（年龄由此派生，不存储） |
| grade | VARCHAR(20) | NULL | 年级编码 |
| school | VARCHAR(50) | '' | 就读学校 |
| mobile | VARCHAR(20) | — | 手机号（软唯一） |
| counselor_id | BIGINT | NULL | 顾问 → sys_user.id |
| source | VARCHAR(20) | NULL | DIRECT_MARKETING/REFERRAL/ONLINE/OTHER |
| tags | VARCHAR(255) | '' | 标签，逗号分隔 |
| status | VARCHAR(20) | 'ENROLLED' | ENROLLED/SUSPENDED/COMPLETED/LOST |
| total_hours | DECIMAL(10,1) | 0.0 | 累计课时(冗余缓存) |
| remaining_hours | DECIMAL(10,1) | 0.0 | 剩余课时(冗余缓存) |
| last_visit_time | DATETIME | NULL | 最近到校(冗余缓存) |
| completed_at | DATETIME | NULL | 结业时间 |
| remark | VARCHAR(500) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_mobile_deleted (mobile, deleted)`, `idx_name`, `idx_grade`, `idx_status`, `idx_counselor_id`, `idx_source`, `idx_last_visit`

**状态流转**：
```
ENROLLED ⇄ SUSPENDED（手动停课/恢复）
ENROLLED → COMPLETED（所有报班关闭 + 剩余课时=0）
ENROLLED → LOST（手动标记 / 长期未到校）
COMPLETED → ENROLLED（重新激活 / 新报名）
LOST → ENROLLED（新报名自动恢复）
```

**派生字段（不存储）**：年龄、报班数（→edu_class_student）、评分次数（→N05 教评学）、积分（→N04 edu_points_account）、最近到校（→N07 edu_attendance）

## 3. edu_student_parent（家长关联）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| student_id | BIGINT | — | → edu_student.id |
| user_id | BIGINT | NULL | → sys_user.id（可为空，注册后回填） |
| name | VARCHAR(20) | — | 家长姓名 |
| relation | VARCHAR(20) | — | Relation 枚举 |
| mobile | VARCHAR(20) | — | 手机号 |
| sort | INT | 0 | 排序（决定首选联系人） |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_student_mobile (student_id, mobile)`, `idx_user_id`, `idx_mobile`

**规则**：user_id 可为空（家长未注册），通过 mobile 匹配回填；解绑时仅删关联，不删 sys_user。

## 4. edu_student_hours_log（课时变动明细）

> ⚠️ **日志型表**——不继承 BaseEntity，无 update_time/deleted，只追加不修改不删除。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| student_id | BIGINT | — | → edu_student.id |
| course_id | BIGINT | NULL | → edu_course.id |
| enrollment_id | BIGINT | NULL | Batch 2 预留 → edu_enrollment.id |
| class_id | BIGINT | NULL | → edu_class.id |
| change_type | VARCHAR(20) | — | HoursChangeType 枚举 |
| change_amount | DECIMAL(10,1) | — | 正=增加，负=减少 |
| balance_after | DECIMAL(10,1) | — | 变动后余额 |
| source_type | VARCHAR(30) | NULL | HoursSourceType 枚举 |
| source_id | BIGINT | NULL | 来源业务记录 ID |
| operator_id | BIGINT | NULL | → sys_user.id |
| remark | VARCHAR(500) | NULL | 备注 |
| create_time | DATETIME | NOW | 变动时间 |

**索引**：`idx_student_time (student_id, create_time)`, `idx_student_course`, `idx_course_id`, `idx_enrollment_id`, `idx_source (source_type, source_id)`, `idx_create_time`

**变动类型**：

| 值 | 含义 | 符号 | 来源模块 |
|----|------|:---:|----------|
| ENROLL_GAIN | 报名获得 | + | N06 收费确认 |
| CONSUME | 消课扣减 | − | N07 签到 |
| LEAVE_RETURN | 请假返还 | + | N07 请假审批 |
| MAKEUP_CONSUME | 补课消耗 | − | N07 补课签到 |
| REFUND_DEDUCT | 退费扣减 | − | N06 退费审批 |
| GIFT_GAIN | 赠送获得 | + | N06 赠送审批 |
| MANUAL_ADJUST | 手动调整 | ± | 管理员 |

**余额公式**：`当前余额 = SUM(change_amount) WHERE student_id = ? AND course_id = ?`

## 5. edu_prospect（意向学员）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| name | VARCHAR(20) | — | 姓名 |
| gender | CHAR(1) | 'U' | M/F/U |
| birth_date | DATE | NULL | 出生日期 |
| grade | VARCHAR(20) | NULL | 年级 |
| school | VARCHAR(50) | '' | 学校 |
| mobile | VARCHAR(20) | — | 联系电话 |
| parent_name | VARCHAR(20) | — | 家长姓名 |
| parent_relation | VARCHAR(20) | — | Relation 枚举 |
| parent_mobile | VARCHAR(20) | — | 家长手机 |
| wechat_nickname | VARCHAR(50) | '' | 微信昵称 |
| intended_course_id | BIGINT | NULL | → edu_course.id |
| interest_level | VARCHAR(10) | 'MEDIUM' | HIGH/MEDIUM/LOW |
| source | VARCHAR(20) | 'OTHER' | SourceChannel 枚举 |
| counselor_id | BIGINT | NULL | → sys_user.id |
| follow_status | VARCHAR(20) | 'NEW' | NEW/CONTACTED/TRIAL/CONVERTED/LOST |
| trial_lesson_count | INT | 0 | 体验课次数 |
| last_followup_date | DATETIME | NULL | 最近跟进(冗余) |
| converted_student_id | BIGINT | NULL | 转化后 → edu_student.id |
| remark | VARCHAR(500) | NULL | 备注 |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`uk_mobile_deleted`, `idx_follow_status`, `idx_counselor_id`, `idx_intended_course`, `idx_source`, `idx_last_followup`, `idx_converted_student`

**状态流转**：`NEW → CONTACTED → TRIAL → CONVERTED / LOST`

**转化数据继承**：

| Prospect 字段 | → Student/Parent 字段 |
|---------------|----------------------|
| name, gender, birth_date, grade | → edu_student |
| mobile | → edu_student.mobile |
| counselor_id, source | → edu_student |
| parent_name, parent_relation, parent_mobile | → edu_student_parent |

## 6. edu_prospect_followup（跟进记录）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT PK AUTO | — | 主键 |
| prospect_id | BIGINT | — | → edu_prospect.id |
| method | VARCHAR(20) | — | PHONE/WECHAT/FACE_TO_FACE |
| content | VARCHAR(1000) | — | 跟进内容 |
| followup_date | DATETIME | — | 跟进时间（支持补录） |
| next_plan | VARCHAR(500) | NULL | 下次计划 |
| operator_id | BIGINT | — | → sys_user.id |
| create_by/update_by | VARCHAR(64) | '' | 操作人 |
| create_time/update_time | DATETIME | NOW | — |
| deleted | TINYINT | 0 | 逻辑删除 |

**索引**：`idx_prospect_time (prospect_id, followup_date DESC)`, `idx_operator_id`

**副作用**：新增跟进时自动更新 `edu_prospect.last_followup_date`；首次跟进时 `follow_status` 自动从 NEW→CONTACTED。
