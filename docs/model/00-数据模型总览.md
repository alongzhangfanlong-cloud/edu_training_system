> **版本**：v1.0 | **日期**：2026-07-18
>

---

## 1. 设计规范

| 规范 | 规则 | 来源 |
|------|------|------|
| 表前缀 | `edu_` | PRD §9.3 |
| 引擎/字符集 | InnoDB / utf8mb4 | N08 edu-schema.sql |
| 业务表 | 继承 `BaseEntity`：`id`(BIGINT AUTO), `create_time`, `update_time`, `deleted` | 项目惯例 |
| 日志型表 | 不继承 BaseEntity，无 update_time/deleted，只追加 | N08 sys_oper_log |
| 开关状态 | TINYINT：1=正常/启用, 0=停用/禁用 | N08 sys_user.status |
| 业务状态 | VARCHAR(20) 存储枚举 `name()` | 团队偏好 |
| 外键 | 无 JPA 注解，Mapper/Service 层处理 | MyBatis-Plus |
| 非DB字段 | `@TableField(exist = false)` | MyBatis-Plus |

## 5. 关键设计决策

| 决策 | 说明 |
|------|------|
| `current_count` 冗余存储 | 班级列表高频查询，在增删学员时原子 +/- 维护 |
| `total_hours`/`remaining_hours` 冗余缓存 | 学员列表高频查询，由 hours_log 写入时同步更新 |
| `hours_log` 只追加不可变 | 银行流水模式，无 update_time/deleted |
| 枚举用 VARCHAR 存 name() | 语义自解释，避免魔术数字 |
| 手机号软唯一 `(mobile, deleted)` | 删除后可复用，未删除记录内唯一 |
| 派生字段不存储 | 年龄、报班数、评分次数、积分、最近到校 |

## 7. 跨模块引用关系图

```
N08 (sys_user) ──────┬── N02.edu_student (counselor_id)
                     ├── N02.edu_student_parent (user_id)
                     ├── N02.edu_prospect (counselor_id)
                     ├── N02.edu_student_hours_log (operator_id)
                     ├── N03.edu_class (teacher_id)
                     └── N03.edu_resource (upload_by)

N03.edu_subject ──────── N03.edu_course (subject_id)

N03.edu_course ─────┬── N03.edu_class (course_id)
                    ├── N02.edu_student_hours_log (course_id)
                    └── N02.edu_prospect (intended_course_id)

N03.edu_classroom ───── N03.edu_class (classroom_id)

N03.edu_class ─────┬── N03.edu_class_schedule_rule (class_id, 1:1)
                   └── N03.edu_class_student (class_id)

N02.edu_student ─────── N03.edu_class_student (student_id) ★唯一跨模块桥接
                   ├── N02.edu_student_parent (student_id)
                   ├── N02.edu_student_hours_log (student_id)
                   └── N02.edu_prospect (converted_student_id)
```

N08 (sys_user) ──────── N04.edu_points_redemption (operator_id)

N02.edu_student ───┬── N04.edu_points_account (student_id, 1:1)
                   ├── N04.edu_points_log (student_id)
                   └── N04.edu_points_redemption (student_id)
```

> **核心原则**：N03 不直接依赖 N02 的表，所有 N02↔N03 关联仅通过 `edu_class_student` 桥接表。N04 积分模块接收来自 N05（评价积分）的事件写入，本身不反向依赖业务模块。`edu_points_log` 的 `source_id` 为多态外键。
