## 三、本次修复的问题

### 1. 学费管理 payTime 字段为空

- **现象**：`/api/v1/tuition/fees/list` 返回的 `payTime` 字段全部为 null
- **根因**：Maven 本地仓库中的旧 JAR 包仍包含 `@TableField(exist = false)` 注解，导致 MyBatis-Plus 未映射 `pay_time` 数据库列
- **修复**：
  - 全量执行 `mvn install -DskipTests` 重新编译安装所有模块
  - 补充 PARTIAL 状态记录的 `pay_time` 数据（`UPDATE edu_tuition_fee SET pay_time=create_time WHERE amount_paid > 0 AND pay_time IS NULL`）
- **涉及文件**：[EduTuitionFee.java](file:///d:/ai/edu_training_system/education-store-server/edu-modules/edu-module-tuition/src/main/java/com/education/store/module/tuition/entity/EduTuitionFee.java)

### 2. 教师工作台教室名称取值错误

- **现象**：教师工作台今日课表显示的教室名称与排课记录中的教室不一致
- **根因**：后端 `getSchedule()` 方法使用班级默认教室（`clazz.getClassroomId()`）而非排课记录的教室（`schedule.getRoomId()`）
- **修复**：优先使用排课记录的 `roomId`，如果为空再使用班级默认教室
- **涉及文件**：[TeacherDashboardServiceImpl.java](file:///d:/ai/edu_training_system/education-store-server/edu-modules/edu-module-teacher-dashboard/src/main/java/com/education/store/module/teacher/dashboard/service/impl/TeacherDashboardServiceImpl.java#L205-L235)

### 3. 管理员密码重置

- **现象**：admin 账户密码无法登录
- **修复**：将 admin 密码重置为 `123456`（与 teacher01 相同的 bcrypt hash）

## 四、业务闭环验证说明

### 4.1 业务流程闭环

```
潜客管理 → 报名管理 → 学员管理 → 班级管理 → 排课管理 → 考勤管理
     ↓           ↓          ↓          ↓          ↓          ↓
  潜客(7)    报名(5)    学员(9)    班级(3)    排课(22)   签到(2)
                                    ↓          ↓          ↓
                               课程管理(14)   ↓     学生请假(3)
                                    ↓          ↓     教师请假(2)
                               课件资源(10)  考试(3)     ↓
                                    ↓          ↓          ↓
                               科目管理(9)  教学评(4)  作业管理(4)
                                              ↓          ↓
                                           学评教(6)  作业提交(2)
                                                          ↓
                                                    学费管理(5) → 退费(1) → 赠送课时(1)
                                                          ↓
                                                    薪资管理(2) → 课酬标准(4)
                                                          ↓
                                                    积分管理(4)
```
