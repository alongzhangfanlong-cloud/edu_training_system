# N05 家校沟通

> **编码**：N05 | **菜单名**：家校沟通 | **优先级**：P1
> **后端模块**：`edu-module-teaching`
> **PC 端路由**：`/teaching`
> **版本**：v3.0 | **日期**：2026-07-14

---

## 1. 模块概述

### 1.1 模块定位

家校沟通模块是连接教师与家长的教学互动层，覆盖课后作业布置与批改、教师评价学生（教评学）、学生评价教师（学评教）三大子模块。核心价值在于建立教学透明度，降低家校沟通成本。

### 1.2 三个子模块总览

| 编码 | 子页名称 | 路由 | 来源 | 核心用户 | 核心价值 |
|:----:|----------|------|:----:|----------|----------|
| N05.1 | 课后作业 | `/teaching/homework` | M9 §C | 教师布置，家长查看 | 家长明确作业内容，降低沟通成本 |
| N05.2 | 教评学 | `/teaching/evaluation` | M9 §A | 教师录入，家长查看 | 家长了解孩子课堂表现，建立教学透明度 |
| N05.3 | 学评教 | `/teaching/teacher-evaluation` | **新增** | 家长提交，管理员查看汇总 | 教师获得教学反馈，促进教学质量提升 |

### 1.3 业务闭环

```
排课(N03.2) → 上课签到(N07) → 教师评价学生/教评学(N05.2)
  │                                    │
  │                                    ▼
  │              家长查看评价 → 家长评价教师/学评教(N05.3)
  │                                    │
  ▼                                    ▼
布置作业(N05.1) ←→ 学生提交 → 教师批改 → 家长看反馈
                                        │
                                        ▼
                                  积分奖励(N04)
```

### 1.4 访问角色

| 角色 | 数据范围 |
|------|---------|
| **运营主管/校长** | 查看全部数据（学评教汇总统计） |
| **教师** | 仅查看/操作所教班级的数据；学评教中不可见匿名评价的学生身份 |
| **家长** | 仅查看自己孩子的数据（小程序端）；学评教提交功能（小程序端） |

### 1.5 跨模块引用

| 本模块引用 | 对应模块 | 说明 |
|-----------|----------|------|
| 课程/科目 | N03.3 课程管理 | 作业关联课程、评价关联课程 |
| 班级 | N03.4 班级管理 | 作业关联班级、评价关联班级 |
| 排课记录 | N03.2 排课计划/课程表 | 评价和作业可关联排课记录 |
| 学生 | N02 学员管理 | 评价对象、成绩归属 |
| 积分 | N04 积分商城 | 教评学可附带积分奖励 |

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |

```

  班级下拉 → 选班级 → 课程下拉 → 排课下拉（该班级+课程下已完成排课，日期倒序）
```

**编辑行为**：
- 所有字段均可修改（包括关联信息）
- 编辑后保存 → 记录 `is_updated = 1` → 家长端显示"（已更新）"标记
- 如果家长已查看过，编辑保存后家长端对应的作业卡片刷新为"作业内容已更新"

**发布行为**：
- 点击「发布」→ 全量表单校验 → 调用 API → 成功后关闭抽屉，刷新列表
- 发布后关联班级所有学生家长在小程序端可见
- 发布时触发微信订阅消息推送（家长已订阅"作业通知"时）

| 属性 | 说明 |
|------|------|

### 2.8 状态处理

| 场景 | 处理 |
|------|------|
| 关联排课已取消 | 作业保留，`schedule_id` 置为 null，详情页标注"关联排课已取消" |
| 关联班级已删除 | 作业保留，班级名称显示"已删除班级"，不可编辑关联 |
| 附件上传中 | 进度条显示，上传中「发布」按钮置灰 |
| 附件上传失败 | 红色"上传失败"标记，可点击重新上传 |
| 编辑后家长已读 | 家长端该作业卡片显示"（已更新）"标记，点击后清除标记 |
| 列表空状态 | "暂无作业记录。点击「布置作业」开始。" |

### 2.5 学生提交作业（小程序家长端）

家长查看作业后，可拍照上传提交作业。

**流程**：
```
家长小程序查看作业 → 点击「提交作业」→ 拍照/选择图片上传
  → 可选添加文字备注 → 提交
  → 教师端看到提交记录
```

**业务规则**：

| 场景 | 行为 |
|------|------|
| 提交截止 | 不做硬性截止时间，延迟提交仅标记"迟交" |
| 重新提交 | 在教师批改前可覆盖提交（教师批改后不可修改） |
| 多人提交 | 一个家长关联多个孩子时，各自独立提交 |
| 不提交 | 非必须，不提交不影响任何流程 |

### 2.6 教师批改作业（PC 端）

教师查看学生提交的作业，可打分 + 写评语。

**流程**：
```
教师查看作业 → 点击「已提交列表」→ 查看学生提交的图片
  → 打分（1-5 星或分数）+ 文字评语（可选）→ 提交
  → 家长端收到反馈通知
```

**评分规则**：
- 综合分：一个总体分（1-5 星），不细分维度
- 评语：文字，可选，最多 500 字
- 批改后学生不可重新提交

**评语示例**：
```
教师评语：字迹有进步，但第三题计算错误较多，建议重新练习乘法口诀。
```

## 3. N05.2 教评学

### 3.1 页面结构

```

├─────────────────────────────────────────────────────────┤

│  ┌────┬──────┬──────┬──────┬──────┬──────┬──────┬────┐ │

```

### 3.2 搜索栏

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 评价内容 | 输入框 | 模糊搜索课堂总结或学生评语中的关键词 |
| 课次 | 下拉 | 按关联排课记录筛选 |
| 教师 | 下拉 | 按评价教师筛选；管理员可见全部教师，教师仅可见自己 |
| 学生 | 下拉（远程搜索） | 按被评价学生筛选 |
| 日期范围 | 日期范围选择器 | 按上课日期筛选 |
| 评价状态 | 下拉 | 全部 / 已评 / 待评 / 草稿 |

### 3.3 工具栏

教评学页面不以"新增评价"为入口，评价基于已上课的排课记录自动生成列表行。教师从列表的「评价」按钮进入表单。

| 按钮 | 权限 | 说明 |
|------|------|------|
| 批量导出 | `teaching:evaluation:export` | 导出当前筛选条件下的评价记录为 Excel（P1 迭代） |

### 3.4 数据表格

| 字段 | 说明 | 宽度 |
|------|------|:----:|
| 序号 | 自动编号 | 60px |
| 学员 | 被评价学生姓名 | 100px |
| 课次标题 | 格式"课程名+班级简称"，如"数学三(1)班" | 150px |
| 上课日期 | 关联排课的日期 yyyy-MM-dd | 120px |
| 点评得分 | 星级展示（★ 实心 / ☆ 空心），附分数如"★★★★☆ 4分" | 130px |
| 点评内容 | 文字评语前 30 字，超出省略；无评语时显示"—" | 200px |
| 点评老师 | 教师姓名 | 100px |
| 评价状态 | 已评（绿色）/ 待评（灰色）/ 草稿（橙色） | 90px |
| 奖励积分 | 附带积分值，无则显示"—" | 80px |
| 更新时间 | yyyy-MM-dd HH:mm | 160px |
| 操作 | 见下方操作规则 | 120px |

**操作按钮规则**：

| 状态 | 授课教师 | 其他教师 | 运营/校长 |
|------|:--------:|:--------:|:---------:|
| 待评 | 「评价」 | — | 「查看」（只读提示） |
| 草稿 | 「继续编辑」| — | — |
| 已评 | 「查看」 | 「查看」 | 「查看」 |
| 删除 | 仅草稿/待评可删 | ❌ | ❌ |

**数据来源核心逻辑**：

列表数据来源为**已完成上课的排课记录**（排课日期 ≤ 当天），而非预先创建的评价记录。系统按排课记录查询是否有对应评价，有则展示评价状态，无则展示「待评」。

- 教师：展示自己所教班级的排课记录
- 运营/校长：展示全部排课记录

**排序规则**：按上课日期倒序，同一天按上课时段排序。

### 3.5 评价表单页（新建 / 编辑草稿）

| 属性 | 说明 |
|------|------|
| 触发 | 评价表单页点击「暂存草稿」按钮 |

- 教师仅可查看自己提交的评价详情
- **家长端仅可查看自己孩子的个人评价**（不展示课堂总结、不展示其他学生评价）

### 3.9 状态处理

| 场景 | 处理 |
|------|------|

| 提交时网络异常 | Toast 错误提示，表单数据保留不丢失 |
| 小程序端 | 同 PC 端功能但在"动态 Tab"中以卡片形式展示 |

**触发时机**：每节课后，教师完成教评学评价后，家长可在小程序评价该课教师

**评价窗口**：课后 7 天内可提交，超过窗口期不可评价

**提交后修改**：提交后 24 小时内可修改，之后锁定

**提交流程**：
1. 进入评价页面（自动关联对应课次）
2. 多维度评分（各 1-5 星）：教学态度 / 课堂氛围 / 孩子喜欢程度 / 沟通及时性
3. 文字评语（可选，最多 500 字）
4. 匿名选项：复选框，默认不勾选。勾选后教师端显示"匿名用户"
5. 提交
4. 评价内容（选填，最长 500 字）
5. 是否匿名（开关，默认关闭）
6. 提交

**约束**：
- 同一学生对同一教师同一课次只能评价一次
- 教师必须先完成教评学（评价该学生），家长才能对该课次进行学评教
- 提交后不可修改

| G01 | 所有数据变更操作使用逻辑删除（`is_deleted = 1`），不物理删除 |

| G03 | 家长仅可查看自己关联孩子的数据，后端通过 Token 提取家长身份而非前端传参 |
| G04 | 关联数据（排课/班级/学生/课程）被删除后，业务记录保留但关联字段置 null，展示时标注"已删除" |
| G05 | 所有教师端操作记录操作日志（`@Log` 注解），用于教学质量追溯 |
| G06 | 微信订阅消息推送失败不影响业务操作成功，静默降级 |

## 12. 异常边界

### 12.1 数据异常

| 异常场景 | 处理策略 |
|---------|---------|
| 排课被删除 | 关联评价不可编辑，仅可查看历史；关联作业保留但 `schedule_id` 置 null；关联学评教保留 |
| 班级被删除 | 关联数据保留，班级名称显示"已删除班级"，筛选时仍可搜到 |
| 学生从班级移除 | 历史记录保留，新排课不再出现在待评价名单 |
| 学生被删除 | 历史记录保留，姓名显示"已删除学生"，成绩不参与统计 |
| 教师被删除/离职 | 历史记录保留，姓名显示"已离职教师" |
| 课程被删除 | 关联数据保留，课程名称显示"已删除课程" |
| 考试成绩被删除 | 已删除成绩不参与统计计算 |

### 12.2 并发异常

| 异常场景 | 处理策略 |
|---------|---------|
| 同一排课被多次提交评价 | 数据库唯一约束 + 接口乐观锁 |
| 同一考试被重复录入 | 数据库唯一约束 + 前端禁用重复提交 |
| 家长同时查看导致查看次数溢出 | `UPDATE ... SET view_count = view_count + 1` 原子更新 |

### 12.3 边界条件

| 边界条件 | 处理策略 |
|---------|---------|
| 班级无学生时录入成绩 | 前端提示"该班级尚无学生"，阻止进入录入页 |
| 满分设为 0 | 前端校验，满分必须 ≥ 1 |
| 分数超过满分 | 前端校验阻止 + 后端二次校验返回错误 |
| 所有学生缺考 | 允许提交，统计显示"无有效数据" |
| 评语超过字数限制 | 前端实时计数阻止 + 后端截断 |
| 附件数量/大小超限 | 前端阻止选择 + 后端校验返回错误 |
| 同一家长多个孩子 | 动态时间线混合展示，每条标注孩子姓名 |
| 家长未绑定手机号 | 无法关联学生 → 各页面显示空状态 |

### 12.4 隐私保护

| 规则 | 说明 |
|------|------|
| 教评学家长视图 | 仅可查看自己孩子的个人评价，不展示课堂总结、其他学生评价 |
| 学评教匿名评价 | 教师不可见学生身份，管理员可见但标记匿名 |
| 成绩家长视图 | 仅可见自己孩子成绩+排名+班级均分，不可见其他学生信息 |
| 后端越权防护 | 家长端接口通过 Token 提取家长 ID 关联学生，非前端传参 |

### 12.5 推送异常

| 异常场景 | 处理策略 |
|---------|---------|
| 微信订阅消息推送失败 | 不影响业务操作成功，静默忽略 |
| 家长关闭订阅通知 | 数据正常产生，仅不推送；可在小程序动态 Tab 手动查看 |
| 微信接口限流 | MVP 阶段失败降级（记录日志）；P1 迭代引入消息队列缓冲 |
