## 1. 项目概述

### 1.1 产品定位

**新艺智源管理平台**是一款面向艺术/学科培训机构的在线教育课程展示与交易平台，覆盖学生/家长/教师/管理员全角色，提供从招生获客、教务排课、考勤签到、家校沟通到财务核算的一站式解决方案。

### 1.2 目标用户

| 角色 | 标识 | 核心需求 |
|------|:----:|----------|
| **校长** | PRINCIPAL | 全局数据监控、财务审批、战略决策 |
| **运营主管** | ADMIN | 日常教务运营、招生管理、财务对账 |
| **教师** | TEACHER | 课表查看、签到操作、教学评价、作业布置 |
| **家长** | PARENT | 孩子动态查看、请假申请、课程浏览、成绩查询 |

### 1.3 产品形态

- **PC 管理后台**（Vue 3 + Element Plus）：运营主管/校长/教师
- **微信小程序**（uni-app）：家长端 + 教师端

## 5. 核心业务流

### 5.1 招生→收费→入账

```
意向学员 (N02.2) → 转为在学 → 报名录入 (N06) → 收费确认 (N06)
  → 课时自动入账 (N02.5) → 排课 (N03) → 考勤消课 (N07)
```

### 5.2 消课→课酬→统计

```
考勤签到 (N07) → 消课记录 → 月度汇总 → 课酬计算 (N06.2)
  → 授课统计 (N06.3) → 工作台营收卡片 (N01)
```

### 5.3 教学→评价→积分 闭环

```
排课 (N03) → 上课签到 (N07) → 教师评价学生/教评学 (N05.2)
  → 学生评价教师/学评教 (N05.3) → 积分奖励 (N04)
```

### 5.4 请假→课时返还

```
家长发起请假 (N07/小程序) → 教师/运营确认 → 自动考勤标记
  → 免费次数内返还课时 / 超出则扣除 (N02.5)
```

## 9. 全局设计约定

### 9.1 统一响应格式

```json
{"code": 200, "msg": "ok", "data": {}}
```

### 9.2 分页参数

```json
{"pageNum": 1, "pageSize": 10}
```

### 9.3 数据库规范

- 表名：`edu_` 前缀 + 下划线分隔（如 `edu_student`）
- 每表必有：`id`、`create_time`、`update_time`、`deleted`
- 逻辑删除，InnoDB 引擎，utf8mb4 字符集

### 9.4 权限码格式

`{模块}:{子模块}:{操作}` — 如 `student:enrolled:list`、`attendance:signin:batch`

### 9.5 前端路由命名

- 列表页：`/{module}/{entity}` — 如 `/student/enrolled`
- 详情页：`/{module}/{entity}/:id`
- 组件目录以 PascalCase 命名，页面主文件为 `index.vue`
