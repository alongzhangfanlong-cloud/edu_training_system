# 文件上传 · API 文档

> 通用模块，不属于任何一个业务 PRD。所有模块的文件上传统一下载。

**Base Path**：`/api/v1/files`

---

## 端点清单

| # | 方法 | 路径 | 说明 | 认证 |
|:--|:----|------|------|:--:|
| 1 | `POST` | `/upload` | 上传文件 | ✅ JWT |
| 2 | `GET` | `/{dateDir}/{storedName}?name=` | 下载文件 | — |

---

## 1. 上传文件

```
POST /api/v1/files/upload
Content-Type: multipart/form-data
Authorization: Bearer <token>
```

**表单字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `file` | MultipartFile | ✅ | 上传的文件 |

**存储规则**：
- 文件命名为 `UUID.ext`（去横线）
- 按月份分目录：`{uploadPath}/yyyyMM/UUID.ext`
- 默认 `uploadPath` 为 `upload/`（可通过 `edu.upload-path` 配置）

**响应**：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "fileName": "课程封面.jpg",
    "filePath": "202607/a1b2c3d4e5f6.jpg",
    "fileSize": 245760,
    "fileType": ".jpg",
    "storedName": "a1b2c3d4e5f6.jpg"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `fileName` | string | 原始文件名 |
| `filePath` | string | 相对存储路径（用于下载和数据库存储） |
| `fileSize` | long | 文件大小（字节） |
| `fileType` | string | 扩展名（含点号，如 `.jpg`） |
| `storedName` | string | 存储文件名（UUID 格式） |

---

## 2. 下载文件

```
GET /api/v1/files/{dateDir}/{storedName}?name=课程封面.jpg
```

**路径参数**：

| 参数 | 说明 |
|------|------|
| `dateDir` | 日期目录（如 `202607`），来自上传返回的 `filePath` 第一段 |
| `storedName` | 存储文件名（UUID 格式），来自上传返回的 `filePath` 第二段 |

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| `name` | string | — | 下载时的文件名（否则用 storedName） |

**响应**：二进制文件流，`Content-Type: application/octet-stream`，`Content-Disposition: attachment`。

**示例**：
```
GET /api/v1/files/202607/a1b2c3d4e5f6.jpg?name=课程封面.jpg
```

---

## 使用场景

文件上传后被其他业务模块引用：

| 模块 | 使用方式 |
|------|----------|
| N03 教务系统 | 课程封面图、课件资源（`EduCourse.imageUrl`、`EduResource.fileUrl`） |
| N04 积分商城 | 礼品图片（`EduPointsGift.imageUrl`） |
| N05 家校沟通 | 作业附件（`EduHomeworkAttachment.fileUrl`） |
| N08 系统管理 | 用户头像（`SysUser.avatar`） |

> **注意**：本接口只负责文件的物理上传下载，不管理业务关联。文件的业务归属由各模块的 Service 层维护。
