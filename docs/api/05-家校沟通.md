## 1. 教师档案 — EduTeacherController

> 此 Controller 在 Phase 6 新增（Fix 1），对应的 `edu_teacher` 表独立于 `sys_user`，
> 解决 Dashboard 统计教资人数时直接查 `sys_user` 不准确的问题。

**Base Path**：`/api/v1/teaching/teacher`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/list` | 教师列表 | `teaching:teacher:list` |
| 2 | `GET` | `/{id}` | 教师详情 | `teaching:teacher:query` |
| 3 | `POST` | `/` | 新增教师 | `teaching:teacher:add` |
| 4 | `PUT` | `/` | 编辑教师 | `teaching:teacher:edit` |
| 5 | `DELETE` | `/{ids}` | 批量删除（数组） | `teaching:teacher:delete` |

### 1.1 教师列表

```
GET /api/v1/teaching/teacher/list
```

返回 `List<EduTeacher>`（不分页，全量）。

### 1.2 教师详情

```
GET /api/v1/teaching/teacher/{id}
```

### 1.3 新增教师

```
POST /api/v1/teaching/teacher
Content-Type: application/json

{
  "userId": 10001,
  "name": "张老师",
  "phone": "13800138000",
  "status": "ACTIVE",
  ...
}
```

### 1.4 编辑教师

```
PUT /api/v1/teaching/teacher
Content-Type: application/json

{
  "id": 1,
  "status": "INACTIVE",
  ...
}
```

### 1.5 批量删除

```
DELETE /api/v1/teaching/teacher/1,2,3
```

路径参数 `{ids}` 为逗号分隔的 Long 数组（如 `1,2,3`）。

> **关联说明**：Dashboard 的 `getStatistics()` 查 `edu_teacher WHERE status='ACTIVE'` 统计在职教师人数。

## 2. 作业提交批改 — EduHomeworkSubmissionController

> 此 Controller 在 Phase 6 新增（Fix 4），对应 `edu_homework_submission` 表。
> 与 `HomeworkController`（作业布置/编辑/删除）分离，独立管理提交和批改流程。

**Base Path**：`/api/v1/teaching/homework-submission`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/list` | 提交列表 | `teaching:homework:list` |
| 2 | `GET` | `/{id}` | 提交详情 | `teaching:homework:list` |
| 3 | `PUT` | `/{id}/grade` | 批改作业 | `teaching:homework:edit` |

### 2.1 提交列表

```
GET /api/v1/teaching/homework-submission/list
```

返回 `List<EduHomeworkSubmission>`（不分页）。

### 2.2 提交详情

```
GET /api/v1/teaching/homework-submission/{id}
```

返回单个提交记录，含学生提交内容、附件等。

### 2.3 批改作业

```
PUT /api/v1/teaching/homework-submission/{id}/grade
Content-Type: application/json

{
  "score": 95,
  "teacherComment": "完成优秀，继续努力",
  "status": "GRADED"
}
```

教师端调用，对学生的作业提交进行打分和评语。

> **流程**：教师布置作业（HomeworkController） → 学生提交（本 Controller） → 教师批改（本 Controller grade 端点） → 家长查阅（`edu_parent_view_log` 表记录）
