# N01 工作台 · API 接口

> Controller: `DashboardController` | Base: `/api/v1/dashboard` | 权限前缀: `dashboard:*`

---

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/dashboard/user-info` | 获取欢迎区信息（用户名、角色、头像） | `dashboard:dashboard:view` |
| 2 | `GET` | `/dashboard/statistics` | 获取统计卡片（学员数/教资/今日课次/本月营收） | `dashboard:dashboard:view` |
| 3 | `GET` | `/dashboard/calendar?month=` | 获取排课日历数据（月/周/日视图） | `dashboard:dashboard:view` |
| 4 | `GET` | `/dashboard/schedule/{scheduleId}/students` | 某排课的学生签到详情列表 | `dashboard:dashboard:view` |
| 5 | `GET` | `/dashboard/todos` | 获取待办提醒（待审批请假/退费/补交作业） | `dashboard:dashboard:view` |
| 6 | `GET` | `/dashboard/enrollment-stats?month=` | 本月报名统计 | `dashboard:dashboard:view` |
| 7 | `GET` | `/dashboard/weekly` | 周课次分布（备用接口） | `dashboard:dashboard:view` |
| 8 | `GET` | `/dashboard/monthly-hours` | 月消课课时 + 趋势（备用接口） | `dashboard:dashboard:view` |

### 关键说明

- `user-info`：从 JWT Token 中解析当前用户身份，返回用户名、角色列表、头像 URL
- `statistics`：4 张卡片数据 — 在学学员数 (`edu_student.status='ENROLLED'`)、在职教师数 (`edu_teacher.status='ACTIVE'`)、今日课次数 (`edu_schedule`)、本月营收 (`edu_tuition_fee.pay_time`)
- `todos`：合并查询，取前 3 条 — `edu_leave_teacher` + `edu_leave_student` + `edu_tuition_refund`（PENDING 状态）
- `calendar`：Query 参数 `month=2026-07`，返回当月每日课次列表
