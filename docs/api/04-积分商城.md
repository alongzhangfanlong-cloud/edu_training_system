# N04 积分商城 · API 接口

> 3 个 Controller | 权限前缀: `points:*`

---

## 1. 积分礼品 — PointsGiftController

**Base**: `/api/v1/points/gift`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/list?page=&pageSize=&keyword=&status` | 礼品列表（分页） | `points:gift:list` |
| 2 | `GET` | `/{id}` | 礼品详情 | `points:gift:list` |
| 3 | `POST` | `/` | 新增礼品 | `points:gift:add` |
| 4 | `PUT` | `/{id}` | 编辑礼品（不可改库存，库存通过补货接口调整） | `points:gift:edit` |
| 5 | `PUT` | `/{id}/status` | 启用/禁用礼品 | `points:gift:edit` |
| 6 | `DELETE` | `/{id}` | 删除礼品（有关联兑换记录时拒绝） | `points:gift:delete` |

---

## 2. 兑换记录 — PointsRedemptionController

**Base**: `/api/v1/points/redemption`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/list?page=&pageSize=&studentId=&status=` | 兑换记录列表（分页） | `points:redemption:list` |
| 2 | `GET` | `/{id}` | 兑换记录详情 | `points:redemption:list` |
| 3 | `POST` | `/` | 兑换礼品（扣积分 + 减库存，@Transactional） | `points:redemption:list` |
| 4 | `POST` | `/{id}/claim` | 标记已领取（核销，PENDING_CLAIM → CLAIMED） | `points:redemption:claim` |
| 5 | `POST` | `/{id}/cancel` | 取消兑换（退积分 + 恢复库存，终态不可逆） | `points:redemption:cancel` |

### 状态机

```
PENDING_CLAIM ──claim──▶ CLAIMED（终态）
      │
      └──cancel──▶ CANCELLED（终态，退积分+恢复库存）
```

### 库存防超卖

```sql
UPDATE edu_points_gift
SET stock_remaining = stock_remaining - ?
WHERE id = ? AND stock_remaining >= ?
```

条件 UPDATE + 受影响行数判断，不依赖乐观锁版本号。

## 3. 积分账户 — PointsAccountController

**Base**: `/api/v1/points/account`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/{studentId}` | 查询学生积分余额（total_earned/total_spent/balance） | `points:account:query` |
| 2 | `GET` | `/log/{studentId}?page=&pageSize=` | 查询学生积分日志（只追加，不可变） | `points:account:query` |
| 3 | `POST` | `/admin/adjust` | 管理员手动调整积分（产生 ADJUST 类型日志） | `points:account:adjust` |

> 积分日志表 `edu_points_log` 只追加（无 `update_time`/`deleted`），所有变动可追溯。
