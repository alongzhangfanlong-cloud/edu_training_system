# N08 系统管理 · API 接口

> 11 个 Controller | 权限前缀: `system:*`

---

## 1. 认证 — AuthController

**Base**: `/api/v1/auth`

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `POST` | `/login` | 用户名密码登录 → 返回 JWT Token | 公开 |
| 2 | `POST` | `/refresh` | 刷新 Token | 公开（需传 refreshToken） |
| 3 | `POST` | `/logout` | 退出登录 | 登录 |
| 4 | `PUT` | `/password` | 修改密码（需旧密码验证） | 登录 |

## 2. 用户管理 — SysUserController

| # | 方法 | 路径 | 说明 | 权限 |
