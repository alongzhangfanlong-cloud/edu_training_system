# N09 教师端 · API 接口

> Controller: `TeacherDashboardController` | Base: `/api/v1/teacher/dashboard` | 权限前缀: `teacher:*`

---

| # | 方法 | 路径 | 说明 | 权限 |
|:--|:----|------|------|------|
| 1 | `GET` | `/teacher/dashboard/user-info` | 获取欢迎区信息（教师姓名、所教班级数、今日课次） | `teacher:dashboard:view` |
| 2 | `GET` | `/teacher/dashboard/statistics` | 获取统计卡片（所教学生数、待批作业数、本月课酬） | `teacher:dashboard:view` |
| 3 | `GET` | `/teacher/dashboard/schedule?date=` | 获取今日课表（含班级、科目、教室、时间） | `teacher:dashboard:view` |
| 4 | `GET` | `/teacher/dashboard/schedule/{scheduleId}/students` | 某排课的班级学生名单 + 签到状态 | `teacher:dashboard:view` |
| 5 | `GET` | `/teacher/dashboard/todos` | 获取待办数据（待批作业数、待填评价数、待处理请假） | `teacher:dashboard:view` |
