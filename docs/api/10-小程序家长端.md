## 2. 孩子信息

### 获取关联孩子列表
```
GET /api/v1/parent/children
Authorization: Bearer {token}
```
**返回**:
```json
[{
  "studentId": 1, "name": "张三", "grade": "三年级",
  "gender": 1, "school": "实验小学",
  "totalHours": 100, "remainingHours": 32, "status": 1
}]
```

### 获取孩子详情
```
GET /api/v1/parent/children/{studentId}
```
**返回**: 基本信息 + 在读班级列表

---

## 3. 首页动态聚合

### 时间线
```
GET /api/v1/parent/timeline?days=30&limit=20
```
**返回**: 按孩子分组的混合事件流（SIGN_IN / EVALUATION / HOMEWORK / EXAM），按时间倒序

## 4. 考勤

### 考勤记录
```
GET /api/v1/parent/children/{studentId}/attendance?page=1&pageSize=20&yearMonth=2026-07
```
**返回**: 分页考勤记录（status / statusText / signinTime）

### 月考勤统计
```
GET /api/v1/parent/children/{studentId}/attendance-stats
```
**返回**: `{ "present": 18, "late": 1, "absent": 0, "leave": 1, "attendanceRate": 95 }`

## 5. 作业

```
GET /api/v1/parent/children/{studentId}/homework?page=1&pageSize=10
```
**返回**: 作业列表（通过班级关联），含 title / content / teacherId / createTime

## 6. 请假

### 请假记录
```
GET /api/v1/parent/children/{studentId}/leaves
```
**返回**: `[{ "id", "leaveDate", "leaveType", "reason", "status", "rejectReason", "createTime" }]`

### 发起请假
```
POST /api/v1/parent/children/{studentId}/leaves
Content-Type: application/json
{ "leaveDate": "2026-07-25", "leaveType": 1, "reason": "身体不适" }
```
**返回**: `{ "id": 1, "status": 0 }`（0=待审批）

## 权限模型

所有家长端 API 使用 `@PreAuthorize("@ss.hasPermi('student:parent:query')")` 进行角色校验。

每个涉及具体孩子的端点都会执行 `isParentOf(userId, studentId)` 校验，确保家长只能查看自己关联孩子的数据。

---

## 数据隔离

- 家长 ↔ 孩子：通过 `edu_student_parent` 表关联（手机号匹配 + userId 绑定）
- 作业查询链路：家长 → 孩子 → `edu_class_student` → `edu_homework.classId`
- 课表查询链路：家长 → 孩子 → `edu_class_student` → `edu_schedule.classId`
- 评价/成绩：直接按 `studentId` 查询
