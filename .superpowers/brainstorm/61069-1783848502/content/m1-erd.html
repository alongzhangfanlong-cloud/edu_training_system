M1 课程管理 · 数据模型

5 张表，核心实体关系

🏷️ sys_course_type · 课程类型
id BIGINT PK · name VARCHAR(50) · description VARCHAR(200) · sort_order INT · status TINYINT
📚 sys_subject · 科目
id BIGINT PK · name VARCHAR(50) · code VARCHAR(20) · sort_order INT · status TINYINT
📖 sys_course · 课程
id BIGINT PK · code VARCHAR(30) UNIQUE · name VARCHAR(100) · type_id BIGINT FK → sys_course_type
pricing_mode VARCHAR(20) ← PER_SESSION / PER_TERM · price DECIMAL(10,2) · total_sessions INT ← 整期模式时必填
description VARCHAR(500) · cover_image VARCHAR(255) · status TINYINT
🔗 sys_course_subject · 课程-科目关联
course_id BIGINT FK → sys_course · subject_id BIGINT FK → sys_subject
(course_id, subject_id) 联合主键
🏫 sys_classroom · 教室
id BIGINT PK · name VARCHAR(50) · capacity INT · facilities VARCHAR(300) · location VARCHAR(100) · status TINYINT ← 1启用 / 0停用
