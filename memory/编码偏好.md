## 编码偏好

### 通用
- 默认使用简体中文交流
- 缩进 2 空格（前端）/ 4 空格（后端）
- 单引号，分号必须
- 禁止 `any` 类型（TypeScript），必须明确类型定义
- 禁止在生产代码中遗留 `console.log` / `print`

### Vue 前端
- 必须使用 Composition API + `<script setup>`
- 禁止 Options API
- Dialog/Drawer 一律使用 v-model（受控组件）
- 所有接口调用必须走 `src/api` 目录
- 新增页面必须同步更新路由
- 样式使用 `<style scoped lang="less">`，通过 @import 引入

### Spring Boot 后端
- Controller 层只做参数校验和路由，业务逻辑在 Service 层
- Service 层接口与实现分离
- 统一返回格式 `R<T>`
- 禁止在循环中执行 SQL 查询
- 敏感信息不打印日志

### 代码审查关注点
- 正确性 > 可维护性 > 安全性 > 性能
- 不纠结代码风格（已由规范覆盖）

**Why:** 这些偏好来自用户的明确要求，部分来自 OA 系统的成熟规范积累。
**How to apply:** 每次代码生成和审查时严格遵循，发现偏离主动提醒。
