## 后端 M0（系统管理）来源与运行

`education-store-server/` 后端 M0 系统管理是从 `D:\Work\Personal\OA\OA-Space` 抽取的，
决策：**去掉 多公司 + 部门(SysDept) + 岗位(SysPost) + 数据权限(DataScope)**，
重命名 `com.oa`→`com.education.store`、模块 `oa-*`→`edu-*`、表前缀 `oa_`→`sys_`、库 `oa_system`→`edu_system`。
保留：用户/角色/菜单/字典/配置/通知/日志 + 登录认证 + 文件上传。登录已改为**一步式**（删除了 OA 的两步选公司）。

### 本地运行环境（非显性，仓库未记录）
- MySQL：`root` / `root`，库 `edu_system`（先跑 `sql/edu-schema.sql` 再 `sql/edu-init-data.sql`）
- MySQL CLI：`C:\Program Files\MySQL\MySQL Server 9.7\bin\mysql`
- Redis：需手动启动 `redis-server.exe`（winget 装的 taizod1024.redis-windows-fork 目录下），端口 6379
- 默认管理员：`admin` / `admin123`（userId=1，`SecurityUtils.isAdmin()` 靠 userId==1 判定，绕过全部 @PreAuthorize）
- 构建：`mvn clean install -DskipTests`（多模块必须 install）；启动 `mvn -pl edu-server-app spring-boot:run`，端口 8080

### 已清理的历史包袱（2026-07-10）
- **后端 SysLog 冲突已删净**、**残留部门字段已删净**（见上文）。
- **前端 edu-web 落地（2026-07-10）**：从 oa-web 抽取登录+系统管理，去多公司/部门/岗位/数据权限。vue3+element-plus+vite+pnpm。`pnpm build` 通过（3.69s）。7 个系统管理视图：user / role / menu / dict / config / notice / log。
  - 前端路径：`education-store-web/`，`pnpm dev` 启动端口 3000，代理 `/api-prefix`→`localhost:8080`。
  - 删掉的业务域：flow/hr/im/oa/attendance/personal/monitor/tool/swagger + system/{company,dept,post} + mock。
  - 去耦合外科：login 去选公司步骤、stores/user.js 去 company/dept、api/auth/login.js 去 selectCompany、user 视图去部门树+岗位、role 视图去数据权限弹窗+dataScope 列、首页换教育欢迎页。
  - 登录链：`/api-prefix/api/v1/auth/login`→Vite proxy 剥离 `/api-prefix`→backend `:8080/api/v1/auth/login`（一步式，不走选公司）。
