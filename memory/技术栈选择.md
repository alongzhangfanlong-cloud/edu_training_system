## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | Vue 3 (Composition API) | ≥3.3 |
| 构建工具 | Vite | - |
| UI 组件库 | Element Plus | - |
| 状态管理 | Pinia | - |
| 样式方案 | Less + scoped | - |
| 包管理器 | pnpm | - |
| 后端框架 | Spring Boot | 3.x |
| JDK | Java 17 | - |
| 数据库 | MySQL | 8.0 |
| 缓存 | Redis | 7 |
| ORM | MyBatis-Plus | - |
| 安全 | Spring Security + JWT | - |
| 包结构 | com.education.store.module.* | - |

**Why:** 复用了 OA 系统的成熟技术栈，团队/个人对此技术组合有丰富经验。
**How to apply:** 新模块开发时严格按照此技术选型，不引入新的技术栈除非有充分理由。
